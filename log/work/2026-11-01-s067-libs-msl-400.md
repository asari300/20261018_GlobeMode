## 依頼

S063 の持ち越し「MSL 4.0.0 で回し直したときの版の差の数」。公開ライブラリの検査（`libraries.yml`）を MSL 4.0.0 でも回せるようにし、4.1.0 との本数の差を測って書く。サブエージェントとして実装し、main へのマージ・CI の最終確認・セッション記録の写しは親が行う。

## 決めたこと

- `fetch-msl --version`（既定 4.1.0、4.0.0 も可）。4.0.0 の sha256 は実際に取得して計算した（`98d8e785…a783`、29,117,960 バイト、12,403 ファイル）。置き場は既定の `data/msl` のままで、**別の版が展開済みの `--dest` を断る**（目印の版を見るだけ）。版ごとの置き場（`data/msl-4.0.0`）を既定にはしなかった。
- `libraries.yml` は入力 `msl` を `env.MSL_VERSION` に写し、cache の key・`fetch-msl --version`・`libraries-report --msl` に渡す。定期実行は 4.1.0。
- `libraries-report` の見出しの MSL の版は、funnel の JSON の `msl_version`（xtask の定数）でなく `--msl` から書く。`funnel.rs`・`sim.rs` は変えない。
- `doc/libraries.md` は 4.1.0 の表を正のままにし、4.0.0 の表は research に書いた。
- 4.1.0 の側の土台: S058 の run との比較に加え、この branch のコードで 4.1.0 を回し直した（Buildings を除く 6 つ）。差 0 だったので Buildings も S058 の run を土台にした。
- S 番号: `doc/sessions/README.md` と `git ls-remote --heads origin` で S067 は空きだった（S064・S066 は別セッション）。
