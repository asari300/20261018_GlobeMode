## 依頼

P4 の完了条件の残り。Desktop で MSL を読めるようにし、MSL を読んだ後の RSS の基準値を CI で記録する。

## 決めたこと

- MSL は JSON で送らず、sidecar の起動時の `--library` / `GLOBE_LIBRARY` のまま。command `libraries` が起動時のパスの一覧を返し、`TauriBackend.library()` は一覧が空でなければ resolve（JSON は捨てる）。App.svelte・`Backend` は変えない。
- smoke は環境変数 `GLOBE_DESKTOP_SMOKE_MODEL` でライブラリのモデルを指定（最小の変更）。RSS はアプリ自身の `/proc/self/status` と sidecar の `/proc/<pid>/status` の VmHWM を各段の後に表示する。`time -v` は残す。
- `data/msl` は `msl-sim.yml`・`ci.yml` と同じ key（`msl-${{ hashFiles('src/Rust/xtask/src/main.rs') }}`）で cache（run では復元に成功）。

## やったこと

- `src/Rust/apps/desktop/src/main.rs`: command `libraries`、smoke の拡張（`hwm`・`report_hwm`）。
- `src/Rust/apps/desktop/src/worker.rs`: 試験 `budget_kills_a_silent_sidecar` の ETXTBSY（`Text file busy`）の競合を再試行で避ける（最初の run 41243722087 で Linux の試験が落ちた。S049 から潜在）。
- `src/Svelte/src/lib/tauri-backend.ts`: `library()`。
- `.github/workflows/desktop.yml`: MSL の cache と取得、smoke を ChuaCircuit の検査・実行に、artifact `desktop-linux-smoke`。Windows のジョブは変えていない。
- 文書: ADR-0023 の S056 の節、roadmap（S056 の節、P4 の表）、セッション文書、索引。
