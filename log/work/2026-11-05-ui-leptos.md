## 依頼

P7 の完了条件「`doc/bench/ui.md` に 3 UI × 3 OS の比較」のうち Leptos 版を作り、S125 の測定ハーネスでブラウザ（Linux）の 1 列を足す。機能は絞る（textarea、検査、実行、MSL、ダークモード）。CI・Dioxus・Tauri・プロット・Windows/macOS は持ち越し。

## 決めたこと

- Leptos 0.8.23（MIT、`csr`）。0.9.0-rc1 は採らない。ビルドは `trunk` を使わず `cargo build` → `wasm-bindgen --target web`（`wasm:build` と同じ作り）。ADR は不要という選択肢もあったが、facade 直結（ADR-0023 の (a) の例外）を残すため ADR-0035 を書いた。
- 別の workspace（desktop と同じ）。target は `${CARGO_TARGET_DIR:-target}/leptos`（ルートのものと混ぜない）。ルートの `[patch.crates-io] diffsol` を同じく書いた。
- facade 直結。メインスレッドが止まるのは許容（解説書に書いた）。
- テーマの保存はしない（持ち越し）。`ci.yml` は触らない。
- Svelte の公平な比較のため、同じ条件（load 約 2）で Svelte を測り直した（pnpm build、既存の wasm-pkg）。S125 の列は上書きせず、ui.md の出典に併記した。
