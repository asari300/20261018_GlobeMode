## 決めたこと

- **XML パーサは `roxmltree` 0.21**（MIT OR Apache-2.0、依存は `memchr` だけで Cargo.lock に既にある）。選ばなかった: `quick-xml`（MIT、DOM が無く手書きが増える）、`serde-xml-rs`（属性とテキストの扱いに癖があると推測）、`fmi-schema`（`hard-xml`・`chrono` など 42 パッケージ）。
- **C ABI は案 A（自前）を推奨し、決定はユーザーに残した**（ADR-0026 (b)）。選ばなかった: `fmi` 0.8（`fmi-sys` が bindgen と libclang を要る）、`fmi-rs` 0.3.4（公開から 3 日、`colored` が MPL-2.0、build.rs の C が wasm32 で落ちた、fmusim の基盤で検証の相手と重なる）、`fmu-runner`（更新停止）。FMI crate は調査だけで依存に足していない。
- 共有ライブラリは書かなかった。FMU の実行は ADR-0023 の別プロセスのワーカーの中に限る案。
- fixture は Dahlquist と Feedthrough の `modelDescription.xml` 4 つ（BSD-2、`tests/data/LICENSE` に原文。原文の誤植 "IMPLIEDi" はそのまま）。バイナリは入れない。
- `fetch-msl` の展開部分を `fetch_zip` に括り出して `fetch-reference-fmus` と共有した（挙動は変えていない。MSL の目印ファイル名も同じ）。
- 3.0 の `variability` の既定は、Float 以外を `discrete` とした（XSD に既定が無く、仕様本文で未確認。コードのコメントと調査に【未確認】と書いた）。
- ルートの Cargo.toml は触っていない（`members` の glob `src/Rust/mod/globe-mode-*` が新 crate を拾う）。architecture.md・features.md は触っていない（並行セッション）。
