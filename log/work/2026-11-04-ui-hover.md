## 依頼

S138 の持ち越し「ホバー」: エディタで名前の上にマウスを置くと、その宣言（型・部品の 1 行）と説明文字列が出る。`Backend.hover`、wasm と Tauri（`globe/hover`）、CodeMirror の `hoverTooltip`（300 ms、素のテキスト）。依存は足さない。

## 決めたこと

- 既存の `textDocument/hover` は「囲むクラスの種類」だけで、名前の宣言は返さない。UI 用に `definition::hover_at` を足し、`definition_at` と同じ `Resolver` で定義を引く。`Target` に `class: bool` を足した。
- `ComponentOutline` の範囲は名前だけで、説明文字列を持たない。アウトラインを広げず、定義のファイルの本文から行頭〜`;`（クラスは行末）を取る。説明文字列が同じ文に入る。限界は `shortcut:` として `hover_at` に書いた。
- `textDocument/hover` は VS Code と既存の試験のため変えない（持ち越し）。
- `App.svelte` は、エディタの拡張の並びの 1 行（`modelicaDefinition` に第 3 引数 `{ backend, file: () => file }`）だけ変えた。`modelicaLinter` の `file` は文字列の写しで、ライブラリのファイルを開くと古くなる。ホバーは現在のファイル名が要る（古い名前で `setFile` すると元の文書を上書きする）ので、関数で渡した。import や `smoke()` には触れていない。
