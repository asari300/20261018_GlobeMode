## 決めたこと

- SSD の XML は `globe-mode-fmi`（roxmltree 済み）、zip の展開と変換は `globe-mode-fmi-import`（`Ssp::open`）。CLI は `globe fmu cosim` が拡張子で分ける。
- SSP の start / end は向きではない（仕様 5.3.2）ので、FMU の causality で出力 → 入力に揃える。
- 単位は `Units` を読まず、接続の両端の `unit` の名前の一致だけを見る（違えば断る）。
- XSD では検証しない（取得していない【未確認】）。
