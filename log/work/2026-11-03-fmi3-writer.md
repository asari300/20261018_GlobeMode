## 依頼

S117 の持ち越し: FMI 3.0 の `modelDescription.xml` の書く側 `write_model_description_3`。既存の読む側と `ModelDescription` 型に合わせ、Real・Integer・Boolean だけ（Enumeration・String は `Err`）。試験は Dahlquist 3.0 と P5a の Decay 3.0 の round-trip、2.0 の writer の試験は変えない。`globe-mode-fmu` は 2.0 のまま触らない。ADR-0031 に 1 段落追記。

## 決めたこと

- 2.0 と 3.0 は private な `write_model_description(md, major)` を共有し、違うところ（トークンの属性名、変数の要素、`ModelStructure`）だけを分けた。2.0 の出力の文字列は変えていない（`ScalarVariable` の行は同じ書式）。
- 3.0 には `numberOfEventIndicators` が無い。読む側は 3.0 で `<EventIndicator>` の数を `number_of_event_indicators` に入れ、書く側は 1 つ以上なら `Err` にした。valueReference を持つには `ModelStructure` に欄が要るが、`globe-mode-fmu` がその構造体を欄の名前で組み立てているので、欄を足すと範囲の外の crate を変えることになる（`shortcut:` の注記、P5b の 3.0 のときに足す）。Dahlquist 3.0 と Decay 3.0 には `EventIndicator` が無い。
- 3.0 では `structuralParameter` と `ScheduledExecution` も書く（型が持ち、手間が増えないため）。
