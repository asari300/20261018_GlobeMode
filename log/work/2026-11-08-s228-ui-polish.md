## 依頼

roadmap の「機能の穴（P4）UI の使い心地」の 4 点（Esc で止める、タブの並べ替え、設定のモデルごとの保存、開始時刻・固定刻み・予算の欄）を Svelte の UI に入れる。

## 決めたこと

- Esc は `shortcut`（window の capture）の先頭で、実行中・修飾キー無し・入力欄/ダイアログの外・補完の一覧が閉じているときだけ `backend.cancel()`。一覧が開いていれば CodeMirror が閉じるだけ。
- タブの並べ替えは `moveTab`（`tabs` と `cur` を入れ替え、`persistSoon`）。DOM がタブについていくよう `{#each tabs as t, i (t)}`（キー付き）。ドラッグは HTML5 の `draggable`、キーは Ctrl/Cmd+Shift+PageUp / PageDown。
- 設定のモデルごとの保存は `SimSettings` の中で localStorage `globe-mode.sim`（上限 50 モデル）。App の `persist`（タブ）には混ぜない（タブの本文と無関係で、モデル名の鍵のため）。
- 「設定を既定に戻す」の名前は、Plot の「既定に戻す」と他の試験の `name="実行"` の部分一致を避けて決めた。
- 固定刻みのソルバの一覧は UI に写した（`SolverEntry` に印が無い。Rust は触らない）。
- protocol の Rust 側に `step`・`max_wall_seconds` は既にあり、TS の型にだけ足した。
