## 依頼

FMI 3.0 の Scheduled Execution（SE）の Export の最初の一切れを調べ、できる範囲で作る。クロックの無い連続モデルを周期 Clock 1 つ・パーティション 1 つとして出せるか。`globe-mode-fmi-import` は触らない。

## 決めたこと

- P5b だけで出す（Rumoca の `fmi3` テンプレートに SE が無い）。`fmi3ActivateModelPartition` は CS の `do_step` を呼ぶ。
- 口は既存の旗に合わせて `--runtime p5b --fmi-version 3 --kind se`。facade は `FmuOptions.kind`（JSON `"se"`）。
- Clock の値参照は `time` の次、周期は `experiment(Interval)` か 0.01。1 つに固定（shortcut。複数 Clock は持ち越し）。
- fmusim は SE を回せない（v0.15.0・v0.16.0）ので `fmu-export.yml` には足さない。FMPy の `FMU3ScheduledExecution` を Python から直接回す試験にした。
