## 決めたこと

- **Rust 4 種の範囲外は HTTP 200 の `ok: false`**: 依頼は「既存の `indent` の誤りと同じ形の 4xx」だったが、4 種の `indent` の誤りは HTTP 200 の `ok: false` で、[web-apps.md](../../doc/web-apps.md) の 3 が「HTTP は常に 200」と決めている。**「同じ形」を優先**し、4xx にはしなかった（FastAPI は 422、Astro は 400。どちらも前からの形）。
- **`:407` の `width + 1`**: 407 行目に `+ 1` は無く、溢れる所は 341 行目の 2 か所だった（`let limit = self.opt.width.saturating_add(1)`）。ほかに `width` に足す所は無い。
- **伏せ字の規則**: キーの直後に引用符が来る形は、値も引用符で始まるものだけ伏せる。単に引用符を任意にすると、コミット済みの `log/sessions/2026-10-18-40153c9b-….md` の `'time_to_first_token': 25.680112`（LM Studio の統計）を拾い、`--check` が 1 件落ちた。PEM は `BEGIN`〜`END` を丸ごと伏せ、`END` が `clip` で切れていれば続く base64 だけの行（16 字以上）までを伏せる（文書全体を一度に `redact` するので、`END` が無いときに末尾まで消すと記録が壊れる）。`Authorization:` は `token`・`basic` の後ろ（`Bearer` は既存の規則）。
- **Astro の検査**: ルートの `format.ts` は拡張子なしで `lib/globe` を読むので Node の試験から読めない。範囲の検査を `lib/globe.ts` の `intIn(v, lo, hi)` に出して試験し、`indent` もそれで検査する（意味は同じ）。
- **Desktop の試験**: 既存の `write_mo_writes_only_mo_files_in_an_existing_folder` に symlink（先あり・先なしのぶら下がり）を足した（`#[cfg(unix)]`）。手元に webkit2gtk が無くビルドできないので、`write_mo` と試験を切り出して `rustc --test` で、直す前（落ちる）と直したあと（通る）を確かめた。本番の試験は CI のジョブ `desktop` で回る。
