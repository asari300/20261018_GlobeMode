## 決めたこと

- **wasm に `check` を足す**（WP-B の所有の例外。Fable が許した）: `Workspace::check(model)` が facade の `CheckResponse` を JSON で返す。`worker.js`・`client.js` に `check` を足した。他の Rust は変えていない。
- **TypeScript の型は手書き**（protocol の構造体から、UI が使う項目だけ）。JSON Schema は WP-0 の持ち越しのまま。
- **試験は Python の Playwright 1 本**（`dist/` を localhost で配る）。npm の試験の枠は足さない。
- **起動で落ちた worker は作り直さない**（Fable が直した）: `GlobeWorker` は `init` が終わる前に落ちると、`worker.js` が 404 のとき 8 秒に 914 回の GET を出して無限に作り直していた。`#alive` を持ち、`init` 前に落ちたら以後の呼び出しをその誤りで reject する。Node の試験（`worker-node.mjs`）に 1 件足した。
- **MPL-2.0 の lightningcss**（Vite 8 のビルド時の依存）は cbindgen と同じくツールとして許可。`dist/` にも配布物にも入らない。prod の 12 個は全部 MIT。
- サブエージェントの判断で受け入れたもの: TypeScript 6 に固定（svelte-check 4.7 が 7 を受けない）、`test_ci_plan.py` の「関係ない変更」の鍵に `ui` を足す、CI の `ui` ジョブで `pnpm licenses` の GPL・NC を失敗にする。
- ヘッドレス Chromium の最初のページで frame が出ない件は、素の HTML でも起き、2 つ目のコンテキストでは 0.06 s で通ったので、UI の問題ではなく WSL の環境と判断した。試験は `click(force=True)` のまま。
