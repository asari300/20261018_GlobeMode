## 決めたこと

- `ida` を S032 の feature `sundials` に足す（サブエージェント Sonnet・high）。新しい依存は無く、sundials-sys の feature に `ida` を加えるだけ（`Cargo.lock` は変わらない）。
- ホストは ODE の導関数しか渡さないので、IDA には残差 F(t, y, y') = y' − f(t, y) を渡す。`IDACalcIC` は呼ばず、y'0 = f(t0, y0) を導関数 1 回で求める（始め直すたびも同じ）。始点で断られた・有限でない傾きは `AdvanceExhausted` の失敗。
- `IDA_ONE_STEP`・`IDASetStopTime`・`IDAGetDky`・`IDAReInit`・密な線形ソルバ・差分商のヤコビ行列・根探索なしは `cvode` と同じ。`plugins/ida.rs` は `cvode.rs` を写した作りで、共通化しない（抽象の層を足すより小さい）。`shortcut:` は冒頭に 1 つ（密な線形ソルバだけ、IDA の本領の DAE を使わない）。
- 登録表: feature を立てると計画だけのソルバは 0 になるので、`planned()` と `BDF` の定数、`planned_solver_is_an_error_with_a_substitute` の試験を `cfg(not(feature = "sundials"))` にした。
- 既定のまま進めたこと: CI に feature つきのジョブを足さない。

## 残したこと

- CI は feature つきのビルドを回していない。既定のビルドの `--solver ida` が `GM-E10005` になることは、登録表の試験で確かめた（CLI を回しては見ていない）。

- `msl:funnel`・`msl:sim` は回していない（既定の `auto` は `ida` を通らない）。release での時間は測っていない。
