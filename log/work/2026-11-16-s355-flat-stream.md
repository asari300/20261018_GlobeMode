## 依頼

自前の flat が MSL の例題 21 本（`Modelica.Fluid.Examples.AST_BatchPlant.BatchPlant_StandardWater` ほか）と `GlobeModeValidation.Connect.MediumFlow` を理由 `stream` で断っている。stream コネクタ（MLS 15。`stream` 変数、`inStream`・`actualStream`、接続集合の混合。2 本は値の受け渡し、3 本以上は混合、つながないなら自分）を平らにできるようにし、Rumoca の flat と名前・方程式の数を合わせる。原因ごとに分けて多いものから。全部でなくてよいが回帰 0。Fluid の例題は replaceable の Medium が多いので S297・S341 の redeclare の道を再利用する。

## 決めたこと

- **base は S335 のブランチにした**。S335 が main に未着で、回帰の基準の `target/frontend-diff.json` が S335 の最後の全体の検査（518/566）のものしか無い。main（S336 まで）から切ると基準を作る全体の検査をもう 1 回回すことになり、`unsized-array` で止まる例題の先も見えない。S335 の作業ツリーは未コミットの変更が無い（12e4bfbc）。マージの順は親に任せる（S335 → S355 の順なら S335 の分が重複しない）。
- **22 本は原因が 1 つだった**（`diff-frontend --class … --dump` の理由。21 本は `stream: <葉>` の最初の `connect` で止まる）。`stream` を通したあとに別の穴が出るかを見るため、先に実装して 22 本をまとめて回した。
- **Rumoca の定義を読んで合わせた**（`rumoca-phase-flatten/src/connections/stream_operators.rs`、`equation_generation.rs`。rev 276e82bd）: (1) 外側のコネクタの端ごとに `x = <x を除いた集合の混合>`（`inStream(x)` ではない）を 1 本、内側の端・つながない端には作らない。(2) `inStream(x)` は `x` が内側の端の集合の混合: 端 0 なら自分、1 つならその端の値、2 つ以上なら `Σ max(∓m_flow, ε)·値 / Σ max(∓m_flow, ε)`、`ε = 1e-7 × 最小の nominal`。外側の端の値は 1 段上の `inStream`。(3) 流量が集合へ入らない端（内側で `min >= 0`・外側で `max <= 0` のリテラル）は混合に入れない。(4) 大きさ 0 の欄（`Xi_outflow[0]`）は端にせず、`inStream` は `{}`。
- **展開は平らにし終わったあとの 1 回**（`flatten/stream.rs` の `expand_streams`）。外側の端の値は 1 段上の集合で決まるので、全部の集合がそろうまで展開できない。外側の端の方程式は印字 `x = __outStream(x)` で置いておき、一緒に置き換える。式の木は作らず、印字を走査して `inStream(…)` を置き換える（文字列の中は読まない）。
- **shortcut**: `smooth(0, m_flow * actualStream(x))` は作らない。添字が定数でない `inStream(ports[i].h)` と流量が 1 つに決まらないコネクタは `stream` で断る（MSL の例題には無い）。
- **Fluid の例題で見つかった穴を直した**: (a) `pending_bind` が `massDynamics = energyDynamics` のような別名をたどらず、後ろに宣言された `inner system` の欄で `if` が評価できなかった（状態 8 対 4）。(b) `count_eq`（`if`・`for` の中）が `dims_of` を使わず `zeros(nXi) = …`（nXi = 0）を 1 本と数えた（+44）。どちらも `stream` の展開ではないが、新しく通る 20 本の数字を左右するので同じ WP で直した。
- **直さなかったもの**（理由は ADR-0039 の付記）: Rumoca が評価しない `show_Res = true`（自前が正しい）、Rumoca の部品の配列の方程式の数え方、`StateGraph` の `outer` のコネクタの `connect`、DAE のレコードの欄ごとの行。
