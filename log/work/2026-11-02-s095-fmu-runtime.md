## 依頼

P5b（自前のランタイム）を P5a（S094）と並行して進める。`globe-mode-fmi` と CLI は触らない。新 crate `globe-mode-fmu`（cdylib）で Decay を ME で動かし、FMU に詰めて FMPy で x(1) ≈ e⁻¹ を確かめる。(a) `fmi-export` 0.3.0 と (b) 自前の FMI 2.0 ME の C ABI を比べて小さいほうを取る。ADR-0032 を Proposed で書く。

## 決めたこと

- **(b) 自前の C ABI を取った**（既定のまま進めた）: 依存 0、FMI 2.0（P5 の完了条件）を満たす。(a) は FMI 3.0 のみで依存が増え、1.0 前。
- **exec にも facade にも依存しない**: 依頼は「facade か exec に依存」だったが、exec の公開 API は最後まで回すものだけで、ME に要る「状態 → 微分」の評価が無い。exec は触らない約束なので、Decay の式を Rust で手書きした。exec に API を足すのが次の一歩（ADR-0032 の (b)）。
- **置き場は `binaries/linux64/`**: 依頼の `x86_64-linux` は FMI 3.0 の名前。FMI 2.0 では `linux64`。
- `catch_unwind` は置かない（panic の道が無く、Rust 2024 の `extern "C"` は abort）。
- 試験の cdylib は結合テストが作らない（rlib だけ）ので、試験の中で `cargo build --lib --message-format=json` を呼んで置き場を取る。
