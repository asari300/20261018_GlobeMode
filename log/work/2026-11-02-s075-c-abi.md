## 依頼

P7 の C / Zig / Julia。facade を C ABI で包む crate `globe-mode-c`（cdylib + staticlib、facade だけに依存）を足し、`gm_workspace_new` / `gm_workspace_free` / `gm_set_file` / `gm_check` / `gm_simulate` / `gm_string_free` を最小に出す。panic は `catch_unwind`。新しい依存は足さず、ヘッダは手書きにして署名の突き合わせの試験を 1 本置く。Zig（`build.zig`・`src/main.zig`）と Julia（`ccall` だけの `globe_mode.jl` と `test.jl`）で Decay を check → simulate し、JSON の長さと最後の時刻を出す。`mise.toml` に `c:zig` / `c:julia`。ci.yml にはジョブを足さない。main へのマージ・push は親が行う。

## 決めたこと

- **面は `globe_mode._native` と同じにした**: 最小の 6 つに `gm_load_dir`・`gm_graph`・`gm_solvers` を足して 9 関数（それぞれ数行）。
- **誤りは JSON**（`{"error": ...}`）。NULL を返すのは `gm_workspace_new` だけで、理由は stderr に出す（ハンドルの関数に誤りの出口を足さないため）。`gm_set_file` は 0 / -1、`gm_load_dir` は数 / -1。
- **workspace の `unsafe_code = "forbid"` はこの crate だけ外した**（`[lints] workspace = true` を使わず、残りの 2 つを書き写した）。`forbid` は crate の中の `allow` で覆せないため。
- **cbindgen は入れない**。`tests/header.rs` がヘッダと `src/lib.rs` の `extern "C" fn` を読み、名前・引数の型・戻り値の型を型の対応表で突き合わせる（表に無い型は試験が落ちる）。
- **Zig は `addTranslateC`**（`@cImport` でなく）と `linkSystemLibrary("globe_mode_c")`、rpath。Zig 0.17 の `std.process.Init`・`addPassthruArgs` に合わせた（`b.args` と `Allocator.dupeZ` は 0.17 に無い）。
- **Julia は JSON を解析しない**: 標準ライブラリに JSON が無いので、`passed`・`ok` は部分文字列、最後の時刻は CSV の最後の行を正規表現で拾う（`shortcut:` のコメントつき）。
- **CI には入れない**（既定のまま）。zig・julia の取得とビルドの時間（手元で release の `globe-mode-c` 約 5 分）に見合うかを決めていない。入れるなら `ci.yml` に手動の 1 ジョブ（`mise run c:zig` と `c:julia`）が最小。
- `.github/scripts/ci_plan.py` は変えていない: crate を `src/Rust/mod/globe-mode*/Cargo.toml` から自動で拾い、依存元も自動で辿るため。`test_ci_plan.py` の期待の集合（facade の依存元）にだけ `globe-mode-c` を足した。
