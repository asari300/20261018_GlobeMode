## 依頼

S256 の `Workspace::blt` を LSP・wasm・UI・Python から使えるようにする。式をクリックして宣言へ飛ぶのは位置が無いので範囲外。

## 決めたこと

- LSP は `globe/blt {model}`（`{file}` は取らない。UI は model 名を持っているため）。検査が通らなければ -32000。
- UI は DocsPanel のタブではなく、ツールバーの「BLT」ボタンで診断表の下に出す独立の `BltPanel.svelte`。S260・S261 が DocsPanel と backend を触るので衝突を避けた。
- Python は `blocks` の dict のリストだけ返す（`reduced`・`skipped` は落とす）。通らないモデルは `SourceError`。
- S256 が main に入るのを待ち、入ったあと main を取り込んだ（S261 の `globe/addConnect`・`globe/movePart` と RPC の一覧が衝突したので全部残した: 29 本）。
