## 依頼

P7 の完了条件「3 UI × 3 OS の比較」の 3 つ目、Dioxus 版を S153 の Leptos 版を型にして作り、ブラウザ（Linux）の 1 列を ui.md に足す。機能は同じ（textarea、検査、実行、MSL、ダークモード）。CI・Tauri・プロット・Windows/macOS は持ち越し。

## 決めたこと

- Dioxus 0.7.10（最新の安定版。0.8.0-alpha.3 は採らない）、`default-features = false`、feature は `minimal` + `web`。
- `dx` は使わず、Leptos 版と同じ `cargo build` → `wasm-bindgen --target web`。一度で通ったので、ADR に「無理だった理由」は要らない。載せ先は `index.html` の `<div id="main">`。
- 描画の待ちは `setTimeout(0)`（`js-sys` を足す）。Leptos の `tick()` に当たるものが無いため。
- ui.md の Svelte・Leptos の列は S125・S153 の値のまま残し、同じ日に測り直した 3 UI の値は Dioxus の出典の欄と解説書に書いた。

## やったこと

- `src/Rust/apps/experimental/dioxus/`（Cargo.toml・Cargo.lock・deny.toml・src/main.rs・index.html・main.js・style.css・tests/test_dioxus.py）。style.css・deny.toml・テストは Leptos 版の写し（名前だけ直した）。
- `mise.toml` に `dioxus:build`・`dioxus:check`。`bench_ui.py` の `--ui` に `dioxus`（`test_ui.DIST` の差し替えを `leptos` 固定から `experimental/<ui>/dist` に一般化した）。
- ADR-0036、`doc/adr/README.md`、`doc/licenses.md`、`doc/features.md`、`doc/roadmap.md`、`doc/architecture.md`、`doc/bench/ui.md`、`doc/sessions/` の索引・スライド・解説書。
