## 依頼

roadmap の「機能の穴（P8）拡充」の Documentation ビュー。カーソルのあるクラス（またはライブラリの木で選んだクラス）の `annotation(Documentation(info, revisions))` の HTML を、UI の右のパネルに出す。HTML は信用しない。

## 決めたこと

- Rust は `globe-mode-fmt` に `documentation(src, 完全修飾名)` と `class_at(src, offset)`（`structure::class_spans` を足した。字句解析と文の切り出しだけ）。共通の関数は `globe-mode-lsp::documentation`（wasm と `globe/documentation` が使う）。
- ライブラリの木で選んだクラスは、`openLibrary` が宣言の行にカーソルを置く（S186）ので、カーソルの道でそのまま引ける。`Backend.documentation(cls, at?)` の `cls`（完全修飾名）は UI からは使っていない（wasm・LSP・smoke の試験で使う）。
- 白リストは依頼の一覧に sub・sup・hr・blockquote・dl・dt・dd・thead・tbody を足した。属性は a の href（http・https・modelica）以外を捨てる。img は alt の文字。出力は文字列でなく木で、`{@html}` を使わない。
- `main` の最大幅を 60 rem から 76 rem に（右のパネルでエディタが細くならないように）。
- node の `--test` は DOM が無いので、`DomNode`（使う分だけ）の小さな木を渡す。本物の DOMParser を通る道は `test_ui.py` の `docs_panel`（script・onerror・javascript: が出ず走らない）。
