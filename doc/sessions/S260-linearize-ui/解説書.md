## 1. 目的

S254 の線形化（facade `Workspace::linearize`）を UI（Svelte。Desktop とブラウザ共用）から使えるようにする（[features](../../features.md)、[roadmap](../../roadmap.md) の P8）。

## 2. 決定と理由

| 項目 | 決定 | 理由 |
| --- | --- | --- |
| JSON | facade の `linearization_json` に 1 つ。CLI・LSP・wasm が使う | 3 か所で同じキー（`x u y x0 u0 y0 A B C D`）を手で書かない |
| LSP | `globe/linearize` `{model, time?, parameters?}`。できなければ -32000 | `globe/parameters` と同じ流儀。`RPC_METHODS` は 27 |
| wasm | `linearize(model, time?, parameters_json)` | 上書きは名前 → 数の JSON 文字列（`simulate` の `settings.parameters` と同じ形） |
| UI | ツールバーの「線形化」と時刻の欄。結果は結果の欄の表（`LinearizeView.svelte`） | 結果の欄はファイルのタブとは別の層なので、タブには足さず、プロット・グラフと並ぶ欄にした |
| 上書き | 実行の設定のパラメータ（`simSettings.parameters`）を使う | 実行と同じ値で線形化できる |
