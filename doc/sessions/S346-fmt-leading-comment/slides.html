annotation の引数の前の行のコメント

S343 の残り: コメントだけの行にあるコメントが付いた引数は、並べ替えから外れていた

名前を引くとき、頭のコメントを飛ばす
原因

コメントは次の引数の最初の字句

  • // icon の次の行の Icon(…) は、括弧の木（layout::seq）では 1 つの引数 [// icon, Icon, (…)]
  • annotation::position_in は先頭の字句の名前を表で引く。先頭がコメントだと引けず「その他」（後ろ）
  • 図形プリミティブの arg_name も同じで、先頭にコメントがあると「名前のない引数」とみなして並べ替えと origin の補完をやめていた
直し

body を 1 つ足した

  • annotation.rs に body（引数の中身から頭のコメントを除いた節）。position_in と arg_name がそこから名前を引く
  • 並べ替えは Arg ごと動かすので、名前が引ければコメントは引数と一緒に動く。layout.rs は変えない
  • lint の annotation-order は position_in を使うので、同じ入力で同じ判定になる
前後

同じ入力が、こうなる

入力（annotation の引数、各引数の前の行にコメント）前後
Documentation / Icon / experiment元の順のまま（3 つとも「その他」）experiment / Icon / Documentation、コメントも一緒

回帰試験 leading_line_comments_travel_with_annotation_args（並び、コメントの位置、2 回目で変わらないこと）

  • globe fmt --check src/Modelica: 75 ファイルが整形済み（0 件が要整形）
  • MSL 4.1.0 の 2,556 ファイルを globe fmt --check に通して、「整形でトークンが変わった」は 0 件
次回

残したこと

  • コメントの次のトークンが 1 段深く字下げされる（layout::push_token の規則。変えると括弧の引数すべての出力が変わる）
  • Documentation の info = "…" は、頭にコメントがあると HTML 整形されない（mark_html）
