## 1. 目的

[S230](../S230-lsp-cross-file-refs/解説書.md) が持ち越した、継承した部品と `import` の別名を、LSP の参照（`textDocument/references`）とリネーム（`textDocument/rename`）に届かせる。[roadmap](../../roadmap.md) の「エディタの言語サービス」の行。

## 2. 決定と理由

| 項目 | 決定 | 理由 |
| --- | --- | --- |
| 部品の同定 | 識別子のトークンごとに `Resolver::definition` を引き、宣言の場所（ファイルと範囲）が同じものを数える（`component_hits`）。`class_hits` の部品版 | `definition` が内側のクラスから外へ、`extends` の先も、`b.x` も解く。新しい名前解決器は書かない |
| 定義元に寄せる | カーソルが継承先の `x` でも、`definition` が定義元 `A.x` を返すので、そこから全体を数える | 宣言の場所が識別子になるので、どこから始めても同じ集合 |
| 探すファイル | 開いている文書は全部。ディスクは `A` を継承するクラスの名前の組を不動点まで広げ（`extends` の先の最後の名前が組にあるクラスを足す）、`x` と組の名前のどれかを含むファイルだけ調べる | MSL 約 2,500 本のうち `SISO` の先だけを字句に分ける |
| 鎖の途中のファイル | 不動点の途中でアウトラインを `scratch` に読み、`Resolver::locate` が木にない名前を `scratch` のファイルからも探す（開いていない `.mo` の `extends`・`import` の先を引ける） | 鎖 `C extends B extends A` の `B` が開いていなくても `C` の `x` が `A.x` と引ける |
| `import` の別名 | 別名 `D` の宣言と `D.X` の頭を、宣言したクラスの中の字面で数える（`alias_at`）。リネームはその文書の中だけ。`class_of` は別名のトークンをクラスとして扱わない | 別名は宣言したクラスの中だけの名前。解決は要らない |
| `D.X`・ワイルドカード | 既存の `resolve`（別名・`.*`・修飾 import）が解く。開いていない `.mo` では、その `.mo` 自身を `locate` が引けなかったので `import` を見落としていた。`scratch` から探すようにして解けた | 新しい解決器は書かない |
| S230 の守り | 仕組みは残す。解決できる分は断らなくなった | 実在しない `Elsewhere.Pkg` を通る `D.Base` は別のクラスなので、黙って取りこぼさないよう今も断る |
| ライブラリ | 部品の定義元がライブラリならリネームは断り、参照は返す。継承先がライブラリのファイルなら参照に出し、リネームでは変えず知らせる | S230 と同じ |

## 3. 図

```text
カーソル: B の中の der(x)   -- definition --> A.x（宣言の場所）
  |-- 開いている文書          component_hits
  |-- ディスク                 A を継承する名前の組を広げる -> 含むファイルだけ -> component_hits
  `-- ライブラリ               参照に出す。リネームは変えない
```

届く範囲の前後は次のとおり。

| 対象 | 参照（前） | 参照（後） | リネーム（前） | リネーム（後） |
| --- | --- | --- | --- | --- |
| 継承先の中の `x`（定義元から） | × | ○ | × | `changes` に入る |
| 継承先の中の `x` にカーソル | 同じ文書の字句 | ○（定義元と他の継承先も） | 断る | ○ |
| `b.x` | × | ○ | × | ○ |
| `import D = A.B;` の別名 `D` | × | その文書の中 | 断る | その文書の中 |
| `D.X`・`import A.B.*;` を通るクラスの参照 | 開いている文書だけ | 開いていない `.mo` にも | 断る（解決できず） | `changes` に入る |
| `redeclare`・`replaceable` の先 | × | × | × | × |

## 4. 測定

MSL 4.1.0（`-L data/msl`、release の `globe lsp`）で、`Modelica.Blocks.Interfaces.SISO` の `u` の上の `textDocument/references`。

| 呼び出し | 時間 | 結果 |
| --- | --- | --- |
| 初回 | 4.3 s | 321 箇所、92 ファイル |
| 2 回目以降 | 0.75 s | 同じ |

初回が S230 のクラス名（2.0 s）より長いのは、継承の鎖を広げるときに `extends` のあるファイルのアウトラインを読むため。

## 6. 次回

- `redeclare`・`replaceable` の先は対象外。
- 継承先が同じ名前を宣言していても衝突は見ない（`check_component_name` は定義元のクラスと `extends` の先まで）。
- 定義元が開いていない根の下の `.mo` で、カーソルが継承先のとき、`Resolver` がまだ読んでいない定義元は引けない（定義ジャンプと同じ限界）。
- `model C = B;` の短いクラス定義は継承の鎖と見ない。
- UI の `globe/*` はメモリ上の文書のまま。
