進捗と中断の Python の段

ADR-0033 の実装の順の 3: globe-mode-py と globe_mode

on_progress が True か Ctrl-C で止まる
目的

このセッションでやること

  • S123 の facade の simulate_observed を Python から呼べるようにする
  • Workspace.simulate と simulate_columns に keyword 引数 on_progress
  • 実行中は GIL を離し、Ctrl-C を KeyboardInterrupt で届ける
  • wasm（S127 が触っている）・C・NIF・LSP は持ち越し。exec と facade は変えない
決定と理由

決めたこと

項目決定理由
引数on_progress=None の keyword。None なら前の道既存の呼び方と結果を変えない
進捗の形dict（stage・time・start_time・stop_time）exec の Progress をそのまま写す
GILpyo3 0.30.1 の Python::detach で離し、進捗ごとに Python::attach旧名 allow_threads。crate のソースで確かめた
Ctrl-C進捗ごとに check_signals。例外ならトークンを立て、戻ってから投げ直す実行系は次の区切りで止まり、列が壊れない
unsafe使わないfacade の Workspace は Send だった
