モデルを線形化して A・B・C・D を出す

globe linearize -m Plant [--time T] [--json]

入力は input、出力は output、x は状態。数値の中心差分
仕組み

ModelInstance の上で中心差分

  • 状態と入力を 1 つずつ ±h ずらし、derivatives（f）と出力の変化を 2h で割る
  • h = eps1/3·max(1, |v|)。代数ループの許容誤差 1e-10 に埋もれない大きさ
  • 代数変数は評価のたびに解き直される。線形化の側は触らない
  • Rumoca の公開 API にヤコビ行列は無かった（ADR-0038）
口

試験

解析的に分かる系で 1e-6

  • LinearSystem: 2 状態・1 入力・2 出力、代数変数を挟む。A・B・C・D が手計算と一致
  • Pendulum: A = [0 1; -cos θ -c]。θ = 0.5・平衡点 0・t = 2 で実行した点
  • CLI は JSON と表示の 2 本
