## 1. 目的

モデルを指定時刻で線形化し、状態空間の行列 A・B・C・D を出す最小版（[features](../../features.md) の線形化、[roadmap](../../roadmap.md) の P8）。

## 2. 決定と理由

詳細は [ADR-0038](../../adr/0038-linearize-numeric.md)。

| 項目 | 決定 | 理由 |
| --- | --- | --- |
| 微分 | 数値の中心差分。刻み eps^(1/3)·max(1, \|v\|) | Rumoca の公開 API にヤコビ行列が無い。代数ループの許容誤差 1e-10 を √eps の刻みで割ると雑音が大きい |
| 変数 | x は状態、u は top-level の `input` の Real、y は `output` の Real | FMU の `ModelInstance` の変数の分類をそのまま使う |
| 点 | 既定は初期化の直後。`--time` が後ならそこまで実行した状態 | 平衡点の探索（trim）は別の問題で、今回は入れない |
| 口 | facade `Workspace::linearize`、CLI `globe linearize -m <model> [-L] [--time] [--param] [--json]` | 既存の `simulate` と同じ引数の形（`-m`）に揃えた |

## 3. 図

```text
globe linearize ─► Workspace::linearize ─► compile ─► ModelInstance::new(start)
                       │ time > start なら run して状態を置く
                       ▼
        x[j] ± h / u[k] ± h ─► derivatives(f)・variable_values(y) ─► (f+ − f−)/2h ─► A B C D
```

## 4. 再現手順

```bash
cargo test -p globe-mode --test linearize
cargo test -p globe-mode-cli --test linearize
globe linearize src/Modelica/GlobeModeValidation -m GlobeModeValidation.Simulation.LinearSystem
globe linearize src/Modelica/GlobeModeValidation -m GlobeModeValidation.Simulation.Pendulum --time 3 --json
```

`LinearSystem` は A = [-2 1; 1 -2]、B = [1; 2]、C = [1 2; 1 -1]、D = [3; 0]。`Pendulum` は A = [0 1; -cos θ -c]。
