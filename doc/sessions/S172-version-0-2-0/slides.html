版を 0.2.0 に揃える

0.0.1・0.1.0・0.0.5 と混在していた版を、公開せずに 1 つにした

次の版は 0.2.0。タグも Release も作らない
目的

このセッションでやること

  • 版を書いている場所を洗い出し、すべて 0.2.0 にする
  • lock は自分の版の行だけが変わるようにする
  • Rumoca の rev は版ごとに固定する、と正典に書く
  • 公開はしない。上流の issue は提出せず貯める

決定と理由

決めたこと

項目決定理由
版の配り方仕組みを作らず、表で残す年に数回の作業。表があれば grep をやり直さない
Rumoca の rev版ごとに固定版の途中で差が混ざらない。v0.10.2 のまま
Modelica の package.mo上げないライブラリ自身の版で、製品の版ではない
