## 1. 目的

S281 の部品・結線の削除（Svelte の DiagramView で選んで Delete）を、S264 で移動と結線ができるようになった VS Code の側のパネルにも入れる。Rust・LSP は変えない。

## 2. 決定と理由

| 決めたこと | 理由 |
| --- | --- |
| 選び・印・削除の対象を `src/Svelte/src/lib/diagram-select.ts`（`pickSel`・`markSel`・`deleteOf`）に出し、Svelte と webview が読む | `DiagramView` に埋まっていた処理が DOM の API だけで書けたので、`diagram-drag.ts` と同じく写しを作らずに済む。node の試験に偽の要素を渡せる |
| `edit.js` に `deletePart`・`deleteConnect` を足す。結線の端は `名前[添字]` を許す | 配列の結線（S283）は `b[2].p` を `data-conn` に持つ。`deleteConnect` は比べるだけでソースに書かないので、添字の字（`\w , + * -`）だけ見る。書き込む `addConnect` は Rust の `end_ok` が見る |
| `file`・`class` は webview から受け取らない | S264 と同じ。パネルが最後に描かせた図のものを使う |
| `reveal` を `preserveFocus: true` にした | 部品のクリックで宣言へ飛ぶとエディタへフォーカスが移り、続く Delete が文字を消す。Svelte は飛んだあとに選びへフォーカスを戻す |
| e2e は `panel.handle` へメッセージを渡す | webview の DOM は拡張ホストから操作できない（S264 と同じ）。選びの処理は `pnpm test` の偽の要素で見る |

## 3. 図

```text
webview: click / focusin → pickSel → markSel（.sel）
         keydown Delete → deleteOf → postMessage {deletePart | deleteConnect}
拡張:    parseEdit（検査）→ globe/deletePart | globe/deleteConnect
         → TextEdit の配列 → WorkspaceEdit（undo 1 回）→ 図の引き直し
```
