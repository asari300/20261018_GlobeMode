VS Code のパネルでも、部品と結線を消せる

選んで Delete / Backspace。Svelte の UI と同じ操作

Rust・LSP は変えない。選びの処理は共有、拡張は検査して LSP を呼ぶだけ
流れ

webview から文書まで

  • webview: クリック・Tab で選び（青い枠・太線）、Delete で deletePart / deleteConnect を postMessage
  • 拡張: edit.js が型と値を検査（端は b[2].p も可）。file・class は受け取らない
  • globe/deletePart・globe/deleteConnect の複数の TextEdit を 1 つの WorkspaceEdit で入れる（undo 1 回、保存しない）
共有と確かめ

選びは diagram-select.ts に出した

  • pickSel・markSel・deleteOf を Svelte の DiagramView と webview が読む
  • 部品のクリックで宣言へ飛ぶとき、フォーカスは webview に残す（エディタへ移ると Delete が文字を消す）
  • 試験: pnpm test（検査・選び）と e2e（消す、undo で戻る）
