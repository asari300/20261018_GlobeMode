Diagram ビューの編集: 部品の移動

図の部品をドラッグして離すと、宣言の Placement の origin が書き換わる

書き換えはRust、UI はエディタに入れるだけ（Ctrl+Z で戻る）
Rust

move_part（globe-mode-fmt）

宣言編集
origin = {20, 0} あり{x, y} を新しい値に（小数 3 桁）
extent だけtransformation( の直後に origin = {dx, dy},
rotation つきorigin は図の座標の平行移動なので、そのまま足す
Placement なし・origin が式動かさない（null）

返すのはバイト範囲と文字列。他の所には触らない

口

どこから呼ぶか

  • LSP globe/movePart（Desktop の RPC 許可は 26 から 27 本）
  • wasm move_part → WorkerBackend・TauriBackend の movePart
  • 返りは LSP の TextEdit の配列。ファイルは書かない
UI

ドラッグ

  • 動かす間は部品の <g> に transform だけ。離したら 2 単位の格子に吸着した (dx, dy) を渡す
  • 4 px 未満は移動でなく、従来のクリック（宣言へ）。ダブルクリック・右クリック（S248）とは衝突しない
  • 編集は 1 回の dispatch。図が読み直されたら見た目の transform を捨てる
  • 結線は中心どうしなら読み直しで追従。Line(points) の点は動かさない
