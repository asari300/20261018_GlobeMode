エディタの Tab は字下げ

S175・S185 の持ち越し「Tab での字下げ」

Tab で字下げ。フォーカスを出す手は別に用意する
挙動

前と後

操作前後
Tabフォーカスがエディタの外へ移る行頭に空白 2 つ（選んだ行はすべて）
Shift+Tab前の要素へ移る字下げを 1 段戻す
Esc のあと Tab（Esc は選択を畳むだけ）次の要素へ移る。Shift+Tab は前へ
Ctrl+M（Mac は Shift+Alt+M）効いても Tab は外へ出ていたTab で移る・字下げの切り替え
タブ文字は入れない。幅は整形器の既定と同じ 2
仕組み

CodeMirror の組み込みを使う

  • indentWithTab（Tab は indentMore、Shift+Tab は indentLess）と indentUnit を足しただけ
  • 出る手は @codemirror/view 6.43.15 と @codemirror/commands 6.11.1 の組み込み。defaultKeymap が Ctrl+M を持つ。自前のキー処理は無い
  • Esc は補完の一覧を閉じ、選択を畳む。同時に 2 秒の窓が開くだけで、Esc 自体は奪わない
使い方の案内

画面とスクリーンリーダーの両方に

  • エディタの下に 1 行（#editor-help）。エディタ本体の aria-describedby が同じ要素を指す
  • README のショートカットの表に 2 行
  • WCAG 2.1.2（キーボードトラップなし）を満たす: 出る手を文書化してある
試験

test_ui.py

  • Tab で空白 2 つ、選んだ 2 行の字下げと Shift+Tab、補完の一覧が開いていても字下げで Enter は確定
  • Esc のあと Tab（次）・Shift+Tab（前）、2 秒の窓の外の Tab は字下げ、Ctrl+M で往復
  • S175 の「キーボードだけ」の tab_to は、エディタからは Esc のあと Tab に直した（弱めていない）
持ち越し

  • Tab で補完を確定する（CodeMirror の既定は Enter だけ）
  • Leptos・Dioxus の試験版（<textarea>）
