# S243 `fmu-p5b-size`: P5b の FMU を小さくする

## 1. 目的

S238・S239 の持ち越し。P5b の FMU（Accelerate で 13.5 MB）のうち、cdylib（約 12.8 MB）と `resources/lib`（0.53 MB）を小さくする。決定は [ADR-0031](../../adr/0031-fmi-export-p5a-first.md) の S243 の追記。

## 2. 決定と理由

| 項目 | 決めたこと | 理由 |
| --- | --- | --- |
| cdylib のプロファイル | `opt-level z`・fat LTO・cgu 1・`panic = abort`・strip を、環境変数 `CARGO_PROFILE_RELEASE_*` で facade の `build_runtime` と `fmu-export.yml` から与える。workspace の `[profile.release]` は変えない | `globe` など他の crate の release を遅くしない。`mise run wasm:build` と同じ作り |
| `panic = abort` | 入れる | `extern "C"` の境界を panic が越えると今も abort（Rust 2024）。`catch_unwind` は使っていない。挙動は変わらず unwind の表だけが要らなくなる |
| `opt-level` | s ではなく z | z のほうが 2 MB 小さく、`globe fmu run` は 0.26 s → 0.24 s で遅くならなかった |
| クラス単位の切り出し | `globe-mode-fmt::prune_classes`（`lex` + `class_spans`）。使われない入れ子のクラスを、識別子の名前の一致だけで落とす | Rumoca の名前解決を呼ばずに済み、広めに残す側に倒せる。`operator` のクラスの子と、切り出せないファイルは丸ごと残す |
| 閉包の取り直し | `globe-mode-frontend::library_slice` が、クラスを落としたあとの本文で `library_closure` を取り直す（変わらなくなるまで） | 落としたクラスだけから参照されていたファイルも要らなくなる |
| 依存の整理 | しない | 大半は Rumoca の compile 段（instantiate が resources から compile し直す）。`globe-mode-exec` の積分器は feature が 1 つで、切っても 1 MB 未満 |

### cdylib の大きさ（Linux x86_64、release、strip 後）

| 施策 | 大きさ |
| --- | ---: |
| 既定の release | 33.2 MB |
| LTO fat + cgu 1 | 25.4 MB |
| opt-level s だけ | 27.6 MB |
| opt-level s + LTO fat + cgu 1 | 19.1 MB |
| + panic = abort | 17.1 MB |
| opt-level z（上と同じ他の設定） | 15.1 MB |

### `resources/lib`（Accelerate、FMI 2.0）

| | 前（S238） | 後 |
| --- | ---: | ---: |
| ファイル | 294 | 90 |
| 未圧縮 / zip の中 | 2.37 MB / 590 KB | 393 KB / 131 KB |
| `globe fmu run`（同じ cdylib） | 1.07 s | 0.29 s |
| 最大 RSS | 216 MB | 59 MB |
| FMU 全体 | 13.4 MB | 6.3 MB（cdylib も z） |

### MSL の 20 本（FMI 2.0、FMPy 0.3.32、`--runtime p5b`）

16 / 20 が通った（S237・S238 と同じ）。落ちる 4 本も同じ（ChuaCircuit、DemonstrateSignalExtrema、DiodeBridge2Pulse、DiodeCenterTap2Pulse）。`resources/lib` は 76〜122 ファイル、387〜490 KB（`Thermal.FluidHeatFlow` の 2 本は `Media` のデータで 1.6 MB）。

## 4. 再現手順

```bash
export CARGO_TARGET_DIR=<main>/.git-worktree/target-shared CARGO_BUILD_JOBS=2
cargo build --release -p globe-mode-cli --bin globe
# cdylib（初回 約 6 分）。globe fmu export --runtime p5b が自分で作るときも同じ変数
P=CARGO_PROFILE_RELEASE
env ${P}_OPT_LEVEL=z ${P}_LTO=fat ${P}_CODEGEN_UNITS=1 ${P}_PANIC=abort ${P}_STRIP=true \
  cargo build --release -p globe-mode-fmu-cdylib --lib
target/release/globe fmu export -L data/msl -m Modelica.Mechanics.Translational.Examples.Accelerate \
  --out out --runtime p5b --runtime-lib target/release/libglobe_mode_fmu_cdylib.so
target/release/globe fmu run out/*.fmu --stop-time 1
cargo test -p globe-mode-fmt prune
cargo test -p globe-mode-cli --test fmu_export p5b
```

## 5. 次回

- cdylib をさらに小さくするには Rumoca の compile 段を減らすしかない（上流の話）。`globe-mode-exec` の積分器を feature に分ける案は 1 MB 未満。
- `resources/lib` に残る `Math/Random.mo` など、ファイル全体が必要なものの中の `annotation(Icon…)` は残してある。落とせるが意味を変える危険があるので持ち越し。
- 配布物への cdylib の同梱、host 以外の OS への cross。
