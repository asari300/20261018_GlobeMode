VS Code 拡張

.mo を開くと globe lsp を起動してつなぐだけの小さな拡張

標準の整形キーで GlobeMode の整形器が動き、lint は波線で出る
目的

このセッションでやること

  • 依頼: 標準キーで整形できるように、globe lsp を起動する小さな VS Code 拡張を作る
  • S053 の持ち越し「VS Code 拡張の実体」。P4 の LSP をエディタの外へ出す
  • 計算は増やさない。整形・lint・補完・検査は S053 までの Rust 側をそのまま使う
決定と理由

決めたこと

項目決定理由
クライアントvscode-languageclient 9（MIT）を esbuild で 1 ファイルに束ねるLSP の往復を自分で書かない。VSIX に node_modules を入れない
VSIXpack_vsix.py（Python の標準ライブラリ）@vscode/vsce はライセンス欄の無い署名用バイナリを引き込む
インデント.mo の既定を tabSize 2 にするLSP の整形は tabSize をインデントに使う。VS Code の既定 4 のままだと 4 段になる
動く側extensionKind: workspaceRemote - WSL でも globe と同じ側で起動する
