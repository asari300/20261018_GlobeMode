SSP の往復の続き

.ssp → spec.json の逆変換と、. を含む名前の書き出し

JSON → ssp → JSON が閉じた
逆変換

globe fmu ssp-import

  • system.ssp -o dir/spec.json（--stop-time・--step は cosim と同じ）
  • FMU は .ssp の外の dir/<名前>.fmu に出し、JSON は相対パス。埋め込むより小さい
  • 同名のファイルは上書きせず断る。名前は書く前に検査（..・/ を断る）
名前

s.a はフラットなまま書ける

  • SSD の XSD は要素の name を xs:string（長さ 1 以上）とし、. を禁じない
  • 入れ子に戻すには System のコネクタの素通しを書く必要があり、大きい
  • 限界: 他のツールが階層名と取り違えうる。GlobeMode の往復は取り違えない
試験

CSV がバイトで一致する

  • spec.json → ssp-export → ssp-import: パス以外が同じで、CSV も同じ
  • 入れ子の .ssp → import → export → cosim: 入れ子を直接回した CSV と同じ
