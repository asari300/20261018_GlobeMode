Desktop: Tauri のシェルと sidecar

計算は同梱の globe lsp に任せ、シェルは中継だけ

.deb と .msi を GitHub Actions が artifact に出す
目的

このセッションでやること

  • ADR-0023 の (b) を実装する（計画書の WP-C）
  • src/Rust/apps/desktop に Tauri 2 のシェル。facade はリンクしない
  • globe lsp に独自の要求 3 つ。UI 側は TauriBackend
  • ubuntu-24.04 の .deb と windows-2025 の .msi を Actions で作る
決定と理由

決めたこと

項目決定理由
workspacedesktop は別の workspacewebkit2gtk を手元と差分 CI に持ち込まない
独自の要求globe/check · simulate · graphBackend の操作と 1 対 1
UI と Rustrpc と notify の 2 commandnpm の依存を足さない
予算simulate は 180 s で kill → 作り直し止められない計算を外から止める
UI ビルドvite build だけpnpm build は wasm が無いと落ちる
ライセンスMPL-2.0 の 5 crate を例外に改変せず使う。GPL・NC は 0
