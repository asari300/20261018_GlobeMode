sdirk34hw の GM-E11003 の原因

ThyristorBridge2Pulse_DC_Drive が t = 13.04 で事象の反復が収束しない。S139 の持ち越し

原因は Rumoca の host。GlobeMode 側では直せず、上流の下書き 34 に記録
再現

終了時刻で変わる偶然

実行（release、Tolerance 1e-7）結果
sdirk34hw、0〜15 s57 s で GM-E11003（t = 13.040017098）
sdirk34hw、0〜13.2 s通る（刻みの列が変わる）
esdirk34、0〜15 s通る（CI の run 41666815770）

失敗は 10 ms ごとの事象 1,500 回のうちの 1 回

追跡

根が丸めの雑音になる

  • 事象の時刻で dcpm.la.i = 19.95342803660142 と lMains.i = -19.95342803660142。和が ちょうど 0.0
  • 2 つの根は (+4.1e-30, -4.1e-35)。固定した方式のあとの射影で (-3.3e-34, +3.3e-29) と両方反転
  • host は value == 0.0 の厳密な比べ方なので、上書きが外れて別の方式を固定。周期 2 で 32 回
  • y は回ごとに 1e-29 しか動かない。検出された繰り返しは毎回 Found で、関係式の面の出口に行かない
図

方式が毎回反転する

比べ方が value == 0.0 でなく雑音の範囲なら、上書きが残って収まる

決定

直さずに記録する

  • host の 2 行を abs() <= 1e-24 にすると 15 s まで通る（手元だけ。87,498 行、64.7 s）
  • Rumoca は変えない。プラグインで雑音を整えると全例題の数値が動く
  • v0.10.4 と main（590ac739）も同じ行（確認日 2026-11-05）
  • 記録: 上流の下書き 34 の 4 点、msl-solvers.md の注記、既知の限界の試験 1 本（#[ignore]、116 s）
結果と次回

実行系は変えていない

  • 数値は S139 の run 41666815770 のまま（sdirk34hw 293・管 283 / 292）。wasm:node・wasm:compare・msl-sim.yml は回していない
  • 次回: 下書き 34 を最新の Rumoca で確かめて出す（ユーザー）。直ったら試験を「15 s まで進む」に書き換える
  • 同じ雑音が当たるほかのサイリスタ・ダイオードの回路の数は未調査
