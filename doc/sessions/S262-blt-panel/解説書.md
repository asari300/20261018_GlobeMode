## 1. 目的

S256 で `globe blt`（facade `Workspace::blt` → `BltReport`）ができた。これを UI と Python から見られるようにする（[roadmap](../../roadmap.md) の P8、[features](../../features.md) の BLT の行）。

## 2. 決定と理由

| 項目 | 決定 | 理由 |
| --- | --- | --- |
| LSP | `globe/blt` `{model}` → `BltReport` の JSON。検査が通らなければ -32000 | `globe/parameters` と同じ形。`globe blt --json` と同じ中身 |
| wasm | `Workspace.blt(model)`（`globe blt --json` と同じ JSON）。worker・`client.js` に `blt` | `graph`・`check` と同じ道 |
| Desktop | `RPC_METHODS` に `globe/blt`（28 → 29） | UI が頼む method は一覧と突き合わせる試験がある（ADR-0023） |
| UI | ツールバーの「BLT」ボタンで `BltPanel.svelte` を診断表の下に出す | DocsPanel のタブは S260・S261 も触るので、独立の部品にして衝突を避けた。Graph と同じ置き方 |
| 目立たせ方 | 大きさ 2 以上は警告色の縁・見出し（大きさ・線形か非線形か） | CLI の `globe blt` の見せ方と揃えた |
| Python | `Workspace.blt(model)` → `blocks` の dict のリスト。通らなければ `SourceError`（診断つき） | `report` の `reduced`・`skipped` は落とす（`skipped` のときは空のリスト） |

式をクリックして宣言へ飛ぶのは、`BltBlock` に位置が無いので今回はやらない。
