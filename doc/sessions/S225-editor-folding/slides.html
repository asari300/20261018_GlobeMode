UI（CodeMirror）の折りたたみ

S220 が持ち越した、ブラウザ・Desktop・Android の同じ UI の折りたたみ

範囲は LSP と同じ Rust の関数。UI は印を出すだけ
範囲の道

どこで計算するか

実行環境道
ブラウザ・Androidwasm の folding_ranges(file, text) が globe_mode_lsp::folding を呼ぶ
Desktopsidecar の textDocument/foldingRange（rpc の許可は 20 本目）
UIBackend.foldingRanges(file) が {startLine, endLine} の配列を返す
CodeMirror

foldService と foldGutter

  • foldService は同期なので、範囲は StateField に持つ
  • 入力が 300 ms 止まったら本文を送って取り直す。新しい打鍵が来たら古い応答は捨てる
  • 範囲が届いたら foldGutter の foldingChanged で印を引き直す
  • 畳んでも end M; の行は残る
