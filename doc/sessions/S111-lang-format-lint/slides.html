6 言語に format と lint

S110 の埋める順の 1 と 2。facade に足し、C・NIF・Python と各言語の包みに写した

参照シナリオ（Decay → check → simulate → x(1) → format）が 6 言語で通った
目的

このセッションでやること

  • S110 の機能表で、C・Zig・Julia・Elixir・Gleam・Python に共通して欠けていたのは format だけ
  • facade globe-mode に format / lint を足す（束ねは facade だけに依存する決まりを守る）
  • C ABI・NIF・PyO3 に写し、Zig・Julia・Elixir・Gleam・Python の試験に参照シナリオを 1 本ずつ足す
  • 持ち越し: 列の道（C・NIF）、FMU export の facade、進捗と中断
決定と理由

形は wasm の fmt.rs と同じ

口formatlint
facadeformat(text, indent, insert_origin) -> Result<String, String>lint(text) -> String（JSON の配列）
C ABIgm_format → {"text": …} か {"error": …}gm_lint
Zig・JuliaC を呼ぶ（Julia は load_dir・graph の包みも）同じ
Elixir・GleamNIF の format/3 → {:ok, 本文} か {:error, 理由}NIF の lint/1
Pythonglobe_mode.format（誤りは ValueError）globe_mode.lint → list[dict]

facade は globe-mode-fmt（依存 0 の workspace の crate）に依存するだけ。外部の依存の追加は 0
