## 1. 目的

[roadmap.md](../../roadmap.md) の P8「パラメータダイアログ」の読み取りと実行時の上書き。図の部品を操作するか、実行の設定から、パラメータの一覧（名前・型・既定値・単位・説明）を出し、値を入れると実行の設定の `parameters`（上書き）に乗る。ソースは書き換えず、モデルの保存とは独立。

## 2. 決定と理由

| 項目 | 決定 | 理由 |
| --- | --- | --- |
| 情報源 | frontend のフラット化の結果（`FlatModel.variables` の Parameter）。`CompiledModel::parameters()` を compile のときに作る | 宣言の修飾（`Part c(k = 5)`）が flat の束縛に反映済み。S224 の `enum_type_of` と同じ道。Rumoca の型は `rumoca.rs` の外に出さず、`globe-mode-ir` の `ModelParameter` で渡す |
| 既定値 | リテラルは値（`value`。Boolean は 0/1、Enumeration は 1 始まりの ordinal）、式は字面（`default`）。式の Real / Integer だけ、facade が `tunable_parameters`（lowering）の値を補う | 新しい評価器は書かない。`SimSettings::parameters` は f64 の写像なので、UI の値の尺度と合う |
| 既存の一覧との関係 | 実行の設定の `tunableParameters`（Real の tunable だけ）はそのまま残す。ダイアログは宣言の全体（型つき） | 変更を最小に。2 つの欄は同じ `picked` を共有する |
| 上書きの入れ物 | `SimSettings` の `picked`（名前 → 字面）に入れる。変えた値だけが入り、既定と同じ値に戻せば消える | S228 のモデルごとの保存にそのまま乗る |
| 挙動の変更 | 検査のあとの一覧にない名前を `picked` から消す処理を外した | 一覧は Real だけなので、Boolean / Enumeration の上書きが消えるため。古い名前は実行の GM-E10006 が断る |
| 入口 | 図の部品のダブルクリック・右クリック（部品の名前で絞り込んで開く）、実行の設定の「パラメータ…」（モデル全体）。`App.svelte` は `openParams` の合図 1 つ | 変更を最小に |
| 部品の押せる範囲 | 部品の `<g>` に透明な `path`（枠）を足した | 線だけのアイコン（Capacitor など）は中が押せなかった |
| 誤りの表示 | GM-E10006 の診断のメッセージの中の名前（識別子の一部には当てない）で欄の下に出す | 診断は名前を文中に書く |
| String・配列 | 変えられない（表示だけ） | exec が配列全体の名前を断る。文字列は上書きの尺度（f64）にない |

## 3. 図

```text
図の部品（ダブルクリック）──► App.openParams ──► SimSettings ──► ParameterDialog
実行の設定「パラメータ…」 ─────────────────────────────────────┘      │ backend.parameters(model)
                                                                       ▼
wasm parameters / LSP globe/parameters ─► Workspace::parameters ─► CompiledModel::parameters()
                                                                  （flat の Parameter。式の Real は tunable で補う）
値 ─► picked ─► SimSettings.parameters ─► 実行（exec の param_overrides、S212 の検査）
```

JSON（`globe/parameters`）:

```json
{"model": "Top", "parameters": [
  {"name": "c.k", "type": "Real", "default": "1", "value": 1, "unit": "1/s", "description": "減衰の速さ"},
  {"name": "c.mode", "type": "Enumeration", "default": "Leaf.Mode.slow", "value": 1, "literals": ["slow", "fast"]}
]}
```

## 4. 測定（wasm、Node、MSL 4.1.0）

| モデル | パラメータ | 時間 |
| --- | --- | --- |
| ChuaCircuit | 16 | 33〜94 ms（初回の検査 1.9 s のあと） |
| Fluid.Examples.PumpingSystem | 187 | 約 1.1 s |
| Fluid.Examples.HeatingSystem | 364 | 約 4.7 s |

時間のほとんどは tunable の lowering で、`tunable_parameters` と同じだけかかる。
