パラメータのダイアログ（読み取りと実行時の上書き）

図の部品をダブルクリックすると、その部品のパラメータの表が開く

入れた値は実行の設定に乗る。ソースは書き換えない
Rust

flat モデルから宣言を取る

項目中身
名前comp.k の形（入れ子の部品ごと）
型Real / Integer / Boolean / String / Enumeration（literals つき）
既定値宣言の修飾を反映した束縛か start。リテラルは値（value）、式は字面（default）
そのほかunit・description・min・max・fixed・dims

新しい評価器は書かない。式の Real / Integer だけ、実行系の tunable な値があれば value を補う

口

どこから呼ぶか

  • Workspace::parameters → wasm parameters → Backend.parameters
  • LSP globe/parameters（Desktop の RPC 許可は 25 から 26 本）
  • VS Code への配線は次回（口はある）
UI

表と入力欄

  • ParameterDialog.svelte（<dialog>）。名前・型・値・既定値・単位・説明
  • Real / Integer は数の欄、Boolean はチェック、Enumeration は選択（ordinal）。String と配列は変えられない
  • 変えた値だけが SimSettings の picked に入り、モデルごとの保存（S228）に乗る
  • 入口は図の部品のダブルクリック（右クリックも）と、実行の設定の「パラメータ…」
  • GM-E10006 は欄の近くに出る
測定

時間（wasm、Node）

モデル本数parameters
ChuaCircuit1633〜94 ms
Fluid.PumpingSystem187約 1.1 s
Fluid.HeatingSystem364約 4.7 s

ほとんどは tunable の lowering（tunable_parameters と同じ時間）

試験

cargo test -p globe-mode-frontend --test parameters
cargo test -p globe-mode-wasm --test decay
mise run wasm:node
mise run ui:check     # test_ui.py の parameter_dialog
