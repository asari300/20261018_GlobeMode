## 1. 目的

S280 の `Workspace::stages` が返す `StagesReport` を、Python・LSP・wasm から引けるようにする（[features](../../features.md) の変換デバッガの行）。UI のパネルは別の担当が Svelte を触っているので今回はやらない。

## 2. 決定と理由

| 項目 | 決定 | 理由 |
| --- | --- | --- |
| 形 | S262 の BLT と同じ（JSON をそのまま返す。通らなければ LSP は -32000、Python は `SourceError`、wasm は例外） | 呼ぶ側の作法をそろえる |
| Python の戻り値 | `StagesReport` の dict（`blt` のように中を剥がさない） | 5 つの段がすべて意味を持つ |
| UI | `Backend.stages` を `backend.ts`・`tauri-backend.ts`・`worker-backend.ts` に足し、型 `StagesReport` を `protocol.ts` に足しただけ | Desktop の中継の一覧と UI の method の一致を見る試験があるため。パネルは作らない |

## 3. 図

```text
Workspace::stages ─┬─ LSP globe/stages ── Desktop RPC_METHODS ── TauriBackend.stages
                   ├─ wasm stages ─ worker.js ─ client.js ─ WorkerBackend.stages
                   └─ Python Workspace.stages
```
