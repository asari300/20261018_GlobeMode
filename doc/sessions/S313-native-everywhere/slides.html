native の検査を CLI 以外からも選べる

facade・LSP・Python。既定は Rumoca のまま

frontend を 1 つ選ぶ口
口

3 つの面に、最小の口を 1 つずつ

  • facade: Workspace::check_with(model, CheckFrontend)（check は Rumoca）
  • LSP: globe-mode.toml の [check] frontend = "native" で、診断を自前の段で出す
  • Python: Workspace.check(model, frontend="native")（知らない名前は ValueError）
境界

wasm と UI は今回やらない

  • native は feature。CLI と Python が立て、wasm は立てない（ビルドの大きさを別に測る）
  • 立てない build で選ぶと GM-U0006「この build に入っていない」
  • 未対応の形は Rumoca に切り替えず GM-U0006
