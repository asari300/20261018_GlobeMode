ADR-0026（Proposed）

決めたこと

  • XML は自前（roxmltree）。済み
  • 共有ライブラリは Desktop と CLI の別プロセスの中だけ
  • ME は GlobeMode のソルバ、CS は FMU の積分器

ユーザーが決める

  • 案 A（推奨）: libloading と手書きの C ABI
  • 案 B: fmi 0.8 の Import
  • 外れたら B に切り替える
