決定と理由

決めたこと

項目決定理由
整形器の作り自前（字句解析 → 文の切り出し → 配置）。依存 0上流 tool-fmt は折り返し・並べ替え・空行・origin の補完を持たない
安全装置出力を字句解析し直してトークン列を照合。壊れた入力は触らない整形で意味を変えない保証
補完予約語と Outline の名前だけ新しい解析を入れない（計画書の方針）
ウェブアプリ共通の契約（web-apps.md）。Rust は crate、他は CLI の --json同じ機能を多言語で、エンジンは Rust 側だけ
決定と理由

ユーザーと決めた整形の型

  • インデント 2（4 は明示したときだけ）
  • 80 桁。収まらない Name( と { は開きで改行、閉じは元の段
  • 図形プリミティブの引数は 位置・形状 → points → fill → line の順。グループの境目で改行
  • origin が無ければ origin = {0, 0}（オフにできる）
  • within の後、クラス頭の後、end の前に空行
  • equation / algorithm / クラス直下の annotation( はクラスと同じ段
  • 二項演算子の両側に空白、カンマは後ろだけ、start = 1
  • 行末の空白なし、末尾に改行 1 つ。文字列とコメントは触らない
