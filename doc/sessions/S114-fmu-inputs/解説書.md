## 1. 目的

- [S112](../S112-fmu-outputs/解説書.md) の持ち越しの 1 つ目。最上位に `input Real u` を持つモデルを `ModelInstance` で扱い、FMU では `causality="input"` として `fmi2SetReal` で書けるようにする。
- 同じモデルに `output Real y` を置き、S112 で試験に通っていなかった `ModelStructure/Outputs` を FMPy の validate で確かめる。
- Rumoca は改変しない。代数・離散の変数の書き込み、Enumeration・String、`initial()` の事象、MSL、CS・FMI 3.0・Windows は範囲の外。

## 2. 決定と理由

詳細は [ADR-0032](../../adr/0032-p5b-own-runtime.md) の追記（S114）。

| 項目 | 決定 | 理由 |
| --- | --- | --- |
| 入力の置き場 | パラメータの枠の `SolveLayout::input_parameter_index(name)` に書く | Rumoca の FMI ME の host（`set_float64`）が入力を書く所と同じ。公開の関数なので Rumoca を改変せずに済む |
| lowering の前の値 | 束縛の無い入力の `start` を `SimOptions::initial_inputs`（公開）で渡す | `lower_for_simulation_with_overrides` は駆動されない入力を断る。S094 で呼べなかった `host_driven_input_seeds` と同じ処理を exec の `input_starts` に書いた（20 行ほど） |
| API | `set_input(name, value)`。`variables()` に役割 Input を足す | 値は `visible_values` に入力も入るので `variable_values()` でそのまま読める |
| FMU の変数 | `causality="input"`・`variability="continuous"`・`initial` なし・`start` 必須（初期化の後の値） | FMI 2.0 の表で input は start が要る |
| `InitialUnknowns` | 出力も並べる | FMPy の validate が `Expected {der(x), y}` で落ちた（S112 の `Outputs` は試験に通っていなかった） |
| 作り直し | `fmi2ExitInitializationMode` の作り直しの後に、与えた入力を置き直す | パラメータの変更で `ModelInstance` を作り直すと入力が start に戻るため。初期化そのものは start で解く（`shortcut:`） |
| 試験のモデル | `Simulation/InputDecay`（`der(x) = -x + u`、`y = 2*x`） | 解析解がある。exec の `run` には入力を与える道が無いので解析解と比べる |

## 4. 再現手順

```bash
export CARGO_TARGET_DIR=…/.git-worktree/target-shared CARGO_BUILD_JOBS=2
cargo test -p globe-mode-fmu --test fmpy -- --nocapture
```

- `inputs_and_outputs_through_the_c_abi`: `modelDescription.xml` に u（`causality="input"`、`<Real start="0.0"/>`）と y（`output`、`Outputs`）があり、`fmi2SetReal(u = 3)` で der(x) = 2、`u = -1`・x = 0.5 で y = 1・der(x) = -1.5。出力への書き込みは `fmi2Error`。
- `fmpy_drives_input_step`: FMPy 0.3.32 の ME（CVode）に `input=` で u を t = 0.5 に 0 → 2 の階段で与える。解析解は x(1) = 2 + (e^-0.5 − 2)e^-0.5。

| 変数 | FMPy | 解析解 | 差 |
| --- | --- | --- | --- |
| x(1) | 1.1548180654142353 | 1.1548181217461755 | 5.6e-8 |
| y(1) = 2 x(1) | 2.3096361308284705 | 2.309636243492351 | 1.1e-7 |
| u(1) | 2.0 | 2 | 0 |

- `validate_fmu` は問題なし（`Outputs` と `InitialUnknowns` を含む）。階段は FMPy が時刻事象として扱い、Event Mode に入った回数は 1。
