SSP の入れ子の System と Int32・Boolean を読む

読み取りの持ち越し 2 つ。新しい依存なし

入れ子は 外側.内側 に平らにし、System のコネクタは素通しで 1 本の結線にたどる
読み方

接続の端を節点にして網にまとめる

  • 端は (要素, コネクタ)。startElement を省くと、その System 自身のコネクタ
  • System のコネクタは外側と内側で同じ節点。網ごとに出力 1 本 → 残りの入力
  • 出力が 2 本・FMU の端が 1 つだけ・最上位のシステム自身のコネクタは明確な誤り
  • FMU の名前に . を許し、a.b.x は一番長く合う名前で割る
ParameterBindings

System の binding は階層名で当て、上位が勝つ

置き場名前例（Dahlquist g.a の k）
Componentk3
System ga.k4（Component に勝つ）
最上位g.a.k2（全部に勝つ。x(1) = 0.8^10）

SSP 2.0.1 の 5.2.3。同じ階層では後ろが勝つ

Int32・Boolean・試験

書き出しも読み取りも Int32・Boolean を通す

  • ssc:Real・ssc:Integer・ssc:Boolean で書き、両端の型が違えば書く前に断る
  • 入れ子が平らな版と同じ CSV、System のコネクタを通る接続も同じ CSV
  • Int32・Boolean の ssp-export → cosim がバイトで一致
