## 1. 目的

SSP の読み取りの持ち越しのうち 2 つを足す（[ADR-0026](../../adr/0026-fmi-import-placement.md) の (w)、[調査](../../research/ssp-2026-11-15.md) の 7）。

1. 入れ子の `System`。Component を `外側.内側` に平坦化し、System のコネクタを通る接続を 1 本の結線にたどる。System の `ParameterBindings` も下の Component に効かせる。
2. SSP の Int32・Boolean のコネクタ（S259 でマスターは対応済み。SSP の読み取りと `write_ssp` だけが断っていた）。

## 2. 決定と理由

| 項目 | 決定 | 理由 |
| --- | --- | --- |
| 名前 | Component は階層名 `外側.内側`。FMU の名前に `.` を許し、`<FMU>.<変数>` は一番長く合う名前で割る | 階層名は SSP の 5.2.3 の階層名と同じで、列の名前もそのまま読める |
| System のコネクタ | 接続の端を節点（要素, コネクタ）にして union-find で網にまとめ、System は素通し。網ごとに出力 1 本 → 残りの入力 | 外側の接続と内側の接続が同じ節点で出会うので、鎖の長さに依らない |
| 結線の順 | 入力が SSD に現れた順 | Gauss–Seidel の順に効くので、フラットな SSD は S253 の順のまま |
| 優先 | 階層が違えば上位が勝つ（5.2.3）。深い階層から `start` に入れ、上位が上書き | 仕様どおり。同じ階層は後ろが勝つ（(t) のまま） |
| Int32・Boolean | 読み取りは Integer・Int32・Boolean も受ける。書き出しは Float64・Int32・Boolean を `ssc:Real`・`Integer`・`Boolean` で書き、両端の型が違えば書く前に断る | マスターは同じ型どうしだけ接続できるので、書く側でも揃える |
| 断るまま | 最上位のシステム自身のコネクタ、宙に浮く System のコネクタ、出力が 2 本の網、ほかの型 | 黙って捨てると結線が消える |

## 3. 図

```text
top
├─ a ──(a.x)──▶ g.i        外側の接続: startElement=a, endElement=g
└─ g（System）
   └─ b  ◀── g.i            内側の接続: startElement を省く
→ 網 {a.x, g.i, g.b.u} → 結線 (a.x → g.b.u)
```
