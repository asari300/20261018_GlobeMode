VS Code の側のパネルで部品の移動と結線

S250（移動）と S261（結線）を、拡張のパネルでもできるようにする

ドラッグの処理は1 か所（diagram-drag.ts）、書き換えは Rust、適用は WorkspaceEdit
共有

ドラッグの処理を出した

  • DiagramView.svelte に埋まっていた処理を src/Svelte/src/lib/diagram-drag.ts へ
  • 2 単位の吸着、4 px 未満はクリック、捕まえ先は部品の <g>、.conn から始めたら結線
  • Svelte と webview の両方が同じファイルを読む（shape-svg.ts と同じ置き方。写しは無い）
  • svg の API だけを呼ぶので、node の試験に偽の svg を渡せる
流れ

webview から文書まで

場所すること
webviewドラッグ中は見た目だけ動かし、離したら move / connect を postMessage
拡張（edit.js）型と値を検査（通らなければ捨てる）。file と class は webview の言い分を使わない
拡張（panel.js）globe/movePart・globe/addConnect を呼び、TextEdit を WorkspaceEdit で入れる（undo 1 回、保存しない）
webviewedited の ok を待ち、失敗なら見た目を戻す
拡張文書が変わると既存の 300 ms 後の再取得が図を引き直す
安全

webview は信頼の境界の外

  • 名前は \w+、端は 名前.名前、数は有限で 1e6 以下、点は 64 個まで
  • LSP の応答を待つあいだに文書の版が変わったら入れない
  • CSP（default-src 'none'、script は nonce）と innerHTML 不使用は変えない
