モデルをフラットな変数と方程式にする（B3 の最初の一切れ）

新しい crate globe-mode-flat（依存は globe-mode-syntax と globe-mode-resolve）

GlobeModeValidation の 70 本で、Rumoca の flat と変数の名前・方程式の数が全部一致
作り

クラスをインスタンス化する

  • Project は resolve の Library と、クラスごとの CST、全参照の解決表を持つ。resolve の中は変えていない
  • extends を取り込みながら宣言と節を集め、修飾は外側が勝つ。式は書いた場所の前置きで名前を付け替える
  • 評価するのは大きさ・for の範囲・添字だけ。if・when・関数の呼び出しは式のまま印字する
connect

potential は等式、flow は和が 0

  • インスタンスごとに集合を作る。内側のコネクタは +、外側は -
  • つなげなかった内側のコネクタの flow は 0。最上位のモデル自身のコネクタの flow も 0
  • for の中の connect は展開して数える。stream は断る
