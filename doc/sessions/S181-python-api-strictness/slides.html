決定

キーの一覧は Rust から取る

  • SimSettings に deny_unknown_fields は付けない（wasm・C ABI・NIF・CLI も使う型。挙動を変えない）
  • py の crate が SimSettings を全部埋めた見本 JSON を返す。項目を足すとコンパイルが落ち、Python の一覧は見本から作る
  • Settings（TypedDict、IDE の補完）との一致は試験が見る
  • export_fmu の options は明示のキーワード引数にして、未知は Python 自身の TypeError
  • facade は SimSettings を再公開しただけ（1 語）
docstring と型

help() で読め、IDE が補う

  • 公開の関数・メソッドすべてに、引数・戻り値・例・誤りの docstring
  • py.typed と _native.pyi（wheel に入る。maturin は python-source の全ファイルを入れる）。結果は dict[str, Any]、TypedDict は設定と進捗だけ
  • on_progress は既定のソルバ（bdf・auto・dopri45）では積分の中に届かないと明記。積分より前の段で True なら次の段に入る前に止まる（ok: False）
  • README と main() の古い文面（uv_build・cargo run -p globe-mode-cli）を直し、README の例は試験で実行
