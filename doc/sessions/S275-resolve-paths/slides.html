続き

a.b.c は部品の型の中へ

  • 先頭が部品なら、その型（constrainedby があれば先）の中で次の名前を探す。受け継ぎも含む。添字は無視
  • 型が組み込み（Real・type V = Real）なら、続きは属性（x.start）で Builtin
  • resolve は続きまで、resolve_head は先頭まで（S272 と同じ）
redeclare

その場の型に置き換える（1 段）

  • redeclare package M = X [constrainedby Y] を extends・部品・short class の修飾から読む
  • 探索でその場の M を X に置き換える。replaceable の既定の型と constrainedby も候補
  • 2 段以上先、部品の再宣言、長い形は Reason::Redeclare のまま
