## 1. 目的

S292 の後に main に入った機能（S284、S290〜S302）のうち利用者に見えるものを、[README.md](../../../README.md)（日本語と英語の要約）と [CHANGELOG.md](../../../CHANGELOG.md) に反映する。正典は [features.md](../../features.md) と [roadmap.md](../../roadmap.md)（各セッションが更新済みなので触らない）。

## 2. 決定と理由

| 項目 | 決定 | 理由 |
| --- | --- | --- |
| 対象 | `origin/main` に入ったものだけ | S297・S301・S303 は main に無い |
| Track B | 利用者向けには「定義ジャンプとホバーが読めない文書で答える」（S296）の 1 項目。flat 拡張・DAE は CHANGELOG と「できていないもの」だけ | `globe-mode-flat`・`globe-mode-dae` は検査にも実行にもつながっていない |
| 開発者向け | `mise run msl:diff-frontend`（S300）は README の開発の節と CHANGELOG の Track B だけ | 利用者の機能ではない |
| 古い記述 | 「stages の UI」「VS Code の削除」「結線の点の編集」「固有値の UI」「SSP の入れ子・Int32・Boolean」が未、という記述を直した | S291・S293・S299・S302・S295 で済んだ |
