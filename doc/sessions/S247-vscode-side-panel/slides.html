どこで何をするか

場所役割
panel.js（拡張ホスト）カーソルが 300 ms 止まったら globe/documentation・icon・diagram を Promise.all で引き、webview へ渡す。部品のクリックで宣言の行へ
webview.js（webview）届いた形のデータを DOM にする。dist/webview.js に束ねる
Svelte/src/lib/shape-svg.tsアイコンと図を SVG の要素の木にする純粋な関数（新）。toDom で DOM に
Svelte/src/lib/html-sanitize.ts説明の HTML の白リスト。変更なし
共有

写しは作らない

  • 置き場は src/Svelte/src/lib/ のまま。webview.js が相対パスで import し、esbuild が束ねる
  • Svelte の側は SvgTree.svelte が同じ木を要素として描く（見た目と DOM の形は変えない）
  • VSIX には束ねた結果だけが入る。vscode.yml の paths に 2 ファイルを足した
安全

CSP と無害化

default-src 'none';
style-src ${cspSource} 'unsafe-inline';
script-src 'nonce-…'
  • innerHTML は使わない（試験が grep する）
  • 説明は webview の中で sanitize（DOMParser）→ 要素と文字で描く
