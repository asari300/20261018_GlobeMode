## 1. 目的

S232（説明）・S244（アイコン）・S245（図）は Svelte の UI にだけあった。VS Code の拡張にも同じ「アイコン / 図 / 説明」の側のパネルを足す。`globe lsp` の `globe/documentation`・`globe/icon`・`globe/diagram` をそのまま使い、拡張に業務ロジックは置かない（LSP は変えない）。

## 2. 決定と理由

| 項目 | 決定 | 理由 |
| --- | --- | --- |
| 面 | エクスプローラーの `WebviewViewProvider`「GlobeMode」1 つ。上からアイコン、図、説明 | UI の右のパネルと同じ並び。補助サイドバーは利用者が動かせる |
| 引く時機 | 選択・エディタ・本文の変化から 300 ms 止まったら 3 つを `Promise.all`。新しい要求が来たら古い応答は捨てる。`.mo` 以外のエディタでは更新しない | UI の `modelicaDocs` と同じ |
| 共有の置き場 | `src/Svelte/src/lib/` のまま。拡張の `webview.js` が相対パスで import し、esbuild が `dist/webview.js` に束ねる | 写しを作らない。ファイルを動かす案は得るものが無い。VSIX は束ねた結果だけを入れるので `src/Svelte` に依存しない |
| 無害化 | `html-sanitize.ts`（変更なし）を webview の中で使う | 拡張ホスト（node）には DOMParser が無い。洗った木は `createElement` と文字で描く |
| SVG | 新しい `shape-svg.ts`（`shapeNode`・`iconNodes`・`diagramNodes`・`toDom`）。旧 `ShapeView.svelte` と `DiagramView.svelte` の部品の組み立てを、要素の木を返す純粋な関数に切り出した | Svelte 部品に依存できない webview でも同じ描き方を使うため。Svelte の側は `SvgTree.svelte`（`<svelte:element>`）で木を描く。見た目と DOM の形（`g[data-part]`・`[data-conn]`・`data-line`）は変えない |
| クリック | `data-line` を持つ部品の `<g>` を svg の上で一括して受ける（Svelte も webview も同じ）。webview は `reveal` を postMessage、拡張ホストが `showTextDocument` で宣言の行へ | Svelte では部品ごとの onclick をやめて 1 つにした |
| CSP | `default-src 'none'; style-src ${cspSource} 'unsafe-inline'; script-src 'nonce-…'`。`innerHTML` は使わない | 外への通信もスクリプトの注入も許さない。試験が両ファイルを grep する |
| e2e の見え方 | webview の DOM は拡張ホストから見えないので、webview が描き終えた数を postMessage で返し、`activate` が返す `panel.state` を読む | 本物の VS Code でビューが開き、図に部品が 7 個出ることを確かめる |

## 3. 図

```text
エディタ（.mo）─ 300 ms ─► panel.js ─ Promise.all ─► globe/documentation · globe/icon · globe/diagram
                              │ postMessage {doc, icon, diagram}
                              ▼
                        webview.js ─► sanitize（html-sanitize.ts）─► 説明
                                  └─► iconNodes / diagramNodes → toDom（shape-svg.ts）─► アイコン・図
                              │ 部品のクリック → postMessage {reveal, line}
                              ▼
                        panel.js ─► showTextDocument（宣言の行へ）

Svelte の UI: IconView / DiagramView ─► shape-svg.ts ─► SvgTree.svelte（同じ木を要素として描く）
```

## 4. 再現手順

```bash
cd src/VSCode/globe-mode
mise exec -- pnpm install --frozen-lockfile
mise exec -- pnpm build            # dist/extension.js と dist/webview.js
GLOBE_BIN=…/target/release/globe mise exec -- pnpm test   # test/panel.test.mjs ほか
cd ../../Svelte && mise exec -- pnpm check                 # 0 エラー 0 警告
mise run ui:check                  # test_ui.py の icon_view・diagram_view（Svelte の見た目を変えていないこと）
gh workflow run vscode.yml --ref feature/s247-vscode-side-panel   # 3 OS の e2e
```
