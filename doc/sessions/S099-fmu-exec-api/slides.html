目的

このセッションでやること

  • S095 の持ち越しの 1 つ目: exec に「状態・パラメータ・時刻 → 微分」の公開 API
  • それで globe-mode-fmu の der(x) = -k*x の手書きを置き換える
  • 既存の simulate / run / session の道は変えない（追加だけ）
  • globe-mode-fmi・CLI・P5a の export は触らない（S098 が並行）
決定と理由

host でなく SolveRuntime を包んだ

候補判定理由
FMI ME 風の host（SolveMeKernel）使えないset time / states / derivatives は pub(crate)
積分器の MeDerivativeHandle使えないhost の呼び出しの間しか評価できない
SolveRuntime（公開）採用host と同じ部品。eval_state_derivatives と settle_initialization_system がある
  • 事象（根の条件・sample）のあるモデルは GM-U0004 で断る
決定と理由

載せ替えは道 2（実行時に compile）

道（ADR-0032 の (b)）判定理由
1. FMU ごとにビルド持ち越し利用者にツールチェーンが要る
2. resources の Modelica を compile採用exec の API がそのまま使え、最小で確かめられる
3. Solve IR の解釈実行持ち越し直列化の形を決める仕事が大きい
  • パラメータは fmi2ExitInitializationMode で lowering からやり直して反映
  • modelDescription.xml は手書きをやめて生成。guid はモデル名と文面の FNV-1a
