CLI の走査と VS Code のキー

ユーザーが試して見つけた 3 つの使いにくさを直した

globe fmt は ruff のように辿り、VS Code は Shift+Alt+F で整形する
目的

このセッションでやること

  • web-apps.md に起動コマンドの一覧（Phoenix の初回の mix deps.get で詰まった）
  • VS Code: Ctrl+Shift+I がエージェントの窓を開く。Shift+Alt+F で整形し、保存時の整形を設定で選べるように
  • 拡張が見えない: プロファイルの窓に入っていなかった
  • CLI: ディレクトリを ruff のように辿る
決定と理由

決めたこと

項目決定理由
パスを省く端末ならカレントディレクトリ、パイプか --json なら標準入力ruff と同じ操作性。ウェブアプリ 10 種の呼び方は変えない
除外.gitignore と隠しディレクトリ（crate ignore）data/msl などを誤って整形しない。ruff と同じ crate
壊れたファイル続けて、最後に要約と終了コード 21 本で全体が止まらない
VS CodeShift+Alt+F を .mo に割り当て、formatOnSave は既定オフユーザーの指定。Linux でも同じキー
