FMI 3.0 Scheduled Execution の Export

クロックの無い連続モデルを、周期 Clock 1 つ・パーティション 1 つの FMU にする

globe fmu export --runtime p5b --fmi-version 3 --kind se
調査

仕様と検査の道具

問い答え
Clock は要るか要る。入力 Clock ごとに 1 パーティション。priority は SE で必須
連続モデルは出せるか周期 Clock 1 つで出せる。FMU の中で積分することを仕様が認めるかは【未確認】
Rumoca（P5a）テンプレートに SE が無い。P5b で出す
fmusimv0.15.0・v0.16.0 とも ME・CS だけ。SE は回せない
FMPy 0.3.32simulate_fmu は SE 非対応。低水準の FMU3ScheduledExecution は使える
実装

形

  • modelDescription.xml: ScheduledExecution と周期の Clock（値参照は time の次）
  • fmi3InstantiateScheduledExecution: CS と同じ instance
  • fmi3ActivateModelPartition(clock, t): 前の時刻から t まで CS の do_step（RK4・時刻事象・状態事象）
  • 時間が戻る・Clock が違う・terminate() は fmi3Error
  • facade の FmuOptions.kind、CLI の --kind se。2.0・p5a は断る
