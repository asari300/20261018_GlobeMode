release.yml に macOS（arm64）を足した

globe の tar.gz、Python の wheel、Desktop の .dmg。署名・公証はしない

dry run（run 42048206686）で全ジョブ success。タグも Release も 0 件のまま
目的

このセッションでやること

  • S160 の持ち越し。release.yml には Linux 2 つと Windows しか無かった
  • build と desktop の matrix に macos-latest を 1 行ずつ足す
  • やらない: 署名・公証・鍵、x86_64 の macOS、タグ、Release、desktop.yml
決定と理由

決めたこと

項目決定理由
Rust と uvrustup、uv は misemacOS の python3 は pip install できない
wheelmaturin の既定の tagmacosx_11_0_arm64 が付いた
版の置換sed を perl にBSD sed は 0,/re/ が使えない
ライセンス表about.toml に darwin を足すmacOS だけの crate の漏れを防ぐ
dmg--bundles app,dmgS160 と同じ。署名なし
updater.app.tar.gz を dmg/ に移すlatest.json に darwin-aarch64。鍵があるときだけ

試走で見つけたこと

2 回の失敗と直し

  • 1 回目: コミット前に dispatch し、main と同じ workflow が動いた。cancel して出し直した
  • 2 回目: success だったが、desktop の artifact に dmg/ などの階層が付き、SHA256SUMS から GlobeMode_* が漏れた
  • 原因は upload の path に bundle/macos を足したこと。.app.tar.gz を dmg/ に移して直した
  • sha256sum のエラーは tee に隠れて step が success になる。中身を見て気づいた
