## 1. 目的

[roadmap.md](../../roadmap.md) の P8「Diagram ビュー」の編集の 4 つ目。図の上で部品と結線を消せるようにする。S250（移動）・S261（結線の追加）・S265（部品の追加）と同じく、テキストの編集を Rust が返し、UI がエディタに 1 回の dispatch で入れる（undo 可、保存しない）。

## 2. 決定と理由

| 項目 | 決定 | 理由 |
| --- | --- | --- |
| 部品を消す範囲 | 宣言と、クラス直下の `connect` のうち端の最初の名前がその部品のもの | 宣言だけ消すと結線が未定義の部品を指し、検査が誤りになる |
| 複数の名前の宣言 | 断る（null） | `A a, b annotation(…)` の `annotation` がどちらのものか曖昧。名前だけ外す編集は入れない |
| 行の消し方 | 文が行に 1 つだけなら字下げと行末の改行ごと、他の文が同じ行にあれば要素と後ろの空白だけ | 空行・字下げを壊さない |
| 結線の指し方 | `Connection` の `from`・`to`（添字は落ちた字句）、逆の並びも同じ。同じ端が複数あれば全部 | UI は `globe/diagram` の値しか持たない。配列のコネクタの結線の選び分けは持ち越し |
| 選び | クリックと Tab（フォーカス）で選び、枠か太線で示す | キーボードだけの人も使える（部品は元から `tabindex 0`、結線は透明な太い線に `tabindex 0`） |
| 当たり判定 | 結線と同じ点の透明な太い線（`stroke-width` 10、非拡大）を `[data-conn]` の外に置く | 数 px の近くで押せる。`[data-conn] polyline` の数を変えない（既存の試験） |
| キー | svg の中の Delete / Backspace だけ。部品のクリックで宣言へ飛んだ後、フォーカスを選んだ対象へ戻す | 飛ぶとエディタにフォーカスが移り、Delete がエディタの文字を消してしまうため |
| 口 | LSP `globe/deletePart`・`globe/deleteConnect`（`RPC_METHODS` 31 → 33）、wasm、`Backend` | S250・S261・S265 と同じ形（TextEdit の配列、保存しない） |

## 3. 図

```text
Delete（部品 r1 を選択中）
  → backend.deletePart(diagram.class, "r1")    … Rust: [宣言の行, connect の行, …] の削除範囲
  → view.dispatch(changes)                     … 1 回（Ctrl+Z で戻る）
  → 図が読み直され、選びは外れる
```
