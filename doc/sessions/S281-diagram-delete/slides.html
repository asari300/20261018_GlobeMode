Diagram ビューの編集: 削除

部品か結線を選んで Delete。部品を消すとつながる結線も一緒に消える

範囲を決めるのはRust（delete_part・delete_connect）、UI は 1 回の dispatch で入れる
Rust

消す範囲

操作消すもの
delete_part部品の宣言と、端の最初の名前がその部品の connect（複数の編集）
delete_connectその connect の文全体（annotation・同じ行のコメントを含む）

文が行に 1 つだけなら字下げと改行ごと、他の文があればその要素だけ

断るもの

断る場合

  • 宣言が A a, b; のように複数の名前を持つ（annotation の帰属が曖昧）
  • Placement が無い宣言（図に出ない）・クラスや部品が無い
  • if の中の connect は数えない
UI

選ぶ・消す

  • クリックか Tab で選ぶ（部品は青い破線の枠、結線は青い太線）
  • 結線の当たり判定は線の近く 5 px（透明の太い線）
  • Delete / Backspace は図の中でだけ受ける。クリックで宣言へ飛んだ後、フォーカスを選んだ対象へ戻す
