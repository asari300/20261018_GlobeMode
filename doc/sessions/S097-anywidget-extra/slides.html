anywidget を extra に戻す

S078 で通常の依存にした anywidget を extra widget に移した

pip install globe-mode の依存は 49 → 30（ロック上、全 OS）
目的

このセッションでやること

  • S078 は CI と release の pytest が extra を入れないので、anywidget を通常の依存にした
  • 代償は wheel を入れる人全員に ipython など 18 本が付くこと
  • ユーザーの判断（2026-11-02）: extra に戻し、CI の側で extra を入れる
決定と理由

決めたこと

項目決定理由
pyprojectwidget = ["anywidget>=0.11.0"]使うのは globe_mode.widget だけ
ci.yml pythonuv sync --locked --extra widget--all-extras と同じ大きさで、何を入れるかが読める
release の pytest--with "globe-mode[widget] @ wheel/…"wheel の METADATA の extra が効くことを確かめる
test_widget.pypytest.importorskip("anywidget")extra なしの uv sync --locked（mise run check）でも通る
widget.pyimport は遅延しない。無ければ ImportError に入れ方を添える使う人に直し方を見せる
