SSP の start を .ssv に書く

globe fmu ssp-export --ssv。既定はインラインのまま

読み戻すとインラインと同じ
書き方

Component ごとに 1 ファイル

  • resources/<名前>.ssv に ssv:ParameterSet、SSD は ParameterBinding source で参照
  • 型（Real・Integer・Boolean）は FMU の変数から。start の無い Component には作らない
  • 名前の escape と値の検査はインライン版と同じコード
XSD で確認

型の要素は ssv の名前空間

  • 仕様のリポジトリの v2.0.1 の XSD は elementFormDefault="qualified"
  • Boolean の字句は xs:boolean（true・false・1・0）
  • S263・S295 の【未確認】を解消
試験

CSV がバイトで一致する

  • --ssv の .ssp を cosim で回した CSV は JSON 直の CSV と同じ
  • .ssv の名前空間と ssv:Real・ssv:Integer・ssv:Boolean を確かめる
