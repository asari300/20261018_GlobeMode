決定と理由

#43: 型付きの道を別のスレッドで回して即返す

  • 型付きの道は Rumoca の積分が 1 歩ごとにトークンを見ない。調和振動子で bdf は 0.3 s に立てても 129 s 走った。
  • 第 1 案「トークンがあれば session の道」は、EngineV6 の bdf が型付き 202 s で完走するのに予算で時間切れになり、取り消した。
  • 採用: トークンがあれば別のスレッドで回し、立ったらすぐ GM-I11004 で返す。スレッドは放置して結果を捨てる。
  • 挙動が変わる: 止めた時刻までの途中経過は返らない。裏の計算は予算まで続く。
決定と理由

#67: FAKE が緩いと欠陥が隠れる

  • Desktop の保存は fs プラグイン。許可は dialog で選んだパスだけに与えられる。
  • 試験の偽物はどのパスも受けたので、最近使ったファイルの保存が失敗するのが見えなかった。偽物を本物と同じに厳しくしてから直した。
  • 書くのは Rust の write_recent（.mo、親のフォルダがある、ディレクトリでない、だけ）。
