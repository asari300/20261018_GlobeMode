S067 · 2026-11-01 · P3

公開ライブラリを MSL 4.0.0 で回す

S063 の持ち越し「MSL の版の差の数」を測った

判定の差は 2,132 本中 1 本。実行は -76 本（external "builtin"）
目的

版の差は失敗に混ざっているか

  • 公開ライブラリ 7 つは MSL 4.1.0 と一緒に読んで検査してきた
  • AixLib・ClaRa・DeltaRobot・Chemical の uses は MSL 4.0.0
  • S063 の失敗 1,781 本の分類に、版の差が混ざっていないかが分からなかった
  • 4.0.0 でも同じ検査を回せるようにして、本数の差を測る
決定と理由

uses の MSL

MSL の版ライブラリ
4.1.0Buildings・IBPSA・ThermofluidStream
4.0.0AixLib・ClaRa（TILMedia）・DeltaRobot・Chemical

どちらの版を前提にするライブラリも、もう一方の版で読んでみる。

決定と理由

最小の変更

  • fetch-msl --version 4.0.0（既定 4.1.0）。sha256 は取得して計算した値
  • 別の版が展開済みの --dest には重ねず断る（2 つの Modelica が読まれるため）
  • libraries.yml に入力 msl、キャッシュのキーに版を入れる
  • libraries-report --msl が表の見出しに版を書く
  • artifact 名・doc/libraries.md（4.1.0）はそのまま

原因

external "builtin"

MSL 4.0.0
Math/package.mo の 13 か所が external "builtin" y = log(u);
MSL 4.1.0
同じ関数が algorithm y := .log(u);（external "builtin" は 0 か所）

実行系が builtin の外部関数を解けず GM-U0004。75 本のうち 70 本（sin 28・exp 27・log 10・cos 4・asin 1）。残り 5 本は Solve IR の契約。

gh workflow run libraries.yml -f msl=4.0.0
