## 1. 目的

[S222](../S222-ui-open-results/解説書.md)（結果を開く）と [S229](../S229-fmu-import-facade/解説書.md)（FMU を開く）が次回に持ち越した、ブラウザ・Desktop・Android 共通の Svelte の 4 点を仕上げる。

## 2. 決定と理由

| 項目 | 決定 | 理由 |
| --- | --- | --- |
| 結果のタブの復元 | 自動保存（`globe-mode.tabs`）に結果のファイルの `path` を載せ、Desktop は起動で `Backend.readResultsAt(path)`（`globe/readResults`）から読み直す。読めなければタブを閉じて理由を出す。ブラウザは閉じる旨を注に書く | 列（数 MB）を localStorage に入れない。ブラウザの File API にパスは無い。結果のタブだけで始まらないよう、タブが無ければ Decay を足す |
| FMU の結果 | 復元しない（path を持たない） | 再読み込みでネイティブコードを黙って回し直さない |
| パラメータ | Rust の `OpenedResults` が `data_1` のパラメータを持ち（以前は捨てていた）、`globe/readResults` と wasm の `read_results` が `parameters` を返す。UI は `ResultColumns.parameters`（`Columns` の型は変えない）から折りたたみの表 | 読む本体（`mat::read_results_bytes`）はもう返していた。応答に乗せるだけ |
| 最近使ったファイル | Desktop だけ `.mat`・`.csv`・`.fmu` も入れる。選ぶと結果は `readResultsAt`、`.fmu` は設定フォーム | 結果と FMU は sidecar が path を読むので、`read_recent`・`write_recent`（`.mo` だけ）は広げない。Rust の Desktop は触っていない |
| FMU の設定 | `lib/FmuForm.svelte`。警告と要約を残し、終了時刻・刻み・予算（秒。`timeout`）・種類（CS / ME。FMU が持つものだけ）。空の欄は送らない。FMU のパスごとに localStorage `globe-mode.fmu`（新しい順、上限 50） | S229 の `confirm` の置き換え。S228 の実行の設定と同じ「パスごとの保存」。`Backend.runFmu(path, request, onProgress)` |
| 出さないもの | ME の積分器の選択、出力の選択、パラメータの上書き | 範囲を絞った（次回） |
