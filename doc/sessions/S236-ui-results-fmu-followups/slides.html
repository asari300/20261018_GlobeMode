UI の結果と FMU の仕上げ 4 点

S222 と S229 が持ち越した、結果のタブと FMU の使い心地

新しい部品は設定フォーム 1 つ。あとは既存の道に乗せた
1 再読み込み

結果のタブは Desktop だけ戻る

  • 自動保存（300 ms のまとめ書き）に結果のファイルのパスを載せる。列は載せない
  • 起動で globe/readResults {path} を呼び直す。読めなければタブを閉じて理由を出す
  • ブラウザはパスが無いので閉じる。結果のタブの注に書く
  • FMU の結果は戻さない（ネイティブコードを黙って回し直さない）
2 パラメータ

MAT のパラメータを折りたたみの表に

  • Rust の OpenedResults が data_1 のパラメータを持つ（これまでは捨てていた）
  • LSP の応答と wasm の read_results に parameters を足した
  • 結果のタブに名前・値・単位・説明。CSV と FMU の結果は空で、表を出さない
3 最近

最近使ったファイルに結果と .fmu

面入るか理由
Desktop.mat・.csv・.fmu も入る読むのは sidecar。read_recent を広げずに済んだ
ブラウザ入らないパスが無い（本文を持つのは .mo だけ）
4 FMU の設定

確認ダイアログを設定フォームに

  • 警告と要約は残し、終了時刻・刻み・予算（秒）・種類 CS / ME を入れて「実行」
  • 空の欄は送らない。数でない欄は実行できず理由が出る。Esc でやめる
  • FMU のパスごとに localStorage へ残す（S228 の実行の設定と同じ作り）
  • ME の積分器の選択は出していない
