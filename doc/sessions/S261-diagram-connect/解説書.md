## 1. 目的

[roadmap.md](../../roadmap.md) の P8「Diagram ビュー」の編集の 2 つ目。部品のコネクタからドラッグして別の部品のコネクタで離したら、クラスに `connect(a.p, b.n) annotation(Line(...));` を足すテキスト編集を Rust が返し、UI がエディタに入れる（S250 の部品の移動と同じ道）。

## 2. 決定と理由

| 項目 | 決定 | 理由 |
| --- | --- | --- |
| 足す場所 | 最後の `equation` 節の末尾（クラスの `annotation` の前）。無ければ `annotation`（無ければ `end`）の行の前に節ごと | Modelica の文法でクラスの `annotation` は節の後ろ。`initial equation`・`algorithm` は数えない |
| 字下げ | 既存の文の字下げ。節ごと足すときは `equation` が `end` の字下げ、文が最初の宣言の字下げ | 周りの書き方に合わせる（整形は別の仕事） |
| 端の文字 | 英数字・`_`・`.`・`[]` だけ | ソースに入る文字列なので、UI から来た値でも信用しない |
| 線 | 両端のコネクタの位置の 2 点 + `color = {0, 0, 255}` | `Line(points)` が無いと中心どうしの直線になり、部品に重なる |
| コネクタの位置 | `Part.connectors` を足した（S245 の図は部品の中のコネクタを出していなかった） | 部品のクラスと `extends` の 2 段まで。`iconTransformation`（無ければ `transformation`）の extent の中心 |
| コネクタの見分け | `iconTransformation` が無い宣言は型を引いて `connector` 以外と分かれば除く。引けなければ残す | `LimPID` の中の `Gain` などを除くため。字句解析はせず字面を探すだけ（大きなファイルを何度も読むので） |
| 型の互換 | 今回は見ない | 足したあとの検査（`globe check`、lint `connect-type-mismatch`）が誤りを出す。Ctrl+Z で戻せる |
| 口 | LSP `globe/addConnect`（`RPC_METHODS` 27 → 28）、wasm `add_connect`、`Backend.addConnect` | S250 の `movePart` と同じ形（TextEdit の配列、保存しない） |
| UI | コネクタの透明な円から始めたドラッグは結線。同じコネクタ・コネクタ以外で離したら何もしない | 部品の移動・クリック（宣言へ）・ダブルクリック（パラメータ）と衝突させない |

## 3. 図

```text
pointerdown(.conn) → pointermove(仮の線) → pointerup(別の .conn の上)
  → backend.addConnect(diagram.class, "a.p", "b.n", [[x1, y1], [x2, y2]])   … Rust: connect の挿入編集
  → view.dispatch(changes)                                                  … エディタが変わる（Ctrl+Z で戻る）
  → 図が読み直され、新しい結線が出る
```
