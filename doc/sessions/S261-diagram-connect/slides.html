コネクタの位置

部品のコネクタ（Part.connectors）

  • 部品のクラスと extends の 2 段までの、Placement を持つ宣言
  • iconTransformation があればそれ、無ければ transformation の extent の中心
  • 型が引けて connector でなければ除く（引けなければ残す）
  • MSL で Capacitor・LimPID・Inertia の位置を確かめた
UI

ドラッグ

  • 各コネクタに透明な円（ホバーで色）。そこから始めると部品の移動でなく結線
  • 仮の線を描き、別のコネクタの上で離したら確定。同じコネクタ・コネクタ以外なら何もしない
  • 型の互換は見ない。足したあとの検査が誤りを出す
