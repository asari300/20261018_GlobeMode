wasm

口は 1 つだけ足した

  • Workspace.check_with(model, frontend): "rumoca"・"native"。知らない名前は例外。check(model) はそのまま
  • Worker の check({model, frontend})、GlobeWorker.check(model, frontend?)。省くと Rumoca
  • facade の CheckFrontend と check_with をそのまま呼ぶだけ（wasm に判断は置かない）
UI

select 1 つと要約 1 行

  • select 検査のフロントエンド（Rumoca / 自前（試験））。Backend.checkFrontends を持つ実行環境だけ（ブラウザ・Android）
  • 自前で検査すると Rust の要約（「S0〜S6 を通過。S7 以降は検査していない」）を 1 行出す。GM-U0006 の原文の見出しは「自前の段の原文」

  • wasm（Node）: check_with(Decay, "native") が通って要約に「native: S0〜S6」、rumoca は check と同じ、知らない名前は例外。Worker 越しにも届く
  • UI（Playwright）: 選択肢と既定、自前で Decay が通って要約、expandable が GM-U0006、Desktop に選択肢が無い
