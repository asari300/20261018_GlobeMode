書きかけでも r. の後ろにメンバーが出る

LSP の補完を、自前の寛容な構文と名前解決につなぐ最初の一切れ

今の道で空のときだけ足す。読める文書の出力は変えない
なぜ

今の道が出せなかった所

  • 今の道は、カーソルの行を空白にして読み直した Outline で型を引く
  • ほかの行にも誤りがある・end の前で切れた文書は読めず、候補が空になる
  • 自前の構文（globe-mode-syntax）は誤りがあっても木を返す
しくみ

書きかけの文書を 1 本だけ足して引く

  • ライブラリの Library は最初に 1 回だけ作って Server が持つ
  • 補完のたびに with_source で文書を足し、class_at → members_of で引いて、元に戻す
  • 部品は型の部品とクラス（受け継ぎを含む、protected は除く）
