LSP の定義ジャンプと参照

features.md の「定義ジャンプ・参照は未着手」を埋める

型・部品名・R1.p から、文書の中でもライブラリの別ファイルでも定義へ飛べる
目的

このセッションでやること

  • textDocument/definition: 部品の型、部品名、点つきの名前、extends の先、import を解決して Location を返す
  • textDocument/references: 同じ文書・同じクラスの中で字句が同じ位置
  • initialize で宣言するだけで VS Code 拡張（S059）が使える
  • ブラウザ UI（CodeMirror）との接続、リネームは持ち越し
決定と理由

引き方

項目決定理由
土台既存の Outline だけ補完（S053）と同じ。新しい解析器は入れない
名前点つきの名前の頭から、カーソルの区切りまでModelica.Electrical の途中ならパッケージへ
部品名内側のクラスから外へ。extends の先も（深さ 8 まで）R1.p の p は親クラスの部品
型名入れ子、import、外側の順ClassIndex::resolve と同じ順（MLS 5.3.1）
ライブラリLibraryTree でファイルを決め、要るファイルだけ読むMSL 全部を先に解析しない
