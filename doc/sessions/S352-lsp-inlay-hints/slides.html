LSP の inlay hint（最小版）

機能の穴「アウトライン・inlay hint・call hierarchy」のうち inlay hint

f(x, y) が f(a: x, b: y) に見える
仕様

出すのは 1 種類だけ

  • textDocument/inlayHint（capability inlayHintProvider）。range の内側だけ返す
  • 関数の呼び出しの位置引数の前に、引数の名前（kind = Parameter）
  • 名前は呼び先の関数の input の並び（extends の基底が先）。引けなければ出さない
  • 書きかけの文書でも出る（自前の構文の木の上。S276・S279 と同じ道）
つなぎ

resolve に 1 関数だけ足した

場所変更
globe-mode-resolveComponent.input、Library::function_inputs
globe-mode-lspinlay.rs、textDocument/inlayHint、capability
VS Code の拡張変更なし（vscode-languageclient 9 が capability で自動登録）
出さないもの

推測しない

  • 組み込み（sin・der）、部品、解決できない名前
  • input より多い引数、名前つき引数、for 内包の引数、annotation の中
  • レコードの構築子（Complex(1, 2)）は次回以降
確かめたこと

試験 2 本

  • 名前が出る: extends の基底の input が先、入れ子の呼び出し、書きかけの文書、範囲の内側だけ
  • 出ない: 組み込み・未定義・部品・多すぎる引数・名前つき引数・der
