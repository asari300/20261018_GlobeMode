## 2. 決定と理由

| 項目 | 決定 | 理由 |
| --- | --- | --- |
| 対象 | main に入ったものだけ | 統合ブランチ `integrate-1115` はまだ main に無く、書くと事実と食い違う |
| 限界 | 各項目に一言 | 「最小版」「読み取りだけ」「CLI だけ」を落とすと誇張になる |
