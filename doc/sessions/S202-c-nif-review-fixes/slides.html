C ABI の守り

&mut の別名を作らない

  • GmWorkspace が使用中の印（AtomicBool）を持つ
  • 生のポインタから印のフィールドだけを読み、取れたら &mut Workspace を貸す
  • コールバックの中の gm_* は誤り。gm_workspace_free は放さず stderr に 1 行
  • ヘッダの署名は変えない。Zig・Julia・Rust の試験で固定
