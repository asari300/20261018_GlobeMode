結線の途中の点を図の上で動かす

Diagram の編集の 5 つ目。connect(...) annotation(Line(points = {...})) の中間の点

つまみをドラッグ、線をダブルクリックで点を足す
Rust

2 つの編集

関数することと断るとき
move_waypoint途中の点を (dx, dy) だけ動かす。最初と最後はコネクタに付くので断る
add_waypointpoints があれば index の前に挿す。無ければ両端のコネクタの位置と合わせた 3 点の Line(points) を作る

書き換えるのは 1 点の範囲だけ。座標は S288 の共有の入口（有限で 1e6 以下）を通る

UI

つまみと線のダブルクリック

  • 結線を選ぶと途中の点に四角のつまみ。4 px 未満はクリック、2 単位に吸着、離したら 1 回の dispatch（undo 可、保存しない）
  • 線の上のダブルクリックは、いちばん近い線分の次へ点を足す
  • 口は LSP globe/moveWaypoint・globe/addWaypoint、wasm、Backend。VS Code のパネルは今回やらない
