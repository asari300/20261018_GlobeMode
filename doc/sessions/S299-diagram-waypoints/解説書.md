## 1. 目的

結線の途中の点（`connect(...) annotation(Line(points = {{x1, y1}, ..., {xn, yn}}))` の中間の点）を図の上で動かせるようにする。S250（部品の移動）・S261（結線）・S265（部品の追加）・S281（削除）に続く Diagram の編集の 5 つ目。

## 2. 決定と理由

| 項目 | 決定 | 理由 |
| --- | --- | --- |
| 端の点 | 動かさず断る | 最初と最後の点は部品のコネクタの位置。ずらすと図と接続の意味がずれる |
| `points` の無い結線 | 両端のコネクタの位置と、足す点の 3 点で `Line(points)` を作る | 中心どうしの直線は描画用の仮の線で、`Line(points)` の端はコネクタの位置と決まっている |
| 端の位置 | UI が渡す | `globe/diagram` の `connectors` に出ている。Rust で引き直すと wasm にライブラリの引数が要る |
| 書き換え範囲 | その 1 点の `{x, y}`（足すときは挿入だけ） | 他の点・色・空白に触らない |
| つまみ | `DiagramView` だけが描く | `shape-svg.ts` は VS Code と共有で、VS Code のパネルは今回やらない |

## 3. 図

```text
connect(a.p, b.n) annotation(Line(points = {{0, 0}, {10, 0}, {20, 5}}));
                                           ^^^^^^^^ moveWaypoint(index = 1)
addWaypoint(index = 2, {15, 5})  ->  {{0, 0}, {10, 0}, {15, 5}, {20, 5}}
points が無い直線 + ends ->  annotation(Line(points = {{0, 0}, {x, y}, {9, 9}}, color = {0, 0, 255}))
```
