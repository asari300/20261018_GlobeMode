ライブラリツリーの UI

MSL を読んだら、木でモデルを選んで開ける

木で ChuaCircuit を開き、そのまま検査・実行・プロットへ
目的

このセッションでやること

  • S048 の持ち越し: ライブラリツリーは Must だが UI が無かった
  • ブラウザ UI は「MSL を読む」ボタンとモデル名の欄だけで、名前を知らないと使えない
  • 「使える流れ」の入口: 木で選ぶ、開く、検査、実行、プロット
決定と理由

決めたこと

項目決定理由
木のデータglobe-mode-fmt の LibraryTree（ファイルの見出しだけ読む）wasm と LSP の両方が直に依存する。facade と ir は触らない
取り方展開のたびに直下の子だけ全部を一度に返すと大きい
開き方ライブラリのファイルと同じ名前でエディタに開く同じ名前の setFile がライブラリのファイルを差し替える。編集が検査に効く
単位ファイル。並びは名前の順MSL.json は .mo だけで package.order が無い
