auto-esdirk-fallback

auto の回し直しに esdirk34 を足す（S055 の持ち越し）

BDF → esdirk34 → dopri45。残りの予算を渡す
目的

dopri45 では救えない 3 本

  • bdf の GM-U0005 10 本のうち、auto は 7 本を dopri45 で救う
  • 2 本は dopri45 でも時間切れ（硬い系）、1 本（Dimmer_RL）は文言が対象外
  • 陰的な esdirk34 を先に試す。数値が変わるので、全例題の本数で確かめてから ADR を Accepted にする
決定と理由

順序は BDF → esdirk34 → dopri45

案どうなるか
A: dopri45 を先に硬い系は dopri45 が予算を使い切り、esdirk34 に時間が残らない
B: esdirk34 を先に（採用）TwoMass のように dopri45 だけが救える系は、esdirk34 が 3 秒以内に落ちて dopri45 に回る
esdirk34 だけTwoMass を取りこぼす

回し直しには元の予算を渡す。残りの時間を渡す版は Lightning が 1 本減ったのでやめた。

決定と理由

対象と診断

  • 対象に「歩が丸めの幅より進まない」（Dimmer_RL の BDF）を足す
  • 時間切れ・方向微分（GM-U0004）・初期化の失敗では切り替えない（ADR-0015 のまま）
  • esdirk34 への切り替えは GM-I11003、dopri45 は GM-I11002
  • msl-sim の欄は auto → esdirk34 / auto → dopri45 / auto → esdirk34 → dopri45
