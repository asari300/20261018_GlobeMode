Dioxus 版 UI を作って 3 つ並べた

Leptos 版と同じ機能・同じ測り方。ブラウザ（Linux）の 3 UI が ui.md にそろった

起動 141 ms（Leptos 128、Svelte 289）、バンドル 12.7 MiB（同 12.5、18.7）
目的

このセッションでやること

  • P7 の完了条件「3 UI × 3 OS の比較」の 3 つ目の UI を作る
  • S153 の Leptos 版を型にする: textarea、検査、実行、MSL、ダークモード
  • S125 の測定ハーネスに --ui dioxus を足す
  • 持ち越し: CI、Tauri、プロット・graph、Windows・macOS
決定と理由

決めたこと（ADR-0036）

項目決定理由
依存Dioxus 0.7.10（MIT OR Apache-2.0）、minimal + web最新の安定版。0.8.0-alpha は採らない
ビルドdx を使わず cargo build と wasm-bindgenLeptos 版と同じ。道具が増えない
置き場experimental/dioxus、別の workspace差分 CI に巻き込まない
計算facade を同じ wasm に直接リンク共通の決定は ADR-0035
状態Signal を Ui 構造体にまとめるLeptos 版の RwSignal と同じ形
