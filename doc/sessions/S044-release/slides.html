目的

なぜ今やるか

  • S041 までで CLI・LSP・wasm・Python・ブラウザ UI の骨格がそろった。配る道がまだ無い
  • WP-I は他の作業と独立。Tauri の sidecar（WP-C）が使うバイナリの出どころにもなる（ADR-0023）

決定と理由

決めたこと

項目決定理由
道具素の GitHub Actions の matrix。cargo-dist は足さない3 ターゲット・1 バイナリなら matrix で足りる。依存と設定を増やさない
aarch64ubuntu-24.04-arm でネイティブにビルドpublic なので無料。クロスコンパイルの linker と Rumoca の依存の問題を避ける
Releaseタグの push のときだけ softprops/action-gh-release。contents: write はそのジョブだけ最小の権限。dry-run では artifact に残すだけ
構成--features sundials は付けないcmake と C コンパイラが要る。既定のビルドと同じにする
