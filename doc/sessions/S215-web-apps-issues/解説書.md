## 1. 目的

ユーザーが 2026-11-07 に `/ponytail-audit` で立てた issue のうち、ウェブアプリの 2 件。指摘は「コードを読んだだけで、実行していない」ものなので、いまの main で 1 件ずつ再現してから直した。

| issue | 指摘 | 再現 | 直したか |
| --- | --- | --- | --- |
| #22 | Rust のウェブアプリ 4 種が `Options` のフィールド不足でコンパイルできない。CI が見ていない | した（4 種とも E0063） | 直した。CI にジョブ `web` を足した |
| #36 | CLI を子プロセスで呼ぶウェブアプリに、本文の上限・時間切れ・一時ファイルの守りが足りない | した（FastAPI は新しい試験 3 本、Phoenix は 4 本が直す前に落ちた。Astro・Gleam・Streamlit・marimo は読みと新しい試験で確かめた（直す前のコードでは回していない）） | 直した |

## 2. 決定と理由

### 2.1 #22 の原因

`globe_mode_fmt::Options` に S061 で `blank_around_sections`、S062 で `format_html` が足された。4 つのアプリは `Options { indent, width, insert_origin }` と 3 つだけを名指しして作っていたので、`E0063 missing fields` で止まった。別の workspace で、ルートの cargo も CI も見ていなかったため、S061 から気づかれなかった（`test_ci_plan.py` が `web-axum/.cargo` を「ci.yml の対象でない」と明示していた）。

直し方は各リテラルに `..defaults`（すぐ上に `Options::default()` を取ってある）を足す 1 行 × 4。

### 2.2 #22 の CI

| 項目 | 決定 | 理由 |
| --- | --- | --- |
| 出力 | `ci_plan.py` に `web`。`src/Rust/apps/web-*` を変えたとき、`globe-mode-fmt` の影響を受けたとき、full のときに真 | 今回の原因は `globe-mode-fmt` 側の変更なので、fmt の変更でも回す |
| ジョブ | `web`。matrix（axum・actix・rocket・loco、`fail-fast: false`）で `cargo build --locked` と `cargo test --locked` | 4 つは互いに独立。1 つ落ちても残りを見る |
| 試験 | `test_ci_plan.py` に `test_web_apps` | 判定を守る |
| しなかったこと | `cargo deny`、clippy | 別 workspace はルートの deny の対象外（[web-apps.md](../../web-apps.md)）。壊れに気づくのが目的 |

### 2.3 #36 の共通の値（[web-apps.md の 3.1](../../web-apps.md)）

| 項目 | 値 | 超えたとき |
| --- | --- | --- |
| 本文の上限 | 1 MiB | 413。画面だけのアプリ（Streamlit・marimo）は画面にエラー |
| `globe` の時間切れ | 10 秒。環境変数 `GLOBE_TIMEOUT_MS` で変える（試験が使う） | kill して 5xx（FastAPI は 504） |
| 一時ファイル | 使うなら排他で作り、必ず消す | Phoenix と Gleam だけが使う |

### 2.4 #36 のアプリごとの前後

| アプリ | 本文の上限（前 → 後） | 時間切れ（前 → 後） | 一時ファイル（前 → 後） |
| --- | --- | --- | --- |
| FastAPI | なし → 1 MiB で 413 | 60 秒 → 10 秒（504） | 使わない |
| Streamlit | なし → 1 MiB でエラー | なし → 10 秒 | 使わない |
| marimo | なし → 1 MiB でエラー | なし → 10 秒 | 使わない |
| Phoenix | 既定の 8 MB → 1 MiB で 413（`Plug.Parsers` の `length`） | なし → 10 秒で kill（Port） | `:exclusive` と `File.rm`、変更なし |
| Gleam wisp | 既定の 8 MB → 1 MiB で 413（`set_max_body_size`） | 出力の塊ごとに 60 秒（延び、kill せず） → 全体で 10 秒、`kill -9` | 排他でない書き込み → `exclusive`。書けたときだけ消す |
| Astro | なし → 1 MiB で 413 | なし → 10 秒。`maxBuffer` を 16 MiB に | 使わない |

issue の残りの項目も同じコミットで直した。

| 項目 | 直し方 |
| --- | --- |
| Astro の `indent: 1000000000` | 0〜16 の整数だけ |
| `disable` の値が CLI のオプションになる（`["--json"]` で 500） | FastAPI（pydantic の `pattern`）、Phoenix、Gleam で `^[a-z][a-z-]*$` に合わない値は 4xx。Astro は元からあった |
| Phoenix・Gleam が `indent: 0` を拒む | 契約（[web-apps.md の 3](../../web-apps.md)）どおり 0〜16。Phoenix の `width` も 1〜1000（Gleam と同じ） |

### 2.5 しなかったこと

- Phoenix・Gleam の一時ファイルをやめて、標準入力を直接つなぐ書き換え。標準入力だけを閉じられない Port の制約が理由で、既存の `shortcut:` のまま。
- 巨大な本文を読む前に断る（FastAPI の chunked、Astro）。Content-Length を見て、あとは読み終えてから測る。前段（リバースプロキシ）で切るのが本筋で、`shortcut:` に書いた。
- Rust の 3 つのアプリを消す案（issue #41）。ユーザーの判断。

## 3. 再現手順

```bash
export CARGO_TARGET_DIR=…/target-shared CARGO_BUILD_JOBS=2
cd src/Rust/apps/web-axum && cargo build --locked   # 直す前は E0063
GLOBE_BIN=…/target/debug/globe uv run pytest        # src/Python/fastapi_fmt など
mise exec -- mix test                                # src/Elixir/phoenix_fmt
mise exec -- gleam test                              # src/Gleam/wisp_fmt
mise exec -- node --test test/api.test.mjs           # src/Astro/fmt
```
