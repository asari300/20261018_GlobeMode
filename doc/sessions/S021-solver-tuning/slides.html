自前の積分器の詰め

esdirk34 が MSL の回路で落ちる原因は diffsol の SDIRK が Newton 法の失敗を積分全体で累積して数えることだった。上限を外して直した

Electrical.Analog.Examples 54 本の esdirk34: 実行 42 → 45、管 39 → 42。tsit45 の射影の失敗は陽的 RK の限界で直さない
目的

このセッションでやること

  • roadmap の候補 2。S012 の自前の積分器が MSL で落ちる 3 件を調べ、GlobeMode の側で直せるものを直す
  • esdirk34 が bdf で通る例題で落ちる / tsit45・esdirk34 で射影が収束しない / heun の既定の刻みの精度
  • 既定のソルバ auto は触らない（P3 の完了条件はそのまま）
原因

esdirk34: 失敗を積分全体で数えていた

方法Newton 法の失敗の数え方（diffsol 0.13.2）上限 50 に当たると
BDF（bdf.rs）1 歩の中の回数（歩の始めの値との差）その歩で止まる。刻みの下限が先に効くので実質当たらない
SDIRK（runge_kutta.rs の solve_fail）積分全体の累計（statistics）切り替えのたびに数回失敗する回路では t = 0.009 で止まる（Differentiator は 55 歩目）

直し: SDIRK の問題を組むときに max_nonlinear_solver_failures を外す（rk.rs の 1 行）。失敗ごとに刻みを 0.3 倍にする規則と刻みの下限が 1 歩の暴走を止める

決定と理由

決めたこと

項目決定理由
esdirk34・trbdf2 の失敗の上限外すdiffsol の数え方の違い。刻みの下限が暴走を止める
tsit45 の射影の失敗直さない硬い回路で最初の刻みから発散。試しの点の射影の発散を host が復帰不能の失敗にする。Rumoca の dopri45 も同じ
heun の既定の刻み変えない7 本で 3 / 7。ElasticBearing は発散（陽的 2 次の不安定）。--step で選べる
回帰の試験DiodeSwitching を足す直す前の binary で t = 0.0027 に止まることを確かめた
msl:sim の全体--solver esdirk34 だけauto の道は直しを通らない
