sim-dimmer-thyristor

S064 の持ち越し: Dimmer の y_arg と ThyristorBridge の時間切れ

Dimmer_R・Dimmer_RL はほぼ 0 の振幅の位相。既知の外れへ
目的

このセッションでやること

  • Dimmer_RL の vH01.y_arg・iH01.y_arg が管から外れる原因。Dimmer_R と同じか
  • ThyristorBridge2mPulse_DC_Drive が回し直し（180 s）の時間切れの境目にある件
  • auto の全体の予算は計測だけ
原因

外れるのはサイリスタが止まった窓だけ

区間（Dimmer_RL）vH01.y_rms 参照 / GMvH01.y_arg 参照 / GM
導通 t = 1.03〜6.990.1〜110 / 同じ5 桁一致
止まっている t = 0.25〜1.012.67e-6 / 4〜8e-51.058 / 1.69〜1.79
止まっている t = 7.03〜82.67e-6 / 2〜8e-51.058 / 1.68〜1.72

振幅は導通時の 2e-8。位相は Mean の積分の残差で決まる。RL は L·di/dt の誤差が乗るぶん大きく外れる。

判定

Dimmer_R と同じ原因

  • Dimmer_R の点弧の時刻は参照と 1e-6 s まで一致（最初の 11 回）。research の「点弧のずれ」の見込みは外れ
  • 外れる窓は t = 0.27〜0.39、振幅 7.9e-6 → 2.66e-6 V。位相の差 0.002〜0.02 rad
  • 許容誤差を 1e-8 にすると 9/11 → 4/11 に悪くなる（参照も解けていない）
  • 実行系は直さず、2 本とも既知の外れに理由付きで載せた
