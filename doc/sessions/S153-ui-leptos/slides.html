起動 154 ms（Svelte 324）、バンドル 12.5 MiB（同 18.7）。Decay の計算は 同じ
目的

このセッションでやること

  • P7 の完了条件「3 UI × 3 OS の比較」のうち Leptos 版を作る
  • S125 の測定ハーネス（ADR-0034）で、ブラウザ（Linux）の 1 列を足す
  • 機能は絞る: textarea、検査、実行、MSL、ダークモード
  • 持ち越し: Dioxus 版、Tauri、プロット・graph、Windows・macOS、CI
決定と理由

決めたこと（ADR-0035）

項目決定理由
依存Leptos 0.8.23（MIT、csr のみ）安定版。cargo deny は通った
置き場experimental/leptos、別の workspacedesktop と同じ。差分 CI に巻き込まない
計算facade を同じ wasm に直接リンクこれが Leptos 版の特徴。JSON も Worker も無い
ビルドcargo build と wasm-bindgen（trunk なし）wasm:build と同じ作り。道具が増えない
ダークモードCSS 変数、OS に追従、ボタンで固定ユーザーの要望
