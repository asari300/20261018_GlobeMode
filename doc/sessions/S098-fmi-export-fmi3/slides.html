FMI 3.0 の Export と fmusim

2.0・3.0 とも FMPy と fmusim の validate・ME・CS を通った
目的

このセッションでやること（S094 の持ち越し）

  • FMI 3.0 の FMU を出す（binaries/x86_64-linux/）
  • FMPy で 3.0 の validate と ME・CS の simulate を試験に足す
  • fmusim での検査（手元で実行できないので GitHub Actions）
  • FMU に Rumoca（Apache-2.0）の表示を同梱する
決定と理由

決めたこと（ADR-0031 の追記）

項目決定理由

3.0 の --buildbuildDescription.xml の定義を -D で渡す無いと関数名に接頭辞が付き FMPy が読めない
fmusim手動の fmu-export.yml外から取ったバイナリを手元で実行できない
