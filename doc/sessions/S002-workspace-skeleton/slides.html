決定と理由 · Rumoca

ADR-0003 の最大の懸念は杞憂だった

v0.10.2固定した Rumoca（rev 276e82bd）
stable1.99.1 のまま（nightly 不要）
約 3 分ネイティブの初回 cargo check
3 分 18 秒wasm32-unknown-unknown の cargo check
  • Rumoca の nightly-2026-02-27 の固定は、Rumoca 自身の wasm のスレッド（wasm-bindgen-rayon）のためだけで、git 依存として使う側には影響しなかった
  • 依存は rumoca-compile だけ（default-features = false）。umbrella crate の zenoh などは入らない
  • rumoca-compile は整理された窓口を持つ: Session（文書の追加とモデルのコンパイル）、parsing（AST）、compile::PhaseResult（どの段階で失敗したか）
  • Rumoca を git で使う間は crates.io に公開できないので、publish = false

決定と理由 · ライセンス監査

  • licenses: doc/licenses.md の許可リストだけ
  • bans: umbrella crate rumoca・zenoh・russell_sparse を禁止
