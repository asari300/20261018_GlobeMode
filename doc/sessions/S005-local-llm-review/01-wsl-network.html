S005 · 01 WSL2 のネットワーク

WSL2 から Windows の LM Studio に届かせる

NAT と mirrored で、つなぎ先と必要な設定がまるで違う。この PC は mirrored なので localhost:1234 で届く。

設定 · .wslconfig

%UserProfile%\.wslconfig（Windows 側）

[wsl2]
networkingMode=mirrored
dnsTunneling=true
# memory=16GB      # 任意。既定は RAM の半分
# processors=8     # 任意

[experimental]
hostAddressLoopback=true
  • networkingMode=mirrored: Windows 11 22H2 以降。WSL から 127.0.0.1 で Windows のサーバに届く
  • hostAddressLoopback: 127.0.0.1 以外のホストの IPv4 アドレスでも届く。LM Studio を 127.0.0.1 だけで待ち受けるなら、無くても動く
  • dnsTunneling: 有効だと /etc/resolv.conf の nameserver が 10.255.255.254 になる。NAT 向けの「resolv.conf からホストの IP を取る」手順は使えない
  • 変えたら PowerShell で wsl --shutdown。MS は「WSL Settings」アプリでの変更を勧めている
  • この PC: 上の 3 行が設定済み。memory は未設定で、WSL から見える RAM は約 14 GiB。LM Studio は Windows 側の残りを使う
設定 · ファイアウォール

穴を開けるのは NAT のときだけ。mirrored は Hyper-V の規則を見る

構成LM Studio の待ち受けファイアウォール（管理者の PowerShell）
mirrored ＋ localhost（推奨）127.0.0.1（Serve on Local Network を切る）不要。外からは届かなくなる
mirrored ＋ ホストの IP0.0.0.0New-NetFirewallHyperVRule -Name LMStudio -DisplayName "LM Studio" -Direction Inbound -VMCreatorId '{40E0AC32-46A5-438A-A0B2-2B479E8F2E90}' -Protocol TCP -LocalPorts 1234
NAT0.0.0.0（必須）New-NetFirewallRule -DisplayName "LM Studio 1234" -Direction Inbound -Protocol TCP -LocalPort 1234 -Action Allow -Profile Private
  • 0.0.0.0 で待ち受けると、同じ LAN や Tailscale の相手からも届く。認証が無ければ、誰でもモデルを使え、プロンプトもログに残る（→ 02 の S03）
  • Hyper-V の規則を全体で許す Set-NetFirewallHyperVVMSetting … -DefaultInboundAction Allow は、WSL の中のサーバを外に開く設定。今回は要らない
確認 · WSL 側

届くかを 3 段で確かめる

# 1. mirrored か（Windows の LAN の IP が見えるか）
ip -4 addr | grep inet

# 2. OpenAI 互換の一覧
curl -s -m 5 http://localhost:1234/v1/models

# 3. 読み込みの状態と ctx（LM Studio の REST）
#    （一覧は数十秒かかることがある）
curl -s -m 120 http://localhost:1234/api/v0/models \
  | grep -E '"(id|state|loaded_context_length)"'

# まとめて（スキルのスクリプト）
S=.claude/skills/local-review/lmstudio_review.py
python3 -I $S --check
症状原因と対処
接続を拒否されたサーバが止まっている。Windows で lms server start、または Developer タブで Start
時間切れNAT なのに localhost を叩いている／ファイアウォール。ip route のゲートウェイを試す
401Require Authentication が有効。LMSTUDIO_API_TOKEN を設定する
state: not-loadedモデル未読み込み。03 の S06 の設定で読み込む
