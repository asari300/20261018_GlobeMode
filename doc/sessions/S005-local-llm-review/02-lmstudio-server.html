S005 · 02 LM Studio のサーバ

1 つのポートに 3 種類の API がある

APIパス（http://localhost:1234 の下）使いどころ
OpenAI 互換/v1/models /v1/chat/completions /v1/responses /v1/embeddingsOpenAI SDK、MCP サーバ（houtini-lm）など、ほとんどの道具
LM Studio REST/api/v0/models（state・ctx）
/api/v0/chat/completions（stats 付き）
/api/v1/models/load（0.4.0〜）		/local-review が使う。読み込みの確認、tok/s の計測、ctx を指定した読み込み
Anthropic 互換/v1/messages（0.4.1〜）Claude Code を丸ごと向ける（ANTHROPIC_BASE_URL）。今回は比較だけ（05）

実機: /v1/messages に thinking: {"type":"disabled"} を付けて "pong" が 6 秒で返った。/api/v0/models は 12 モデル中、Bonsai-27B だけが loaded だった。

サーバの起動

GUI でも CLI でも起動できる。WSL からは lms.exe を呼ぶ

Windows の GUI

  1. 左の Developer（緑のターミナルのアイコン）を開く
  2. Status: Running にする（Start Server）
  3. Server Settings で次の S03 の値にする
  4. Settings → Developer の「アプリ起動時にサーバを起動」を有効にする（この PC は有効）

WSL から CLI

# Windows の lms.exe は WSL から直接動く（interop）
alias lms="$(ls /mnt/c/Users/*/.lmstudio/bin/lms.exe \
             | head -1)"
lms server status
lms server start --port 1234   # 既定で 127.0.0.1
lms ps                          # 読み込み中のモデル
lms load prism-ml/bonsai-27b -c 12288 \
    --gpu off --parallel 1 --ttl 1800 -y
lms unload --all
lms log stream -s server        # リクエストを見る

ユーザー名を含むパスは ls で探す。lms はアプリの初回起動時に %USERPROFILE%\.lmstudio\bin に置かれる。

推奨 · Server Settings（ユーザーが GUI で変える）

いまの設定は LAN と Tailscale に開いたまま、プロンプトを全文ログに書いている

項目いま（実機）推奨理由
Serve on Local Network有効（0.0.0.0）無効（127.0.0.1）mirrored なら WSL から localhost で届く。外に開く理由が無い
Require Authentication無効127.0.0.1 なら任意。0.0.0.0 にするなら必須トークンは Manage Tokens で発行。LMSTUDIO_API_TOKEN に入れる
ログ（logSensitiveData / logIncomingTokens）有効（全文）無効差分（社外秘のコードや鍵の取りこぼし）がログに残る。Developer のログ設定で切る
Enable CORS無効無効のままブラウザから叩く用途が無い
Just in Time Model Loading有効どちらでも/local-review は未読み込みなら止まるので、意図しない JIT は起きない
Auto Unload Unused JIT Models3600 秒1800 秒使わないモデルが 5 GiB 近くの RAM を持ち続けないように

設定ファイルは %USERPROFILE%\.lmstudio\.internal\http-server-config.json。手で編集せず GUI で変える（書式が版で変わりうるため）。

接続 · 認証を有効にしたとき

トークンは環境変数で渡し、リポジトリには書かない

# ~/.zshrc など（コミットしない場所）
export LMSTUDIO_BASE_URL=http://localhost:1234
export LMSTUDIO_MODEL=prism-ml/bonsai-27b
export LMSTUDIO_API_TOKEN=...   # 認証を有効にしたときだけ

# OpenAI 互換は Bearer
curl -s localhost:1234/v1/models \
  -H "Authorization: Bearer $LMSTUDIO_API_TOKEN"

# Anthropic 互換は x-api-key も受ける
curl -s localhost:1234/v1/messages \
  -H "x-api-key: $LMSTUDIO_API_TOKEN" \
  -H 'anthropic-version: 2023-06-01' \
  -H 'Content-Type: application/json' \
  -d '{"model":"prism-ml/bonsai-27b","max_tokens":32,
       "thinking":{"type":"disabled"},
       "messages":[{"role":"user","content":"ping"}]}'
  • 認証なしのときは、OpenAI SDK の api_key は任意の文字列でよい（慣例は "lm-studio"）
  • lmstudio_review.py は LMSTUDIO_API_TOKEN があれば Authorization: Bearer を付ける
  • TTL はリクエストごとに "ttl": 1800 で指定できる（スクリプトの既定）
  • 出典: lmstudio.ai/docs の server-start、server/settings、authentication、openai-compat、anthropic-compat（確認 2026-10-18）
まとめ

Windows 側でやることは 3 つ

  1. Serve on Local Network を切る（127.0.0.1 で待ち受ける）
  2. プロンプトの全文ログを切る
  3. モデルを -c 12288 --gpu off --parallel 1 で読み込む（03）
