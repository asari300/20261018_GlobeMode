S005 · 04 /local-review

差分を塊に分けて送り、返ってきた指摘を Claude が裁く

ファイル: .claude/skills/local-review/ の SKILL.md・lmstudio_review.py（標準ライブラリだけ、約 530 行）・test_lmstudio_review.py（unittest 13 件）。

工夫 · 小さいモデルに合わせる

行番号は数えさせず、本文に書いて渡す

送る形（注釈付き）

diff --git a/src/a.rs b/src/a.rs
--- a/src/a.rs
+++ b/src/a.rs
@@ -10,3 +10,4 @@ fn main() {
   10       let x = 1;
      -     let y = 2;
   11 +     let y = x.checked_add(2).unwrap();
   12 +     println!("{y}");
   13   }

返させる形

src/a.rs:11 — high — unwrap can panic — return an error
NO_FINDINGS        ← 指摘が無いとき
  • 行番号: 小さいモデルは @@ +10 から数え間違える。新しいファイルでの番号を各行に付ける
  • 分割: ファイル単位でまとめる → 大きいファイルは @@ ごと → 1 つの @@ が大きければ、番号を引き継いだ (continued) に分ける
  • 見積もり: ASCII 3 文字で 1、日本語は 1 文字で 1 トークン（多めに見積もる。実測は Rust で 3.0〜3.3 文字）
  • 出力の拾い方: 正規表現で path:line — 重大度 — 本文 を拾う。-・–・番号付きリスト・太字の揺れも受ける。合わない行は捨てずに別に出す
  • 止まる条件: 未読み込み・届かないときは終了コード 2（JIT で最大の ctx に読み込まれる事故を防ぐ）
使い方

まず --check と --dry-run、次に絞って走らせる

S=.claude/skills/local-review/lmstudio_review.py
python3 -I $S --check        # 届くか・読み込み・ctx
python3 -I $S --dry-run      # 塊と所要時間の見積もり
python3 -I $S                # main との差分（未追跡を含む）
python3 -I $S --range HEAD~1..HEAD
python3 -I $S --staged
python3 -I $S --path 'src/Rust/**' --max-chunks 2 \
             --out log/local/local-review.md
python3 -I $S --load 12288   # REST で読み込む（FA 有効）
引数・環境変数既定
LMSTUDIO_BASE_URLhttp://localhost:1234
LMSTUDIO_MODELprism-ml/bonsai-27b
LMSTUDIO_API_TOKENなし（あれば Bearer）
--chunk-tokens6000
--max-chunks3（超えた分は一覧だけ出す）
--max-tokens768（生成 2 tok/s で約 6 分）
--temperature0.4（top_p 0.9、top_k 20）
--think切る（reasoning_effort: none）
--pp-tps / --gen-tps8 / 2（見積もり用）
--ctx読み込みの確認を省く（一覧が数十秒かかることがある）
Claude の手順（SKILL.md）

待つ間は自分のレビューを進め、最後に表で裁く

  1. --check。終了コード 2 なら、ユーザーに読み込みを頼む（勝手に読み込まない）
  2. --dry-run。20 分を超えそうなら --path で核心に絞る
  3. Bash を バックグラウンドで起動し、出力は log/local/（コミットしない）へ
  4. その間に Claude 自身のレビューを進める
  5. 指摘を 1 件ずつコードで確かめ、表にして報告する
#場所指摘判定理由
1path:line…採用どこを見てそう判断したか
2path:line…誤検知…
3path:line…保留…

してはいけないこと: 確かめずに直す／秘密を含みうるファイルを送る／Stop フックで自動実行する（1 回 10 分以上、ADR-0007）。

仕込んだ 3 つのバグのうち 1 つを、正しい行番号で拾った
