署名と smoke の分け方

項目決定
ABIrelease は ABI ごと。配るのは aarch64、x86_64 は smoke 用
署名secret を env に写し、あれば keystore.properties を書く
鍵が無いときrelease-unsigned。smoke 用は使い捨ての鍵で署名
smoke 用x86_64 を debuggable で作り直す（Tauri は debug でしか console を logcat に出さない）
emulatormatrix で debug と release の 2 本
