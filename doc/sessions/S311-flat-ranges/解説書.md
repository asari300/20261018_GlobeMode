## 1. 目的

[S307](../S307-native-closure/解説書.md) の持ち越し。`globe check --frontend native` の `GM-E6001`（構造特異）と `GM-E5002`（釣り合わない）に、原因の方程式・変数の行・列を付ける。自前の `DaeStructure` の `file`・`range` は `None` だった（[ADR-0039](../../adr/0039-native-cst-parser.md) の S290・S307 の付記）。理由は、平坦化の結果が元のソースの位置を持たなかったこと。

## 2. 決定と理由

| 決めたこと | 理由 |
| --- | --- |
| `globe-mode-flat` に `Origin { file: Arc<str>, start, end }` を足し、`Var::origin`・`Equation::origin`（`Option`）に持たせる | ファイルは番号でなく名前にする。閉包だけを読む `Project` と全部読みの `Project` で番号が違い、S307 の「平坦化の結果が一致」の試験が壊れるため |
| 変数の由来は宣言（`Declaration` の節点）。`extends` で受け継いだ宣言は基底クラスのファイルの位置、`redeclare` で差し替えても元の宣言 | 平坦化は元の `ClassDef` の節点をたどるので、宣言した場所の節点がそのまま手に入る |
| 方程式の由来は `Equation` の節点（`;` を含む）。`for` の展開は中の方程式の位置（何回展開しても同じ）、定数の条件の `if` は選んだ枝の中の方程式 | 展開は同じ節点を文脈を変えて何度も平らにするだけ |
| `connect` から作る方程式は、その集合に属する最初の `connect` の文。つながない内側のコネクタの `flow = 0` は flow 変数の宣言 | 1 つの集合から複数の `connect` が重なる。代表の 1 つで足りる（複数を指す形は `Diagnostic` に無い） |
| `redeclare` の読み直しの仮のファイル（`SNIP_FILE_BASE` 以上）は由来を持たない | 仮のファイルは本物のソースの位置ではない |
| `globe-mode-dae` は、行・未知数に由来をそのまま入れる。束縛の方程式は変数の宣言、`algorithm` の行は付けない | `algorithm` は印字した文字列で持っていて、文ごとの位置を運んでいない |
| `GM-E5002` は、数が合わないときも S6 の解析（`analyze`）を回し、多い側の「相手のいない」方程式か未知数の位置に診断を置き、名前を注にする | Rumoca の道は位置なしだが、依頼は原因の位置を付けること。S6 の `GM-E6001` と同じ出し方に揃える |

## 3. 図

```text
元のソース（.mo）
  └ CST の節点（宣言・方程式・connect の文）
       └ flatten: Var / Equation に Origin（ファイル名・バイト範囲）を付けて運ぶ
            └ dae::build: EquationRow / Unknown の file・range に入れる
                 └ analyze → GM-E6001・GM-E5002 の診断に「file:行:列」
```

## 4. 結果と、やらなかったこと

- 試験: `globe-mode-flat` に由来の単体試験を 1 本（入れ子・`extends`・`for`・`connect`・`flow = 0`）。`check_native` に位置つきの `GM-E6001` と `GM-E5002` を 1 本。
- やらなかったこと: `algorithm` の文ごとの位置、`if`・`when` の枝ごとの位置、複数の `connect` を指す診断（代表の 1 つだけ）。`globe-mode-resolve`・LSP は変えていない。

詳しくは [ADR-0039](../../adr/0039-native-cst-parser.md) の付記（S311）。

## 5. 再現手順

```bash
cargo test -p globe-mode-flat --test flat origins
cargo test -p globe-mode-cli --test check_native
cargo run -p globe-mode-cli -- check x.mo -m Sing --frontend native   # GM-E6001 に x.mo:行:列
mise run msl:diff-frontend   # 回帰 0 を確かめる
```
