flat の結果に元のソースの位置を持たせた

globe check --frontend native

GM-E6001・GM-E5002 に行と列が付く
やり方

Var と Equation に「由来」を足した

  • Origin: ファイル名と元のファイルのバイト範囲（番号でなく名前なので、閉包だけ読んでも全部読んでも同じ）
  • 入れ子・extends・redeclare: 宣言した場所（基底クラスのファイル）の位置をそのまま運ぶ
  • for の展開: 中の方程式。connect: 集合の最初の connect の文
  • globe-mode-dae が DaeStructure の file・range に入れる（S290 では None）
結果

native の診断が Rumoca の道と同じ形になった

  • GM-E6001: 対応のない方程式の行・列と、対応のない未知数の宣言の行・列
  • GM-E5002: 多い側の対応のない方程式か未知数の位置と、その名前の注
  • 残り: algorithm の行、if/when の枝ごとの位置
