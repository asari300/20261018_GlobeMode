定義ジャンプとホバーを自前に

読めない文書でも、型名と r.p.v の定義に飛び、ホバーが宣言を出す

S279 の補完と同じ形。今の道が読める文書は変えない
目的

このセッションでやること

  • 構文の誤りや end の前で切れた文書では、定義ジャンプとホバーが null だった
  • 自前の構文（globe-mode-syntax）と名前解決（globe-mode-resolve）で答える
  • IDE の機能から自前にする Track B の 3 つ目（アウトライン S276、補完 S279 に続く）
決定と理由

決めたこと

項目決定理由
使う条件文書の Outline が Err のときだけ読める文書の出力と既存の試験を変えない。読める文書で null のたびに木を作らない
引き方書きかけの文書の Ref を段で切って resolve型名も r.p.v も同じ道。with_source で足した Ref を使う
ホバー定義の Target から今の hover_at で作る文面は今の globe/hover と同じ
