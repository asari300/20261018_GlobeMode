### 2.1 レビュー文書の置き場

元の置き場 `doc/sessions/S136・S149・S150・S151・S152` は、main の索引で別のセッションが使っている番号なので、`log/review/2026-11-03-<元のトピック>/` に移した（`review-map`・`review-fmt-panics`・`review-fmt-crlf`・`review-fmt-structure`）。本文は変えていない。変えたのは相対リンク（`../../assets` などが 1 階層ぶん変わる）と、本文のコマンドの `doc/sessions/S15x-…` のパスだけ。作業記録 3 本は `log/work/` の同名で、独立レビューの 1 本は `log/review/` にそのまま入れた。索引 `doc/sessions/README.md` には行を足していない。代わりに [log/review/README.md](../../../log/review/README.md) に表を足し、レビュー地図のフォルダの README に「2026-11-03 の main の snapshot」と 1 行書いた。これらの HTML は `check_docs.py` のスライド検査（`doc/sessions/*/*.html`）の対象外で、相対リンクだけが検査される。

### 2.2 正しいファイルを断らないこと

issue 21 の直しは「断る場合を増やす」変更なので、正しいファイルを誤って断らないことを、整形の前後で確かめた。

| 集合 | 本数 | 断る（前） | 断る（後） | 整形結果の差 |
| --- | --- | --- | --- | --- |
| `data/msl` の `.mo`（MSL 4.1.0） | 2,556 | 0 | 0 | 0 |
| `src/Modelica` | 71 | 0 | 0 | 0 |
| `doc/research/upstream` | 34 | 0 | 0 | 0 |
| `src/Rust` と `data/libs`（Buildings・AixLib） | 10,644 | 4 | 4（同じ 4 本） | 0 |

「前」は `globe-mode-fmt/src` を main のままにして、「後」は直した版で、使い捨ての example（コミットしない）が全ファイルを `format` に掛けて、状態と出力のハッシュを並べた。

## 3. 図

```text
format(src) → lex → structure::split ──(S192)→ Ctx::Block(if|for|while|when) と end の突き合わせ
                       ↓
                    layout → 出力の行 ──(S192)→ \r\n を \n に戻してから改行コードへ（CRLF の入力）
                       ↓
                    lex し直して、空白以外のトークンが同じかを確かめる
```
