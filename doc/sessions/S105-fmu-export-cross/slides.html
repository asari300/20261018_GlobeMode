Windows・macOS 向けの FMU

globe fmu export --build --target <triple> で zig cc を呼ぶ

1 つの FMU が Ubuntu・Windows・macOS の FMPy を通った
目的

このセッションでやること（S098 の持ち越し）

  • --build は host（x86_64 の Linux）の .so だけだった
  • --target を足し、win64・darwin64 にも .dll・.dylib を置く
  • 1 つの FMU に 3 つの binaries/<platform>/ を同梱する
  • 各 OS での実行は GitHub Actions（fmu-export.yml）で確かめる
決定と理由

決めたこと（ADR-0031 の追記）

項目決定理由
指定--target 何度でも、省略は host の cc既存の呼び出しが変わらない
コンパイラzig cc -target <triple>zig は mise にある。新しい依存なし
置き場2.0: linux64・win64・darwin64
3.0: x86_64-windows・aarch64-darwin など		FMI の規格の名前
副産物.pdb・.lib を消すFMU に要らない（.pdb は 1.1 MB）
