大きさ

strip の前後

Decay の P5b の FMU は 14.3 → 12.9 MB。共有ライブラリは 44.5 → 33.1 MB（zip の中で 14.3 → 12.8 MB）。

  • zip に入れる写しだけを strip する。runtime_lib で渡したファイルは触らない。
  • Linux は strip、macOS は strip -x、Windows は何もしない。
UI

ブラウザ・Android には出さない

  • Desktop の「FMU を書き出す」の隣に、P5a（Rumoca の C）と P5b（自前、cargo が要る）の select。
  • P5b は sidecar が cargo build を呼ぶので、globe のソースの作業ツリーの外では理由つきで失敗する。
  • cdylib を作れないブラウザ・Android に選択肢は無い。
