UI の使い心地 4 点

Esc で止める、タブの並べ替え、設定のモデルごとの保存、開始時刻・刻み幅・予算の欄

Svelte の UI だけ。Rust も新しいライブラリも触らない
キー

Esc とタブの並べ替え

操作動き
実行中の EscCtrl+. と同じ。入力欄・ダイアログの中では奪わない。補完の一覧が開いていれば閉じるだけ
Ctrl+Shift+PageUp / PageDownいまのタブを左へ・右へ（端では動かない）。「B.mo を 2 番目へ移した」と読み上げる
ドラッグHTML5 の draggable。順序は 300 ms のまとめ書きで残る
設定

モデルごとの保存と新しい欄

  • globe-mode.sim: モデル名 → 触った欄だけ。モデルを変えると入れ替わり、「設定を既定に戻す」で消える
  • 開始時刻・刻み幅（固定刻みのソルバのときだけ有効）・予算（秒）の欄
  • GM-E10004（出力が 1000 万点を超えるなど）は欄の下にも出る
試験

試験と再現

cd src/Svelte && pnpm check && pnpm build
uv run python src/Svelte/tests/test_ui.py   # ui_polish の 4 本
