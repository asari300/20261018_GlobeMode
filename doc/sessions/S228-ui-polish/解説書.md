## 1. 目的

[roadmap.md](../../roadmap.md) の「機能の穴（P4）UI の使い心地」に残っていた 4 点（Esc で止める、タブの並べ替え、設定のモデルごとの保存、開始時刻・固定刻み・予算の欄）を、Svelte の UI（ブラウザ・Desktop・Android 共通）に入れる。Rust と protocol の Rust 側は触らない（欄はすべて `SimSettings` に既にあった）。新しいライブラリは足さない。

## 2. 決定と理由

| 項目 | 決定 | 理由 |
| --- | --- | --- |
| Esc | 実行中（`runState === "running"`）の Esc で `backend.cancel()`（Ctrl+. と同じ道）。`input`・`textarea`・`select`・`dialog` の中、IME 変換中、修飾キー付きでは動かない。`completionStatus(view.state)` が非 null（一覧が開いている）なら何もせず CodeMirror に閉じさせる | 利用者は実行を押したあと本文かボタンのそばにフォーカスがある。入力欄の Esc はリネームの取り消し等に使う。S188 の「Esc のあと Tab」の窓は握りつぶさないので影響しない |
| 並べ替え（キー） | Ctrl/Cmd+Shift+PageUp / PageDown。端では動かない（回り込まない）。実行中は動かさない。動かしたら `live` に「B.mo を 2 番目へ移した」 | 依頼どおり。`shortcut`（window の capture）の表に 2 行足すだけ。ブラウザのタブ移動と同じ組み合わせだが、ページが先に受けて `preventDefault` する |
| 並べ替え（ドラッグ） | タブの `span` を HTML5 の `draggable`（`role="presentation"`。Svelte の a11y 規則）。`{#each tabs as t, i (t)}` にして DOM がタブについていくので、フォーカスも移る | 新しいライブラリを足さない。キーでもできるので a11y は足りる |
| 並べ替えの保存 | `moveTab` が `tabs` と `cur` を入れ替え、`persistSoon()`（300 ms）。`persist` は `tabs` の順に書くので順序と `active` が乗る | 既存の仕組みに相乗り |
| モデルごとの設定 | `SimSettings` に `model` を渡し、localStorage の `globe-mode.sim`（モデル名 → 触った欄だけ。上限 50 モデル、書き直した順）。モデルが変わったら読み込み（無ければ既定）、欄が変わったら書く。`loaded` で「欄がどのモデルのものか」を持ち、読み込み前に別のモデルの名前で書かない | タブを切り替えても、モデル名の欄を打ち換えても同じ道。保存できなくても動く（S102） |
| 既定に戻す | ボタン「設定を既定に戻す」（保存が無ければ無効）。そのモデルの保存を消す | 名前は Plot の「既定に戻す」と、他の試験の `name="実行"` の部分一致を避けた |
| 新しい欄 | `start_time`・`step`・`max_wall_seconds`。`step` は固定刻みのソルバ（`euler`・`heun`・`rk4`・`impeuler`・`trapezoid`）を選んだときだけ有効で、他では送らない。固定刻みの一覧は UI に写した（`shortcut:` コメント。`SolverEntry` に印が付いたら置き換える） | Rust は触らない。protocol の `SimSettings` に欄はあり、TS の型にだけ足した |
| GM-E10004 | 診断のうち `GM-E10004` を `SimSettings` の欄の下（`[data-refusal]`）にも出す。実行の後の `reveal` はそこへ | 診断の表に出るだけだと、設定の欄から離れている（S212 の 1000 万点の上限） |

## 4. 再現手順

```bash
cd src/Svelte && pnpm install --frozen-lockfile && pnpm check && pnpm build   # wasm は mise run wasm:build の出力
cd ../.. && uv run python src/Svelte/tests/test_ui.py
```

`test_ui.py` の `ui_polish`（4 本）:

- Esc: 入力欄の Esc では止まらず、補完の一覧を閉じる Esc でも止まらず、そのあとの Esc とフォーカスが body のときの Esc で `data-run="cancelled"`。
- 並べ替え: Ctrl+Shift+PageUp / PageDown（端では動かない）、フォーカスは動いたタブについていく、`.tab` のドラッグ。300 ms 後に `globe-mode.tabs` の順序と `active`、再読み込みで戻る。
- モデルごとの保存: Decay に終了時刻 7・rk4・刻み幅 0.5、`Other` に切り替えると空、戻すと復元、再読み込みでも復元、「設定を既定に戻す」で `globe-mode.sim` から Decay が消えて Other は残る。刻み幅は既定のソルバで無効。
- 新しい欄: 開始時刻 1・終了時刻 3 が `data-last` に出る、rk4 と刻み幅 1e-9 で GM-E10004 が欄の下に出る、予算 2 秒で長いモデルが GM-E11005 で打ち切られる。

既存の試験の直し: 補完の Enter の確定の前に 300 ms 待つ（CodeMirror は一覧が出て 75 ms 以内の確定を無視する。負荷が高いと Enter が改行になった）。Plot の「既定に戻す」は `exact=True`。smoke の `settings` は先に `tick()`（プログラムでモデル名を変えた直後に欄を打つと、入れ替えが後から欄を消す。人の操作では起きない）。
