案内

「はじめに」の 3 手順

1. モデルを書く（いまは例の Decay）か「開く」（Ctrl/Cmd+O）。MSL を使うなら「MSL を読む」
2. 「検査」（Ctrl/Cmd+Shift+Enter）で診断を見る
3. 「実行」（Ctrl/Cmd+Enter）で結果のプロットを見る
  • 保存したタブが無い初回だけ。閉じると localStorage に残す（S152 のテーマと同じ流儀）
  • ?smoke=1 では出さない。ready_ms は 382 から 339 ms（3 回の中央値。雑音の範囲）
  • モーダルもツアーも使わない。MSL を読むと 1 行が消える

未保存の印

● と、再読み込みをまたぐ判定

案判断
戻した本文を保存済みとみなす（S151）再読み込みで印が消え、未保存を数え損ねる
保存済みの本文を、編集中のタブだけ localStorage に持つ採る。本文と同じなら書かない。上限の字数に数える
  • 印は role="img" aria-label="未保存"。view は $state でないので rev を進めて再計算
  • 保存済みの本文が無い古い保存は、これまでどおり戻した本文を保存済みとみなす
  • beforeunload は無かった。未保存があるときだけ、ブラウザのみ（Tauri と smoke は除く）
