## 1. 目的

S357（[doc/research/audit42-status-2026-11-15.md](../../research/audit42-status-2026-11-15.md) の D-3）で、CLI の `expand_inputs` が隠しフォルダ（`.history/` など）の `.mo` を読んで同名のクラスが二重になる不具合を、frontend の `collect_mo_files`（`fmt`・LSP と同じ規則）に替えて直した。同じ走査の抜けが、ライブラリの読み込み用の `globe-mode-resolve/src/build.rs` と `globe-mode-flat/src/lib.rs` の `mo_files` に残っていた。この 2 か所も同じ規則（`.` で始まる名前を飛ばす）にする。

## 2. 決定と理由

| 項目 | 決定 | 理由 |
| --- | --- | --- |
| 共有の関数 | `globe-mode-resolve::mo_files`（`pub`）に 1 つだけ置き、flat は自前の関数を消してこれを呼ぶ | flat は resolve に依存している。重複は 1 つ減る |
| frontend の `collect_mo_files` を使わない理由 | frontend が resolve に依存する（`native` feature）ので、resolve から frontend は呼べない。resolve に最小の判定（`.` で始まる名前を飛ばす）を置き、理由を 1 行のコメントにした | 依存の向きが逆になる |
| 飛ばす範囲 | `.` で始まる名前のファイルとフォルダ（`collect_mo_files` と同じ） | 規則を揃える。エディタのスワップファイル（`.#foo.mo`）も読まない |
| S068（`X.mo` と `X/` が並ぶ配置は `X.mo` を正に）は足さない | 隠しフォルダだけを揃えた | 範囲外。AixLib の配置は frontend の経路で読む。自前の読み込みに同じ配置が来たら別に直す |
| 試験 | resolve に `from_dirs_skips_hidden_dirs`、flat に `read_dirs_skips_hidden_dirs`。どちらも `A.mo` と `.history/A.mo`（同じ本文）を置き、読むファイルが 1 本だけ | 直す前は 2 本読んで落ちることを確かめた |
| Track B の数え方 | 変わらない（全体の検査は回さない） | MSL に隠しフォルダの `.mo` は無い（下の再現手順） |

## 4. 再現手順

```bash
export CARGO_TARGET_DIR=<main>/.git-worktree/target-shared CARGO_BUILD_JOBS=2
cargo test -p globe-mode-resolve --test resolve from_dirs_skips_hidden_dirs
cargo test -p globe-mode-flat --test flat read_dirs_skips_hidden_dirs
cargo test -p globe-mode-resolve -p globe-mode-flat
cargo test -p globe-mode-lsp -p globe-mode-frontend --features globe-mode-frontend/native
# MSL に隠しフォルダの .mo が無いこと（出力が空）
find data src/Modelica -mindepth 1 -path '*/.*' -name '*.mo'
```

`ls -a data/msl` の隠しエントリは `.download`（取得した zip だけ）と `.globe-mode-msl`（版の印のファイル）の 2 つで、`.mo` は入っていない。`data/libs/*` の隠しエントリも `.globe-mode-library`（ファイル）だけ。
