ほかに auto の dopri45 への切り替え、パラメータの上書き（再コンパイル無し）、結果の MAT v4、止まった例題の調査と直せるものの修正。MSL の全例題は 309 本が終了時刻まで（S011 は 303 本）、299 / 308 本（97.1%）が管に収まった。

検査 → 実行が Node の wasm で通った

型付きの道は panic する

build_simulation と rk45::simulate は std の Instant::now() を呼ぶ。Node で実際に RuntimeError: unreachable になった。

getrandom

diffsol → faer → rand で getrandom 0.3。--cfg getrandom_backend="wasm_js" だけでは落ち、feature wasm_js も要る。

Cranelift

wasm32 では自動で外れ、インタプリタで回る。instant（RUSTSEC-2024-0384、ignore 済み）が実際に使われる。

フロントエンド

wasm で動く（rayon は呼んだスレッドで逐次）。MSL の .mo は 2556 本・15.3 MB。

panic=abort

catch_unwind は効かない。文言は panic の hook で残すしかない。

ほかの手段

wasm32-wasip1（WASI の時計で動くが wasm-bindgen が使えない）、上流で web-time などに替えてもらう（本命）。

調べたこと · 積分器・再実行・結果の形式

host の生成と実行の関数はどれも公開されていた

数値積分のプラグインを差せる

  • MeIntegratorBackend（initialize・advance・sample・truncate_reset）は公開。Rumoca の BDF・RK45 のプラグインも公開
  • lowering → finish_fmi_component → instantiate → into_lease（初期化）→ numerical_setup → into_session → run_to_stop
  • driver（イベント・根探索・出力・時間切れ）は host が持つ。時間切れは wasm でも効く
  • JIT の可否の関数は pub(crate) → この道はネイティブでもインタプリタ

パラメータの上書き

SimOptions::param_overrides。DAE は使い回し（再コンパイル不要）、lowering と組み立てはやり直す。変えられるのは tunable なパラメータだけ。失敗の文言は 3 つ。

MAT v4 と Arrow

MAT v4（dsres）は OpenModelica の文書の rst と omc 1.27.1 の実物で配置を確かめた（Dymola の実物は【未確認】）。Arrow は OpenModelica の形式が 0.1 の開発版、arrow-rs 60 で依存が 25 増える → 持ち越し。

auto の切り替え

組み立て・初期化で方向微分が作れない（S011 は黙って切り替えていた）、積分の失敗、サンプラの食い違いで dopri45 に。積分の途中で方向微分が作れない失敗では切り替えない。ただし初期化での規則（Rumoca と同じ）に当たる GenerationOfFMUs は RK で進んで誤った結果になる（S013 で見直す）。

パラメータの上書き

--param k=2 で x(1) = exp(−2)、c = 2k が追従。--list-parameters は k と c。プリフライトも上書きを反映する（eval_dae_at は上書きを見ないので置き換えた）。lowering は 2 回のまま。
