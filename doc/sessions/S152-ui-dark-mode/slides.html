Svelte 版 UI のダークモード

ブラウザ・Desktop・Android で共用の UI が、OS の設定に追従する

色は CSS の変数 9 本。部品は変数を読むだけ
目的

このセッションでやること

  • OS の prefers-color-scheme に追従する
  • 手動で 明 / 暗 / OS に合わせる を選べる。選択は localStorage
  • CodeMirror・uPlot・sigma の色も追従する
  • 新しい依存は足さない。Leptos 版・Dioxus 版は対象外（S153）
決定と理由

配色は変数、JS の色は取り直して作り直す

部品やり方
全体theme.css の変数。暗は prefers-color-scheme と data-theme の 2 か所（スライドの CSS と同じ）
CodeMirrorEditorView.theme を変数で書く。darkTheme だけ Compartment で全タブに反映
uPlot軸・格子の色を渡すので、切り替えで作り直す
sigmaノード・辺・ラベル・吹き出しの色を変数から取り、作り直す
PNGいまの背景色で塗る（明は白のまま）
