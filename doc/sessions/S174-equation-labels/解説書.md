## 1. 目的

診断が方程式を名指す所（S7 の `GM-I7001`、S6 の `GM-E6001` の「過剰な方程式」「不足している方程式」、S8・S9 の方程式の並び）で、**方程式ではなく変数の宣言**（`SI.ElectricPotential v`、`Real i`）が並ぶ不具合を直す。S164 の監査が見つけ、[S173 の解説書 2.3](../S173-ui-unsupported-force-errors/解説書.md) が原因を `structure.rs` の `label()` と特定した。

やらないこと: 診断の文面の日本語化、UI、`.github/workflows/`、検査の段階の規則、Rumoca の改変と rev の変更。

## 2. 決定と理由

### 2.1 原因

`label()` は、方程式の来歴（`DaeProvenance`）の span が指すソース片を名前にしていた。書かれた方程式ではそれが方程式の文字になる。一方、Rumoca が生む方程式の span は次を指す。

| 由来（`origin()`） | span が指すもの | 前の名前 |
| --- | --- | --- |
| 接続（`ConnectionEquation`） | コネクタの変数の宣言 | `Real v` |
| 流れの和（`FlowBalanceEquation`） | コネクタの flow 変数の宣言 | `Real i`、`SI.Current i` |
| 束縛（`BindingEquation`） | 宣言の `= 式` の右辺だけ | `3 * k` |

### 2.2 直し方

`label()` に残差の式（`ExprId`）を渡し、由来が接続・流れの和・束縛のときだけ、**残差を式の形にして名前にする**（`structure.rs` の `residual_text` と `expression_text`）。残差 `l - r` は `l = r`、それ以外は `式 = 0`。

| 由来 | 前 | 後 |
| --- | --- | --- |
| 接続 | `Real v` | `a.p.v = b.n.v` |
| 流れの和 | `Real i` | `a.p.i + b.n.i = 0` |
| 束縛 | `3 * k` | `a.w = 3 * a.k` |
| 書かれた方程式 | `v = p.v - n.v` | 同じ（ソースの文字のまま） |

式は変数名、数値の定数、単項・二項の演算（`+ - * / ^` と要素ごとの版）だけを扱う。添字・関数・`if` などを含む式は直さず `f[i]`（i 番目の方程式）に落とす。上限は今までどおり 60 文字。

### 2.3 Rumoca から取れた情報、取れなかった情報

| 情報 | 公開 API | 使ったか |
| --- | --- | --- |
| 由来の区別 | `DaeProvenance::origin()`（`EquationOrigin` に写す `origin()` が既にある） | 使った |
| 残差の式木と変数名 | `DaeView::expression`、`ExpressionOperation`、`VariableView::name` | 使った |
| 元の `connect(a.p, b.n)` の文の span | 取れない。接続の方程式の span は宣言を指す（`ProvenanceSpan` は呼び出し側が選んだ「持ち主」の span） | 式の形で代えた |

Rumoca に足りない情報は無かった（connect 文そのものでなく式の形で足りる）ので、上流の下書き（`doc/research/upstream/`）は作らない。

### 2.4 診断の範囲は変えない

名前（`EquationRow::label`）だけを変えた。`file` と `range` は来歴の span のまま（接続・流れは宣言、束縛は右辺）で、LSP の波線の位置は変わらない。名前を使う所は `label` の読み取りだけ（`globe-mode-analysis` の S6〜S9 の診断の文面、`globe-mode-lsp`、`globe-mode-protocol`、graph）で、どれも文字列を表示するだけなので、直す所は無かった。`init.rs`（初期方程式）の呼び出しは `None` を渡して今までどおり。

### 2.5 前後（MSL）

| 診断 | 前 | 後 |
| --- | --- | --- |
| `CauerLowPassAnalog` の `GM-I7001`「微分した方程式」 | `SI.ElectricPotential v`（1 回）が 4 件 | `C1.p.v = L1.p.v`（1 回）, `L1.p.v = C2.p.v`（1 回）, … |
| `SimpleSolenoid` の `GM-E6001`「過剰な部分の方程式」 | `SI.Current i` など | `r.p.i + -p.i = 0`, `r.n.i + coil.p.i = 0`, `p.i = 0`, `n.i = 0` |

## 3. 図

```text
EquationRow.label の決まり方

origin = Source ───────────────→ ソースの該当箇所の文字（今までどおり）
origin = 接続 / 流れの和 / 束縛 → 残差の式木 → "l = r" または "式 = 0"
                                  └ 扱えない式 → f[i]
```
