Desktop を macOS でも測った

desktop.yml に macOS（arm64、署名なし）を足し、smoke と測定が通った

run 41994245407 で 3 OS のジョブとも成功。3 UI × 3 OS の欄がすべて埋まった
目的

このセッションでやること

  • P7 の完了条件「3 UI × 3 OS」で最後に残った「Svelte Tauri の macOS」
  • desktop.yml の matrix に macos-latest を 1 行足す。.app と .dmg、取得 smoke、UI の測定
  • やらない: 署名・公証・鍵、release.yml、UI のコード
決定と理由

決めたこと

項目決定理由
置き場既存の build の matrix に 1 行既存の step を再利用。作り替えない
bundle--bundles app,dmgdmg だけだと .app が片付けられる
起動.app の実行ファイルを直に起動環境変数と標準出力を渡せる
RSSps を 0.2 s ごとに見て最大time -l は WebKit のプロセスを含まないと考えた
Rust変えないsidecar は Contents/MacOS に並び、そのまま見つかった

署名

署名・公証はしていない

  • 実行ファイルは linker の ad-hoc 署名だけ（TeamIdentifier は not set）
  • Apple の案内: 開こうとしたあと、プライバシーとセキュリティの「このまま開く」を押す（確認日 2026-11-05）
  • Finder から開く経路と updater は CI で確かめていない【未確認】
