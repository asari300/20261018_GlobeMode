## 1. 目的

`globe-mode-syntax`（S268・S269）の CST は、名前を字句として持つだけだった。IDE の機能（定義ジャンプ・参照・補完）に使えるように、型名と式の成分参照の先頭を、クラスか部品に解決する。設計は [ADR-0039](../../adr/0039-native-cst-parser.md) の付記（S272）。Rumoca 側（`globe-mode-frontend` の `class_index`、LSP の定義ジャンプ）にはまだつなげない。

## 2. 決定と理由

| 項目 | 決定 | 理由 |
| --- | --- | --- |
| 置き場 | 新しい crate `globe-mode-resolve`（依存は syntax だけ） | syntax は字句と木に専念させ、B3 以降が resolve に依存できる |
| 型付き AST | `ast` にクラス・宣言・`extends`・`import`・`Name` を足した | resolve が節点の種類を直接見ないで済む |
| クラスの木 | 各ファイルの `within` で組む | `package.mo` のディレクトリ構造・単一ファイル・`Modelica 4.1.0/` の版つきディレクトリを同じに扱える。`package.order` は順序だけ |
| メモリ | ファイルごとに木を捨て、クラス情報と `Ref` だけ持つ | MSL 全体の木を持たない |
| 探索 | Modelica 3.6 の 5.3（宣言 → 受け継ぎ → import を内側から外へ、`encapsulated` で止まる、最上位、組み込み） | 仕様どおり |
| 継承 | 解決結果を覚え、解決中にまた来たら `Cycle`。`class extends` は外側の継承元の同名を継ぐ | MSL の `redeclare model extends` に必要（初回の未解決 2229 件のほとんど） |
| 型が変わる所 | 失敗に `redeclare` つきの `extends` や `replaceable` なクラスが関われば `Reason::Redeclare` | 今回は未対応と明示して数える |
