## 1. 目的

1. 文書・コメント・生成元に残っていた旧い言い回し（`平ら` に活用の語尾が付いた形）を、文脈に合わせて「平坦化」か「フラット」に置き換える。「flatten」を指すものは「平坦化」、入れ子でない形を指すものは「フラットな」にする（2026-11-16 にユーザーが決めた書き分け）。
2. 0.2.0 の公開（時期は未定。ユーザーの判断）に向けて、[README.md](../../../README.md)（英語の要約を含む）と [CHANGELOG.md](../../../CHANGELOG.md) の数字と「既知の限界」を、main の [frontend-diff.md](../../frontend-diff.md)・[libraries.md](../../libraries.md)・[msl-funnel.md](../../msl-funnel.md)・[msl-sim.md](../../msl-sim.md)・[roadmap.md](../../roadmap.md) と突き合わせ、誤りだけ直す。

## 2. 決定と理由

### 置き換えの規則

| 旧（`平ら` に続く形） | 新 | 理由 |
| --- | --- | --- |
| `にできた`・`にできる`・`にできない`・`にでき`・`にして`・`にした`・`にし終わって`・`にしない`・`にする` | 平坦化できた・平坦化できる・平坦化できない・平坦化でき・平坦化して・平坦化した・平坦化し終わって・平坦化しない・平坦化する | Modelica の flatten の動作。文字数が同じなので、表とスライドの折り返しは動かない |
| `になった`・`になり`・`になる`・`になっていれば`・`に戻った` | 平坦化できた・平坦化でき・平坦化できる・平坦化されていれば・平坦化できる状態に戻った | 「n 本が flat になる」の自動詞。「できた」にすると、本数の数え方（`msl:diff-frontend` の「自前で平坦化できた」）と同じ語になる |
| `名前に` ＋ `になり`・`になる`（入れ子の System の名前） | 名前に平坦化され・名前に平坦化される | 入れ子を外す処理（`外側.内側`）の受け身 |
| `FFT の 4 本は` ＋ `なまま` | FFT の 4 本は平坦化できたまま | S370 で FFT の 4 本は平坦化できるようになったが、Rumoca が通らず突き合わせていない、という意味 |
| `な` ＋名詞、`のまま`、`に` ＋入れる・持つ・渡す・書き直される | フラットな…、フラットなまま、フラットに… | 入れ子でない形（フラットなモデル、フラットな SSD・Component、`BinaryExpr` の連鎖） |

置き換えは正規表現の規則を順に当てた（順序が大事で、`名前に` ＋ `になり` を `になり` より先に当てる）。改行（CRLF）は変えず、`doc/frontend-diff.md` と `log/sessions/` は除いた。置き換えたあと、差分の行を目で通して文の続きを確かめた。
