## 1. 目的

[roadmap.md](../../roadmap.md) 末尾の表「機能の穴（P4）エディタの言語サービス」から、VS Code の折りたたみ（`textDocument/foldingRange`）と字下げの規則を埋める。Svelte の UI（CodeMirror）は触らない。

## 2. 決定と理由

| 項目 | 決定 | 理由 |
| --- | --- | --- |
| 実装の場所 | `globe-mode-lsp/src/folding.rs`。`lib.rs` は能力の宣言と 1 つの分岐だけ | 別の WP が `lib.rs` の `serve`・診断を触る |
| 字句・クラスの範囲 | `globe_mode_fmt::lex` と文書のアウトライン（`ClassOutline.range`） | 新しいパーサを書かない |
| 桁 | 出さない | 折りたたみは行だけで決まる。CRLF も `\n` で数えれば足りる |
| 終わりの行 | クラス・節・annotation の閉じは残す | 畳んだあとも `end M;` や `);` が見える |
| 字下げ | `indentationRules`（増やす・戻す）と、`//` の行の Enter で字下げしない `onEnterRules` | 折りたたみの `folding.markers` は LSP に任せるので入れない |

## 3. 図

```text
package P                  <- 0〜12 を畳める（end P; は残る）
  // a                     <- 1〜2 コメント
  // b
  model M                  <- 3〜11
    parameter Real x = 1;
  initial equation         <- 5〜6（次の節の手前まで）
    x = 1;
  equation                 <- 7〜11
    der(x) = -x;
    annotation(            <- 10〜11
      experiment(StopTime = 1));
  end M;
end P;
```

## 4. 再現手順

```bash
export CARGO_TARGET_DIR=<main>/.git-worktree/target-shared CARGO_BUILD_JOBS=2
cargo test -p globe-mode-lsp --test folding          # 入れ子のクラス・節・annotation・コメント、CRLF、全角
cd src/VSCode/globe-mode && mise exec -- pnpm test   # test/indent.test.mjs が字下げの規則を確かめる
```

## 5. 次回

- Svelte の UI（CodeMirror）の折りたたみは別の WP。
- 限界: 構文が壊れてアウトラインが引けない間は、クラスと節の範囲が出ない。`else` 単独の行は戻すが、`if` 式を行をまたいで書いた `else …` は対象外。
- inlay hint、call hierarchy、semantic tokens は未。
