折りたたみと字下げの規則

エディタの言語サービスの穴のうち、VS Code の 2 つを埋めた

折りたたみは LSP、字下げは language-configuration.json
foldingRange

畳める範囲

範囲終わりの行
クラスend の手前（end M; は残す）
equation・algorithm・public・protected次の節かクラスの end の手前。末尾の空行は含めない。initial は節に含む
複数行の annotation) だけの行は残す
コメント連続する // の行、複数行の /* */（kind は comment）
作り

新しいパーサは書かない

  • 字句は globe-mode-fmt の lex、クラスの範囲は文書のアウトライン
  • 行だけで決まるので、桁（UTF-16）は出さない。CRLF は \n で数える
  • 構文が壊れている間は、クラスと節は出ない（コメントと annotation は出る）
字下げ

indentationRules

向き行
次の行で増やすmodel などの宣言（; の無い行）、節の見出し、public・protected、if … then、for … loop など
この行で戻すend、else、elseif、elsewhen、節の見出し
Enter// の行のあとは字下げしない
