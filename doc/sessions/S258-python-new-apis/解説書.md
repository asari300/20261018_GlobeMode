## 1. 目的

この 1 日で facade に入った機能を Python（`globe-mode-py`、パッケージ `globe_mode`）から使えるようにする（[features](../../features.md) の線形化・コシミュレーション・SSP の行）。

## 2. 決定と理由

| 項目 | 決定 | 理由 |
| --- | --- | --- |
| `cosim(spec, *, stop_time, step, on_progress)` | `spec` は dict か `.json`／`.ssp` のパス。結果は `run_fmu` と同じ dict | 呼び方も戻り値も既存の `run_fmu` に揃える。`table(res)` がそのまま使える |
| 実行の共通部 | Rust の `run_observed`（GIL を離す・進捗と Ctrl-C・中断）を `run_fmu` から取り出して `cosim` と共有 | 同じ処理を 2 つ書かない |
| JSON のパス | Python 側で JSON のあるディレクトリからの相対に直す（CLI と同じ）。dict は今のディレクトリから | CLI の `globe fmu cosim` と同じ規則 |
| `.ssp` | Rust の `Ssp::open` に任せ、回し終わるまで展開先を持つ | CLI と同じ。展開は Rust 側（zip slip・サイズ上限は S253） |
| `Workspace.linearize(model, time=None, parameters=None)` | 戻りは `globe linearize --json` と同じキー。A〜D は numpy があれば ndarray、無ければ list | 新しい依存を足さない。行列は shape（行×列）を必ず保つ（行や列が 0 のときも） |
| 誤り | 変換できなければ基底の `GlobeModeError`（`.diagnostics`） | 新しい例外の型は足さない。モデルの誤りは `check` で見る |

## 3. 図

```text
cosim(spec) ─ dict / .json / .ssp ─► _native.cosim ─► Ssp::open（.ssp のとき）
                                              │
                                              ▼
                          run_cosim（別プロセスのワーカー）─► 列 ─► run_fmu と同じ dict
linearize(model) ─► _native.Workspace.linearize ─► JSON ─► dict（A〜D は ndarray か list）
```
