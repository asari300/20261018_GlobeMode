## 1. 目的

Desktop のシェル（`src/Rust/apps/desktop/`）のレビューの指摘 2〜6 を直す。レビューは読んで論証しただけなので、1 件ずつ失敗する試験で再現してから直した。

## 2. 決定と理由

| 項目 | 決定 | 理由 |
| --- | --- | --- |
| 中断（指摘 2・6） | 予算の無い要求も `Running` に登録し、`wait` が予算なしでも 0.2 秒ごとに合図を見る | 応えない検査で `Mutex` を握ったまま全体が止まっていた。検査に予算を付けない決まり（ADR-0018）は変えない |
| MSL の切り替え（4） | 作り直しに失敗したらライブラリを元に戻す | 壊れた MSL が残ると以後の要求が全部失敗する |
| 取得（5） | 取得中の旗で 1 つだけ、HEAD は 10 秒、展開中も取り消し | 二重の取得が同じ置き場を壊す |
| method（3） | `rpc` は `globe/*` の 18 個、`notify` は `didOpen` だけ。UI の呼び出しと試験で突き合わせる | 多層防御。UI が口を足すと試験が落ちる |
| CSP（3） | index.html の meta と同じ＋IPC の `connect-src` | 動いている CSP をそのまま使う。実機は desktop.yml・android.yml で確認 |

詳しくは [ADR-0023](../../adr/0023-desktop-and-web-process-layout.md) の S197。

## 3. 図

```text
UI --invoke(rpc, method)--> allow(method) --> Worker(Mutex) --> sidecar
UI --cancel_run-----------> Canceller --> $/cancelRequest, 2 秒で kill
```

## 4. 再現手順

```bash
mise exec -- cargo fmt --manifest-path src/Rust/apps/desktop/Cargo.toml --check
gh workflow run desktop.yml --ref feature/s197-desktop-review-fixes
gh workflow run android.yml --ref feature/s197-desktop-review-fixes
```

手元には webkit2gtk が無く Desktop のクレートはビルドできないので、tauri に依存しない `worker.rs`・`msl.rs`・`shell.rs` を別の小さなクレートに取り込んで試験を回した（13 件）。
