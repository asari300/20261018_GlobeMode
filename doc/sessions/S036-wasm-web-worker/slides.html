wasm をブラウザの Web Worker で回した

panic の後は Worker ごと作り直す
目的

このセッションでやること

  • ロードマップの候補 3（ブラウザ。P6 の前提）
  • --target web の糊と Web Worker で回す
  • panic の後に使える状態へ戻す
決定と理由

決めたこと

項目決定理由
糊同じ .wasm に --target webビルドは 1 回
Workerブラウザと Node で共通CI は Node で試せる
panicWorker を捨てて再生abort の後は使えない
Rust変えないlib.rs は S035 が持つ
結果

Decay（bdf）の t = 1

場所x(1) の誤差panic の後

Chromium（module Worker）2.7e-8restarts 1 で同じ値

MSL の分割読み込み（メモリ）は次へ持ち越した
