VS Code のパネルでも、結線の途中の点を動かせる

結線を選ぶとつまみが出る。ドラッグで動かし、線のダブルクリックで点を足す

Rust・LSP は変えない。つまみと点の決め方は共有、拡張は検査して LSP を呼ぶだけ
流れ

webview から文書まで

  • webview: 選んだ結線の途中の点に四角のつまみ（rect.wp）。ドラッグで moveWaypoint、線のダブルクリックで addWaypoint を postMessage
  • 拡張: edit.js が端・index（整数）・座標（有限で上限つき）・ends（2 点）を検査。file・class は受け取らない
  • globe/moveWaypoint・globe/addWaypoint の TextEdit を WorkspaceEdit で入れる（undo 可、保存しない）
共有と確かめ

diagram-waypoint.ts に出した

  • handlesOf・halfOf・addWaypointOf・handleNode を Svelte の DiagramView と webview が読む
  • ドラッグは S299 の diagram-drag.ts の onWaypoint のまま
  • 試験: pnpm test（検査・共有の関数）と e2e（足して動かすと Line(points) が変わり、undo で戻る）
