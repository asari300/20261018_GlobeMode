S304 の後に main に入った機能（S297・S301・S303・S305〜S309・S311・S313）のうち利用者に見えるものを、[README.md](../../../README.md)（日本語と英語の要約）と [CHANGELOG.md](../../../CHANGELOG.md) に反映する。正典は [features.md](../../features.md) と [roadmap.md](../../roadmap.md)（各セッションが更新済みなので触らない）。

## 2. 決定と理由

| 項目 | 決定 | 理由 |
| --- | --- | --- |
| native の検査 | 「試し（既定は Rumoca）」と明記し、S6 まで・実行に未接続・wasm と UI から選べないことを書く | [ADR-0039](../../adr/0039-native-cst-parser.md) の付記と S313 の範囲どおり |

| 古い記述 | 「できていないもの」の Track B を、native の検査につながったことに合わせて直した | S305 で flat・dae が検査につながった |
