S316 · 2026-11-15 · P8

結線をマウスなしで足す

部品を選んで c、コネクタを Tab で選んで Enter を 2 回。

c → Tab → Enter（始点）→ Tab → Enter（終点）
操作

キーと見え方

キー動き
c（部品を選んで）その部品のコネクタの選びに入る
Tab・矢印（Shift+Tab で戻る）候補を切り替える
Enter始点を決める。次に別の部品の終点を決めると結線
Escやめる
+（結線を選んで）中点に途中の点を足す

選び中のコネクタは枠、図の下の role="status" の文で読み上げる。

決定と理由

決めたこと

  • 状態の進め方は diagram-connect.ts に置き、webview と Svelte が共有する
  • 出すメッセージはドラッグと同じ connect。Rust・LSP は変えない
  • Svelte も部品の Enter はパラメータにした（S175 の試験に部品の Enter は無く、衝突なし）
  • 途中の点は + で中点に足すだけ。動かす操作は次回
