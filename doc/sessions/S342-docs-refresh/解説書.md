## 1. 目的

S322〜S334 の成果のうち、利用者向けの文書にまだ無い・古いままのものを反映する。コードは変えない。

- [CHANGELOG.md](../../../CHANGELOG.md): 複数ソルバの比較（S322・S323・S327・S328）と Track B の進捗（S324〜S334）。
- [README.md](../../../README.md)（英語の要約を含む）と [features.md](../../features.md): 複数ソルバの比較（使い方の例は README に既にある）と Track B の数字。
- [roadmap.md](../../roadmap.md): Track B の欄が 1 セルに S268〜S334 の経緯を全部入れていて読めないので、今の数字と残りの要約にする。

## 2. 決定と理由

| 項目 | 決定 | 理由 |
| --- | --- | --- |
| 複数ソルバ（S322・S323・S328） | README・features・CHANGELOG に既にあったので足さない | S326 と S328 が足し済み。使い方の例 `globe simulate --solvers … --parallel --compare 6 -o runs/` も README にある |
| 複数ソルバ（S327） | CHANGELOG に 1 項目、README・features に 1 文ずつ | `--solvers -o DIR` の事前の検査、ソルバ名の正規化、1 つだけの `--compare` を断るのは利用者に見える挙動。#118 は LSP の URI |
| 古い 1 文 | README の英語の「比較は最大の相対差を出さない」を S328 に合わせて直した | 日本語側は S328 の後に直してあったが、英語側だけ古かった |
| Track B（CHANGELOG） | S324・S329〜S334 を 1 項目にまとめ、今の数字を書く | 利用者に見える挙動は変わらない（検査は `--frontend native` の試しのまま）ので、内訳は ADR に任せる |
| Track B（README・features・既知の限界） | 279 本を 471 本に、Rumoca と両方で通った分の一致を S334 の数字に | 古い数字が残っていた |
| roadmap の Track B の欄 | 約 4,500 字を、B1〜B4 の今の数字・残り・製品へのつなぎの要約にし、経緯は ADR-0039 へ | 経緯の数字は ADR-0039 の付記に既にある。「機能の穴（Track B）」の行も同じ形にした |
| ADR-0039 | 付記 S342 を足した（数字の推移の表と、主題別の付記の案内） | roadmap から外す推移の表を、情報を消さずにここへ置く。付記が書いた順（S334 が S269 の前にある）で読みにくかった |
| 外した「残り」 | `GM-E` の番号が無い、定義ジャンプ・ホバーが未、`Frontend` の feature `native` が無い、B3 の残りが後ろで宣言したレコードなど | S296・S305・S324・S312〜S334 で済んでいた。ADR の付記 S342 に外した理由を書いた |
| 既存の markdownlint の警告 | 触ったファイルの分（表の中の `\|`、空行、裸の URL）を直した | 警告 0 にするため。意味は変えていない |
