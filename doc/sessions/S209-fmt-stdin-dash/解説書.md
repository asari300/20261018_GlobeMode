## 1. 目的

S199 は `globe fmt` / `globe lint` の標準入力を `-` を明示したときだけにしたが、`--json` のパスなしだけは標準入力を読むまま残した（[S199 の解説書 2.3](../S199-cli-review-fixes/解説書.md)。ウェブアプリが頼っていたため）。ユーザーが 2026-11-07 に「`-` を必須にすべて揃える」と決めた。`--json` の有無に関係なく、パスか `-` のどちらかを渡す。どちらも無ければ使い方を 1 行出して終了コード 2。

## 2. 決定と理由

| 項目 | 決定 | 理由 |
| --- | --- | --- |
| CLI | `paths_or_stdin` から `[] if json` の腕を消した（`json` の引数も不要になった） | 例外 1 行を消すだけで揃う。`--json` はパスありのときの出力形式でもあるので、入力の決め方とは切り離す |
| 呼び出し元 | 6 つのウェブアプリの引数を `--json -` に | 契約は `globe fmt --json -`（[web-apps.md](../../web-apps.md)） |
| Rust のウェブアプリ 4 種 | 直さない | `globe-mode-fmt` を `path` 依存で直接呼ぶので CLI を通らない（S199 の表の「10 種」は、CLI を子プロセスで呼ぶ 6 種と合わせた数え方で、Rust の 4 種は影響が無い） |
| 使い方の文面 | `error: 対象のパスが無い。使い方: globe fmt <FILES…>…か globe fmt -（標準入力。--json でも - が要る）` | 前の文面に括弧 1 つ足しただけ。試験は `globe fmt -` を含むかで確かめる |
| 古い試験 | marimo の `test_format_inserts_origin` が S062 から落ちていた（例題が origin を既に持つ）。origin の無い入力で確かめ直した | `-` とは無関係だが、このアプリの試験を回すために直した |

## 3. 呼び出し元と CLI の前後

呼び出し元（`grep` で洗った。VS Code の拡張は `globe lsp`、CI・`mise.toml` は `fmt --check src/Modelica`、xtask・Python の `globe_mode`・Svelte は CLI を呼ばない）:

| 場所 | 呼び方 | 直したか | 試験 |
| --- | --- | --- | --- |
| `src/Python/fastapi_fmt/app.py` | `fmt --json`、`lint --json` | `--json -` | `uv run pytest`: 直す前に 3 本落ち（HTTP 500）、直して 6 本通る |
| `src/Python/streamlit/globe_cli.py` | 同 | 済 | `uv run pytest` 2 本通る |
| `src/Python/marimo/globe_cli.py` | 同 | 済 | `pytest test_fmt_app.py` 3 本通る（古い 1 本を直した）、`marimo check`・`python fmt_app.py` エラー 0 |
| `src/Elixir/phoenix_fmt/lib/phoenix_fmt/globe.ex` | 同 | 済 | `mix test` 9 本通る |
| `src/Gleam/wisp_fmt/src/wisp_fmt/engine.gleam` | 同 | 済 | `gleam test` 5 本通る |
| `src/Astro/fmt/src/lib/globe.ts` | 同 | 済 | `pnpm test` 3 本通る |
| `src/Rust/apps/web-{actix,axum,loco,rocket}` | CLI を呼ばない | 不要 | 回していない（影響が無いので） |

CLI の前後:

| 呼び方 | 前（S199） | 後（S209） |
| --- | --- | --- |
| `globe fmt -` / `globe lint -` | 標準入力 | 同じ |
| `globe fmt --json -` / `globe lint --json -` | 標準入力 | 同じ |
| `globe fmt --json` / `globe lint --json`（パスなし） | 標準入力 | **使い方を出して終了コード 2** |
| `globe fmt` / `globe fmt --check` / `globe lint` | 使い方、終了コード 2 | 同じ |
| `globe lint src --json` | ディレクトリを lint して JSON | 同じ |
