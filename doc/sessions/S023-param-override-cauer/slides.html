S023 · 2026-10-27 · P3

パラメータの上書きと CauerLowPassSC

CauerLowPassSC が再開で止まる原因は、diffsol の最初の刻みの見積もりが刻みの下限を割ること。下限の 10 倍まで持ち上げて直した。--param の時間イベントは Rumoca の DAE の段が原因で、直さずに上流の候補にした

esdirk34・trbdf2 の CauerLowPassSC が t = 60 まで進み、bdf との差 5.4e-9。全体 356 本の esdirk34 は 282 → 286 本実行、管 273 → 277（サイリスタの整流器 4 本）
目的

このセッションでやること

  • S022 の残し: esdirk34・trbdf2 の CauerLowPassSC が t = 1.05 のイベントの後に「Step size is too small」で止まる
  • S022 の副次の発見: globe simulate --param V.startTime=… が効かない
  • 調査はサブエージェント（Sonnet、high）2 本に分けた: CauerLowPassSC の計測と直し / --param の原因
原因

再開の最初の刻みが下限を割っていた

どこ何をしている結果
rk.rs の initial_state()再開ごとに diffsol の set_step_size で最初の刻みを見積もるh0 = 0.01·‖y‖/‖f‖
t = 1.05 の再開状態はほぼ 0（1e-22）、導関数は 4e4。重み付きで d0 = 2.5e-5、d1 = 1.25e11h = 2e-16
runge_kutta.rs:841,866刻みが下限 1e-13 より小さいと誤り1 歩も試さずに止まる

S022 で疑った試しの点の NaN や host の失敗の記憶ではなかった（再開の後に右辺を 1 度も呼んでいない）

決定と理由

決めたこと

項目決定理由
最初の刻み下限の 10 倍を下回れば 10 倍に持ち上げる使えない刻みを上げるだけ。通っていた例題の出力はバイト単位で同じ
回帰の試験TinyStateRestart を esdirk34・trbdf2・tsit45 で直す前は 3 つとも同じ所で落ちる最小の形
--param の時間イベント直さない。上流の候補 16Rumoca の DAE の段が時刻を既定値で畳む。手元で直すとコンパイルし直す設計の変更になる
