FMU export を facade と各言語に

S110 の埋める順の 5。CLI にしか無かった FMU の書き出しを facade に置く

export_fmu が C・Zig・Julia・Elixir・Gleam・Python から呼べる
目的

このセッションでやること

  • FMU の書き出しは globe-mode-fmi の export と globe fmu export だけにあった
  • facade に export_fmu を足し、CLI もそれを呼ぶ（挙動は同じ）
  • C ABI・NIF・Python と各言語の包み、試験を 1 本ずつ（Decay、2.0、build なし）
  • wasm はファイルを書けないので対象外。globe-mode-fmi の中身は触らない
決定と理由

口ごとの形

口形
facadefeature fmu: FmuOptions・export_fmu・Workspace::export_fmu（wasm は引かない）
設定{"fmi_version": 2, "build": false, "targets": [], "fmi_headers": null}（省略可）
C ABIgm_export_fmu(ws, model, out_dir, options_json) → {"path"} か {"error"}
NIFexport_fmu/4（DirtyIo）。Elixir は export_fmu/3・/4
PythonWorkspace.export_fmu(model, out_dir, **options) -> Path
CLIコンパイルの診断はそのまま、書き出しだけ facade に

外部の依存の追加は 0。CI の定義は変えていない
