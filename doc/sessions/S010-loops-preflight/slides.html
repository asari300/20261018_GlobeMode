解く系を BLT に分け、非線形のループの反復変数の start 値を見る

ブロックの分け方はマッチングの選び方によらない（Duff 1981。並べ替えの乱択テストで確かめた）。最小の tearing は NP 困難なので貪欲法（O(E + k log k)）。start 値のある変数を先に選ぶので、警告は「避けられないもの」に近い。解析できない（S7 の打ち切り、長さの不一致、完全マッチングが無い）ときは LoopReport::skipped に理由を残す。

決定と理由 · S9 の解く系

インデックス 2 以上は Pantelides 法の最高階の系で数える

最高階の系（状態選択の前の見込み）

  • 行: 方程式 e を S7 の differentiations[e] 回微分したもの
  • 列: 各族の最高階 orders[u]
  • 行 e(c) は、元の参照（階数 o）が c 回の微分で o+c になり、それが orders[u] と等しいものだけを未知数として参照する（ADR-0011 の「j 回の微分は族の階数 o..=o+j を参照する」の最高階だけ）

MSL では、S7 でインデックス 2 以上だった 154 本（2 が 58・3 が 95・4 以上が 1）をこの系で数えた。

決定と理由 · 線形・非線形

残差の式木を族の単位で歩き、広めに非線形とみなす（DaeStructure::nonlinear）

式非線形とみなす未知数
加減・符号・配列の構築・添字各項の和（線形のまま）
積 a*b両辺に未知数があれば両辺とも
商 a/b分母に未知数があれば全部
冪 a^b底に未知数があり指数がリテラル 1 でないか、指数に未知数があれば全部
組み込み・利用者の関数引数の全部（abs・min・max も広めに）
if 式分岐の和。条件の関係演算はイベントで凍結されるので非線形にしない。noEvent の中の条件は凍結しないので、その if 式は全部
homotopy(actual, simplified)両方の和
状態 x・パラメータ・離散・pre・time既知（未知数ではない）

選ばなかった案: スカラーの単位の判定（配列を要素ごとに展開すると MSL の大きなモデルで遅い）、Rumoca の phase_structural::sort と tear_algebraic_loop をそのまま使う（analysis crate は Rumoca に依存しない約束。wasm32 と Track B でも同じ検査を使う）。

費用: ChuaCircuit の extract は 0.97 ms → 1.5〜2.3 ms。弱さ: 方程式ごとの「非線形に現れる未知数の集合」しか持たないので、v = R*i の R がループの外で決まっても i を非線形とみなす（omc との食い違いの主な見込み。S13）。

結果 · Rumoca で分かったこと

Rumoca v0.10.2 で見つけた 3 つの事実（2026-10-19）

algebraic_loops が空

phase_structural::analyze は StructuralDiagnostics::algebraic_loops を一度も埋めない（宣言だけ）。ループは ES002 の警告「algebraic loop detected: {n} equations must be solved simultaneously」として積むだけ。

GlobeMode の照合（Checker::reference_structure の loops）は文言から n を読む。上流への報告の候補に足した（ユーザーが出す）。

experiment を黙って捨てる

sanitize_experiment_settings が非有限・StopTime < 0・Tolerance ≤ 0・Interval ≤ 0 を捨て、StopTime < StartTime なら StopTime を捨てる。値は数の字面だけ、根のクラスの annotation だけを見る。

GlobeMode は Dae::source_map() の本文を Rumoca の parser で読み直す（S08）。

字面の 0 除算は ED019

parameter Real T = 1 / a（a = 0）は、使われていなくても flat の定数評価が「division by zero」を出し、DAE への変換が ED019（cannot be evaluated）で止める。

ADR-0007 のコードの規則で GM-U0001（未対応）に振り分けられ、S10 に届かない。モデルの誤りなので、文言で GM-E に戻すかは S011 の候補 6。

ほかに使った API: NumericEvaluator（静的な値だけ。非有限は InvalidValue、関数の assert は AssertionFailed、外部関数は ExternalFunction）、discrete_value_owner の branches()、collect_model_names（Session::model_names() は解決できない文書があると Err なので、構文木から名前を集める）。出典は doc/research/rumoca.md。
