UI の Icon ビュー

カーソルのクラスの annotation(Icon(…)) を「説明」パネルの上に描く

Rust は形のデータを返し、UI が要素を組み立てる
道

どこで何をするか

場所役割
globe-mode-fmticon(src, 名前, library)。字句解析だけで図形を読み、extends の基底を 1 段重ねる
wasm / sidecaricon と globe/icon（rpc は 24 本）
modelicaDocs説明と一緒に 300 ms 止まったら引く
IconView.sveltey を反転して svg の要素に。{@html} なし
要素

読む図形

  • Rectangle・Ellipse・Line（矢印）・Polygon・Text（%name）・Bitmap（枠とファイル名）
  • 読めない値・要素は飛ばして続ける。壊れた annotation でも空のアイコン
  • 塗りは Solid だけ、Bezier は折れ線、DynamicSelect は最初の引数
  • MSL の Blocks の 50 クラスはすべて空でない
試験

試験と再現

cargo test -p globe-mode-fmt --lib icon
mise run wasm:node          # MSL の Gain の polygon
mise run ui:check           # test_ui.py の icon_view
