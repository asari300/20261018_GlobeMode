maturin の --zig で glibc 2.28 に link する

manylinux_2_39 → manylinux_2_28
目的

このセッションでやること

  • S077 の持ち越し: manylinux_2_39 の wheel は Debian 12（glibc 2.36）や RHEL 9（2.34）に pip で入らない
  • ランナー（ubuntu-24.04、glibc 2.39）でビルドすると新しい記号が混じる
  • release.yml の Linux の wheel の段だけを変える。Rust のコードは変えない
