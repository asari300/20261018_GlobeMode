目的

このセッションでやること

  • sidecar の initialize に根を渡す（--root、GLOBE_ROOT、カレントディレクトリ）
  • UI の format() から固定の indent を外す。ブラウザ版だけ 2 を補う
  • command reload_config と「設定を読み直す」ボタン
  • Linux の smoke で cfg=ok を確かめる
決定と理由

決めたこと

項目決定理由
根--root、無ければ GLOBE_ROOT、無ければカレントディレクトリ「フォルダを開く」は S141。起動時の最小の形
渡し方rootPathLSP は rootUri と rootPath の両方を読む。URI の組み立てを Desktop に足さない
LSP の直しglobe/format・globe/lint が設定を土台にするUI が呼ぶ独自の要求は S130 で設定を見ていなかった。params のキーがあれば優先
UIformat() は引数なし。WorkerBackend が 2 と true を補うwasm に設定ファイルは無い
