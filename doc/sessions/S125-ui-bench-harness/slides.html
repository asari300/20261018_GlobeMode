見つけたこと

Linux の Desktop は LANG=C で画面が空

  • 5 回の run で Linux だけ時間切れ。UI が command を 1 度も呼ばない
  • 切り分け: __TAURI__ はある、module は読める、CSP の違反は無い
  • 初めからの error を集めると RangeError: invalid language tag: C
  • WebKitGTK の既定の言語が C になり、CodeMirror の Intl.Segmenter が投げる
  • 測定の手順に LANG=en_US.UTF-8。製品の直しは持ち越し
