決定と理由

診断の行は「行の中に本物の button」

案判断
tr tabindex=0 role=button表の意味（行）が壊れる
先頭のセルに button.jump採る。Enter・Space の click が tr の既存の onclick へ泡立つ。マウスは今までどおり
  • 飛んだ後は view.focus() でエディタ。範囲の無い診断には button を出さない
  • 参照の一覧（Shift+F12）も行番号が button
ショートカット

キー動作

Shift+Enter検査
.止める（実行中だけ）

O開く
  • capture で受ける。修飾キーつきなので入力欄で誤爆しない。IME 変換中と Alt つきは無視
  • ボタンに title と aria-keyshortcuts。Ctrl+R・W・F5 は使わない
プロットと読み上げ

canvas の aria-label と完了の 1 行

Decay のプロット。信号 1 本: x。time の範囲は 0 から 1。x は最後 0.3679、最小 0.3679、最大 1。
  • 文面は純粋な関数 plotLabel（表示の整形。計算は Rust のまま）。5 本を超えると「ほか n 本」
  • 完了の文は aria-live=polite。失敗は alert、未対応と止めたは status が読むので入れない
  • フォーカスの輪郭は --accent の 2px（明 5.2、暗 7.5 の比）。エディタも同じ
