P5b の FMU を CLI で作れるようにした

cdylib・examples/md.rs・zip を手で組むのをやめ、MSL は使うファイルだけを入れる

globe fmu export --runtime p5b
使い方

旗は 2 つ

  • --runtime p5a|p5b。既定は p5a で、今までの出力は変わらない。
  • --runtime-lib: globe-mode-fmu の共有ライブラリを渡す。無ければ cargo build --release -p globe-mode-fmu をその場で呼ぶ。
  • cargo が無い、ソースの作業ツリーの外なら、理由を出して終了コード 2。
  • p5b に --build などを付けても終了コード 2。

結果

20 本は 16 本のまま

  • FMPy の ME・CS で globe simulate と管で比べ直した。P5b は 16 / 20。
  • 落ちる 4 本は S237 と同じ。絞り込みで足りないクラスが出た例題は無い。
  • md を resources/lib から作るので、足りなければ export が断る。
試験と CI

足したもの

  • fmu_export.rs: Decay の P5b を globe fmu run で x(1) = e⁻¹、MSL の Accelerate が 50〜500 ファイルで mass.s(1) = 1。
  • fmu-export.yml の P5b の step と fmu_msl_check.py は CLI を呼ぶ。examples/md.rs は消した。
