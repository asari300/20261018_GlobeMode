実行とプロットの UI

計画書の WP-D の最小の形。「実行」ボタン、CSV の列分け、uPlot、信号のチェックボックス

結果は wasm の CSV を UI で列に分けて描く。Rust には触れていない
目的

このセッションでやること

  • App.svelte に「実行」ボタン（Backend.simulate({ model })、ソルバは既定）
  • src/lib/plot/ に csv.ts（CSV を列に分ける）と Plot.svelte（uPlot）
  • 信号のチェックボックス（既定は最初の 3 本）。ズームは uPlot の既定
  • 2 軸・凝った凡例・MAT v4 は入れない。実装は Sonnet のサブエージェント 1 人
決定

決めたこと

項目決定理由
部品uPlot 1.6.32（MIT、依存なし）軽く、GPL・NC が 0 のまま。npm は 58 パッケージ
CSVUI 側で解析。有限でない値は null にして線を切るwasm に列ごとの API を足すと Rust と protocol に触る
選択setSeries(i, { show })凡例の独自 UI は入れない
10 万点の試験experiment(Interval = 0.01) の 4 状態を実際に実行本番に試験用の入口を足さず、実際の経路で測る
