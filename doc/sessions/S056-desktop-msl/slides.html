Desktop で MSL を読む

sidecar が読んだ MSL に ChuaCircuit を検査・実行させ、RSS の基準値を記録する

P4 の完了条件「RSS の基準値を記録する」を埋める
目的

このセッションでやること

  • 「MSL を読む」ボタン（backend.library）が Desktop でも動くようにする
  • MSL は JSON で送らない。sidecar が起動時に --library / GLOBE_LIBRARY で読む
  • CI の smoke で MSL を読んだ後の最大 RSS（アプリ・sidecar）を記録する
決定と理由

決めたこと

項目決定理由
commandlibraries（起動時のパスの一覧）sidecar を叩かず、ロックを待たずに答えられる
library()一覧が空でなければ resolve、空なら rejectApp.svelte を変えずにボタンが動く。JSON は捨てる
smoke の指定環境変数 GLOBE_DESKTOP_SMOKE_MODEL最小の変更。無ければ今までの D
RSSアプリと sidecar の VmHWM を各段の後に表示time -v はプロセス木の最大 1 つだけ
