FMU を UI から書き出す

S140 の点検の順位 4。FMU export は CLI と各言語 API にだけあった

ブラウザは wasm の zip をダウンロード、Desktop は LSP が書く
目的

このセッションでやること

  • ボタン「FMU を書き出す」（Backend.exportFmu(model, fmiVersion)）
  • ブラウザで出来るかを先に cargo check --target wasm32 で確かめる
  • 結論を ADR-0031 に 1 段落。--build・FMU import は持ち越し
決定と理由

ブラウザでも出来た

項目決定理由
wasm32globe-mode-fmi/export は check が通ったテンプレートは文字列を返すだけ。ファイルに触るのは write_fmu だけ
バイト列fmu_bytes → export_fmu_bytes → wasm の export_fmuzip をメモリ上で組む。中身は build 無しの write_fmu と同じ
DesktopLSP の globe/exportFmu {model, fmiVersion, outDir}facade の export_fmu をそのまま呼ぶ
buildUI に持たないブラウザにはプロセスもファイルも無い。Desktop も持ち越し
