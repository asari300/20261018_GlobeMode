ライブラリの木に入れ子のクラスと検索

S164 の穴 1。ファイルの中のクラスが木に出て、検索欄から Enter だけで開ける

木に出ない例題は 123 本から 0 本（553 本中）
現状

何が困っていたか

  • 木は 1 ファイル 1 項目。Blocks/package.mo の中の Examples（32 本）や Sources.mo の Sine に行けない
  • MSL の例題 553 本（partial を除く）のうち 123 本が木から選べない
  • 検索欄が無い。完全修飾名を知らないと、モデル名の欄に打つしかない
決定と理由

決めたこと

項目決定理由
入れ子の取り方字句解析と文の切り出し（整形器の道）で、ファイルの中のクラス定義を全部取る依存 0 のまま wasm で動く。Rumoca の構文解析は使わない
索引読み込み時に 1 回。展開は索引の直下の子を引くだけ検索が入れ子を含めて引くには全部が要る。軽い
開き方定義するファイルを開き、モデル名に完全修飾名S127 と同じ。検査・実行へ続く
検索名前の部分一致、. を含めば完全修飾名。計算は Rust、50 件Svelte に業務ロジックを置かない
