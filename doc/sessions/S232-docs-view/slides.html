UI の「説明」パネル

カーソルのあるクラスの annotation(Documentation(info, revisions)) を右に出す

取り出すのは Rust、洗うのは UI の白リスト
道

どこで何をするか

場所役割
globe-mode-fmtdocumentation(src, 名前) と class_at(src, offset)。字句解析だけで生の HTML を返す
wasm / sidecardocumentation と globe/documentation（rpc は 23 本）
modelicaDocsカーソルが 300 ms 止まったら引く。木で開いたクラスも同じ道
html-sanitize.tsDOMParser で読み、白リストの木に組み直す
安全

第三者の HTML を信用しない

  • タグは白リストだけ。属性は a の href（http・https・modelica）以外を捨てる
  • script・style・iframe は中身ごと落とし、知らないタグは外して中身だけ
  • img は alt の文字に。画像は今回は出さない
  • 出力は文字列を作らない木。{@html} を使わず、要素と文字列として描く
