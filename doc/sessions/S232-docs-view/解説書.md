## 1. 目的

[roadmap](../../roadmap.md) の「機能の穴（P8）拡充」のうち Documentation ビュー。カーソルのあるクラスの `annotation(Documentation(info = "…", revisions = "…"))` の HTML を、UI の右の「説明」パネルに出す。MSL は Documentation が豊富なので、ライブラリを読んで学ぶ道になる。

## 2. 決定と理由

| 項目 | 決定 | 理由 |
| --- | --- | --- |
| 取り出す所 | `globe-mode-fmt` の `documentation(src, 完全修飾名)` と `class_at(src, offset)`。字句解析と文の切り出し（`structure::class_spans`）だけで読む | 整形器が持つ字句解析を再利用し、Rumoca の構文解析も新しい依存も足さない。構文が壊れた文書では引けない（LSP の他の機能と同じ限界） |
| 値 | `info`・`revisions` の生の HTML。Modelica のエスケープ（`\"` `\\` `\n` `\t` など）を戻し、`"a" + "b"` はつなぐ | HTML は洗わない。洗う場所を UI の 1 か所に決める |
| クラスの選び方 | 名前（完全修飾名）か、空なら文書の行・列にあるいちばん内側のクラス。文書のクラスを先に、無ければライブラリのクラスから | カーソルで引けば、ライブラリの木・検索で開いたクラスも「開くと宣言の行にカーソルが置かれる」（S186）同じ道で引ける |
| 口 | wasm `documentation(class, text, line, character)`、LSP `globe/documentation {class?, file?, line?, character?}`（`RPC_METHODS` は 22 から 23）、`Backend.documentation(cls, at?)` 1 つ | 共通の関数は `globe-mode-lsp::documentation`。hover・definition と同じく wasm と sidecar で同じ形 |
| 更新 | `lib/docs.ts` の `modelicaDocs`。入力かカーソルの移動が 300 ms 止まったら取り直す（折りたたみの往復と同じ形。新しい要求が来たら古い応答は捨てる） | App は拡張 1 行・状態 1 つ・要素 1 つの追加だけ。保存・開く・タブには触れない |
| 安全 | `lib/html-sanitize.ts`: `DOMParser`（不活性な文書）で読み、白リストのタグだけを素のデータの木に組み直す。`DocsPanel.svelte` が要素と文字列として描く。**`{@html}` に文字列を渡さない** | ライブラリは第三者のファイル。HTML の文字列を作り直さないので、組み立てた文字列を再び解釈させる経路が無い |
| 白リスト | p・br・b・i・em・strong・sub・sup・ul・ol・li・h1〜h6・table・thead・tbody・tr・td・th・pre・code・hr・blockquote・dl・dt・dd と、http・https・modelica の href だけの a（`target="_blank" rel="noopener noreferrer"`）。img は alt の文字に置き換え。属性は a の href 以外すべて捨てる。script・style・iframe・object・embed・svg・math・noscript・template・title は中身ごと、知らないタグは外して中身だけ | 依頼の一覧に sub・sup・hr・blockquote・dl・dt・dd・thead・tbody を足した（MSL の下付き文字や定義リストが読めなくなるため）。DOMPurify は足さない |
| 画像 | 今回は表示しない（`<img src="modelica://Pkg/Resources/…">` は alt の文字に） | `modelica://` を実ファイルに解決する道が無い。持ち越し |
| レイアウト | `.work` の右に 16 rem のパネル（小画面は下に 10 rem）。`main` の最大幅を 60 rem から 76 rem に | 左のツリーとエディタに並べるとエディタが細くなるため |

## 3. 図

```text
エディタ（CodeMirror） ─ 300 ms ─► modelicaDocs ─ setFile ─► Backend.documentation("", {file, line, character})
                                                                   │
ブラウザ・Android  wasm Workspace.documentation(class, text, line, ch) ─┐
Desktop            rpc globe/documentation ─ sidecar ──────────────────┤
                                                                       ▼
                         globe_mode_lsp::documentation ─► globe_mode_fmt::{class_at, documentation}
                                                                       │ {class, info, revisions}（生の HTML）
        html-sanitize.ts（DOMParser → 白リストの木） ─► DocsPanel.svelte（要素と文字列。{@html} なし）
```

## 4. 再現手順

```bash
export CARGO_TARGET_DIR=…/target-shared CARGO_BUILD_JOBS=2
cargo test -p globe-mode-fmt --lib documentation
cargo test -p globe-mode-lsp --lib documentation
cargo test -p globe-mode-wasm --test decay documentation

cd src/Svelte && pnpm check && node --test tests/test_html_sanitize.mjs

```

## 5. 次回

- 画像（`modelica://…/Resources/…`）と、`modelica://` のリンクを木のクラスへ飛ぶ操作は未対応（リンクは `modelica:` のまま `_blank` で出る）。
- VS Code の拡張には説明の面を足していない（LSP の `globe/documentation` はある）。
- 継承したクラスの Documentation や、`extends` 先の説明は引かない。
- 構文が壊れた文書では引けない。
