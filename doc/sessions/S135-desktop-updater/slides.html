S135 · 2026-11-03 · P4

Desktop の自動更新

Tauri 2 の updater。署名は secret があるときだけ

latest.json
目的

このセッションでやること

  • features.md の Desktop の「署名と自動更新は未」
  • Release に付けた .deb・.msi から自動で入れ直せる仕組み
  • 鍵は作らない・コミットしない。作り方は解説書と ADR-0023 に
決定と理由

どこに何を置いたか

項目決定
プラグインtauri-plugin-updater 2.14。Desktop だけ（Android には入れない）
公開鍵tauri.conf.json の pubkey。空ならプラグインを入れず UI は「未設定」
配布release.yml に desktop-ui と desktop（.deb・.msi）
署名secret を env に写し、あれば createUpdaterArtifacts で .sig
latest.json.sig があるときだけ。キーは linux-x86_64-deb・windows-x86_64-msi
JSnpm を足さず window.__TAURI__.updater
図

release.yml の流れ

再現手順

dry run で確かめる

gh workflow run release.yml --ref feature/s135-desktop-updater
gh run download <run-id> -n globe-desktop-linux
gh run download <run-id> -n globe-desktop-windows

手動実行は従来どおり Release を作らない（タグの push のときだけ付ける）

ユーザーがやること

鍵と secret

cargo tauri signer generate -w ~/.tauri/globemode.key
gh secret set TAURI_SIGNING_PRIVATE_KEY < ~/.tauri/globemode.key
gh secret set TAURI_SIGNING_PRIVATE_KEY_PASSWORD
# ~/.tauri/globemode.key.pub を tauri.conf.json の pubkey に書く
