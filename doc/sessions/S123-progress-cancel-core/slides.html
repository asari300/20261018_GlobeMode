進捗と中断の 1 段目

ADR-0033 の実装の順の 1: core・IR・exec・facade

止めないときの結果はビット単位で同じ、速さは +1.2%
目的

このセッションでやること

  • 実行の進捗（段と積分の時刻 t）を呼び手に知らせる
  • 呼び手の持つ CancelToken で実行を途中で止める
  • 置き場所は core（GM-I11004）、IR（Termination::Cancelled）、exec（run_observed）、facade（simulate_observed）
  • wasm・UI・Python・C/NIF・LSP は次の段へ持ち越す
決定と理由

決めたこと

項目決定理由
見る場所段に入る前、auto の回し直しの前、session の道の積分器の 1 歩の前lowering と組み立ての中は Rumoca の中で見られない
session の道積分器を包む Observed が advance の前に見るadvance_to の区切りは刻みの上限になり、数値が変わる
積分の中で止めたCancelled { time } とそこまでの列、ok: true、GM-I11004列は壊れていない。止めたのは失敗ではない
積分の前で止めた列は無し、ok: false、GM-I11004 だけError にしない
t の間引き前に知らせてから 100 ms 以上（facade の now）ADR の (1)。実行系は Instant を呼ばない
