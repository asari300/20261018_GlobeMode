S068 · 2026-11-01 · P3

external-builtin

MSL 4.0.0 の Modelica.Math を実行できるようにする（S067 の持ち越し）

external "builtin" y = sin(u); → 組み込みの sin
目的

70 本が実行できなかった

  • MSL 4.0.0 の Modelica.Math は sin・cos・exp・log など 13 個を external "builtin" で書く（4.1.0 は algorithm）
  • Rumoca は実行を断る（EL005 / EX002、GlobeMode では GM-U0004）
  • 公開ライブラリを 4.0.0 で回すと、funnel が OK の 70 本がこれだけで止まる（S067）
決定と理由

道は 3 つ。小さい順に調べた

道結果
(a) Rumoca の hook無い（言語を分類するだけ）
(b) Dae を書き換える（採用）Dae は不変だが serde を実装し、読み戻すと Rumoca が検査し直す。公開 API だけで成り立つ
(c) MSL の文字列を置換版とライブラリに結びつく。採らない
決定と理由

書き換えの条件と失敗の扱い

  • 場所は frontend の compile_strict（実行・プリフライト・wasm が同じ Dae を使う）。check の判定は変えない
  • 関数の external 節で判定: 言語 builtin、記号が sin cos tan asin acos atan atan2 sinh cosh tanh exp log log10 sqrt abs、入力をそのまま渡す、出力 1 つ
  • call ノードを同じ被演算子の builtin ノードに替えて読み戻す
  • "C" や別の記号は今まで通り GM-U0004。読み戻せなければ元の Dae（誤った結果にならない）
