3 UI を 3 OS で測った

Svelte・Leptos・Dioxus のブラウザ版を、Actions の Linux・Windows・macOS で測った

run 41984237319 で 3 OS とも成功。ブラウザ版の 3 UI × 3 OS の欄がそろった
目的

このセッションでやること

  • P7 の完了条件「3 UI × 3 OS の比較」の残り、Windows と macOS の列
  • 手動だけのワークフロー ui-bench.yml を足す。OS ごとに 3 UI をビルドして測る
  • 結果を doc/bench/ui.md に足し、手元の WSL2 の列は残す
  • やらない: Tauri の測定、CPU・フレーム時間、UI のコードの変更、ci.yml への追加
決定と理由

決めたこと（ADR-0034 の付記）

項目決定理由
ランナーubuntu-latest、windows-latest、macos-latest公開リポジトリの標準ランナー
Rust全 OS でランナーの rustupWindows で mise の shim の cargo が失敗した前例
Pythonuv run の no-project と playwright の版指定uv sync は maturin で Rust をビルドしてしまう
列の分け方Actions の Linux は別の列 linux-actions手元の WSL2 と条件が違う
RSSWindows と macOS は psutil/proc が無い。macOS はピークが取れない

再現手順

gh workflow run ui-bench.yml
gh run download RUN_ID -D ui-bench
uv run python src/Svelte/tests/bench_ui.py merge ui-bench/*/ui-bench.json
uv run python src/Svelte/tests/bench_ui.py report
