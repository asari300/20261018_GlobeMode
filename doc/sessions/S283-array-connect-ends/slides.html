配列の結線を 1 本ずつ消す

S281 の不具合。connect(b[2].p, c.n) を消すと b[1].p の結線も消えていた

原因は connect_ends が添字を落とすこと。ここを 1 回直した
直し方

端は添字を含めて比べる

書き方端の字句
b[2].pb[2].p
b[ 2 ].pb[2].p（空白は落ちる。同じ結線）
b[i + 1].pb[i+1].p（式は字句の正規化）

逆の並びは今までどおり同じ結線。delete_part は端の最初の名前で数えるので、部品 b の結線は全部消える（変わらない）

波及

UI はそのまま

  • 図の結線の from・to も添字つきになり、添字ごとに別の線として出る
  • UI は data-conn の値をそのまま deleteConnect に渡すので、変更は要らない
