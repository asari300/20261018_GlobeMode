道

どこで何をするか

場所役割
globe-mode-fmt/diagram.rs部品の宣言・Placement・connect・Diagram を字句解析で読む。型の Icon を引き、変換の行列を付ける
wasm / sidecardiagram と globe/diagram（rpc は 25 本）
DocsPanel「説明」と「図」のタブ
DiagramView.svelte部品の <g transform>、connect の折れ線、名前、クリックで宣言の行へ
規則

読み方

  • 部品は Placement(transformation) のある宣言だけ。壊れた Placement・visible = falseは飛ばす
  • 型は import とスコープで引く。引けなければ破線の枠
  • extent の向きが逆なら反転、origin を中心に rotation
  • connect は Line(points)、無ければ中心どうしの直線
結果

MSL の例題 20 本

  • 部品 174、connect 178、Diagram の図形 21
  • 部品のアイコンはすべて引けた（空 0）
  • ChuaCircuit は部品 7・connect 9
試験

試験と再現

cargo test -p globe-mode-fmt --lib diagram
mise run wasm:node          # ChuaCircuit の部品 7・connect 9
mise run ui:check           # test_ui.py の diagram_view
