## 1. 目的

[roadmap](../../roadmap.md) の「機能の穴（P4）結果の入出力」に残っていた UI の「結果を開く」。ブラウザ・Desktop・Android の UI で、`.mat`（MAT v4）か `.csv` の結果のファイルを「開く」（Ctrl/Cmd+O）で開き、実行の結果と同じプロット（系列の選択、CSV・PNG の書き出し）で見る。読む本体は [S219](../S219-mat-import/解説書.md) の `globe-mode-sim::mat`。

## 2. 決定と理由

| 項目 | 決定 | 理由 |
| --- | --- | --- |
| バイト列の入口 | `mat::read_results_bytes(name, &[u8])`。`read_results(path)` は `fs::read` してこれを呼ぶ | 拡張子での読み分けを 1 か所に。写しを作らない。ブラウザの wasm にファイルは無く、バイト列だけがある |
| 列の形 | facade に `open_results(name, bytes) -> OpenedResults`。`columns()` は `Simulated::columns()` と同じ `(ColumnsLayout, Vec<&[f64]>)`（共通の `columns_of`） | プロットが使う形（`simulate_columns` の `layout` と `columns`）をそのまま返す。実行できなかったときの空の形は変えない |
| 既定で描く信号 | `Trajectory::default_plot(&[])`（先頭の 3 本） | 読んだ結果に状態・出力の役割は無い（MAT は代数に展開する）。規則は 1 か所のまま |
| ブラウザ・Android | wasm の `read_results(name, bytes)` が `ResultColumns`（`layout`・`column(i)`）を返し、Worker の op `read_results` が `{layout, columns: Float64Array[]}` | `SimColumns` と同じ受け渡し（列は `Float64Array`、buffer は転送）。UI は `gapNonFinite` を通して欠損を null に |
| Desktop | sidecar の `globe/readResults {path}` → `{layout, columns}`（`rpc` の許可に 1 つ足す） | Desktop に wasm は無く、`WorkerBackend` は通せない。dialog で選んだパスをそのまま渡せば sidecar が `fs::read` する。ファイルの中身（MAT は数 MB になる）を JSON の数の配列で往復しないぶん、バイト列を渡す道より少ない |
| `Backend.openFile` | 結果のファイルなら `text` は空で `columns` を返す。読めなければ reject | 「開く」の入口が 1 つのまま。App は `f.columns` があれば結果のタブへ。ダイアログの絞り込みと `<input accept>` に `mat`・`csv` を足す |
| タブの種類 | `Tab.results?: Columns`。key は「結果 ＜ファイル名＞」、`own: false`、本文は空の読み取り専用 | 既存のタブの仕組み（切り替え・閉じる・矢印キー）をそのまま使う。`activate` が `columns = t.results ?? null` にするので Plot は実行の結果と同じ部品 |
| 結果のタブでの操作 | エディタは `hidden`、`run` は Workspace へ送らず、保存は断る | 空の本文を `setFile`・保存しない。実行はモデル名（ファイル名の幹）が無く失敗の理由が出る |
| 持続 | しない | 自動保存は自分のファイルのタブだけ（`own`）。結果の列を localStorage に入れない（持ち越し） |

## 3. 図

```text
ブラウザ / Android   <input file> ── bytes ──► Worker: wasm read_results ─┐
                                                                          ├─ OpenedResults.columns()
Desktop              dialog path ── rpc globe/readResults ─ sidecar ──────┘   = simulate_columns と同じ
                                                                                      │
                                              Backend.openFile → { columns } ─► 結果のタブ ─► Plot.svelte
```

## 4. 再現手順

```bash
export CARGO_TARGET_DIR=…/target-shared CARGO_BUILD_JOBS=2
cargo test -p globe-mode-sim --lib mat
cargo test -p globe-mode-lsp read_results
mise run wasm:node            # smoke.mjs の「結果を開く」
mise run wasm:web             # worker-node.mjs の readResults
cd src/Svelte && pnpm check && pnpm build
uv run python src/Svelte/tests/test_ui.py   # open_results_file（.csv と omc の .mat）
cd src/Rust/apps/desktop && cargo test shell   # tauri-backend.ts と許可の一覧の突き合わせ
```
