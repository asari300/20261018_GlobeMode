## 1. 目的

[roadmap.md](../../roadmap.md) の P8「Diagram ビュー」の編集の 3 つ目。ライブラリの木の行を図へドロップしたら、カーソルのクラスに部品の宣言を足すテキスト編集を Rust が返し、UI がエディタに入れる（S250 の移動・S261 の結線と同じ道）。

## 2. 決定と理由

| 項目 | 決定 | 理由 |
| --- | --- | --- |
| 宣言 | `型の完全名 名前 annotation(Placement(transformation(origin = {x, y}, extent = {{-10, -10}, {10, 10}})));` | 型を完全名で書けば `import` を足さずに済む。extent は MSL の部品の標準の大きさ |
| 足す場所 | 最後の public の宣言の次の行（`protected`・`equation`・クラスの `annotation`・`end` の手前まで）。宣言が無ければ最初の節かクラスの `annotation`（無ければ `end`）の行の前 | Modelica の文法で宣言は節より前。字下げは最後の宣言に合わせる |
| 座標 | ドロップした図の座標を 2 単位に吸着 | S250 の移動と同じ格子 |
| 名前 | 型の最後の部分の頭を小文字に。クラスの中の字句・キーワード・型の最後の部分と重なれば `1`、`2`… | `resistor`, `resistor1`。字句の一致だけを見る（継いだ名前は見ない。重複は検査が誤りにする） |
| 型の種類 | package・function・record・type と分かれば断る。引けない・読めなければ受ける | 部品にできるのはモデル・ブロック・コネクタ。判定は `is_connector` と同じ字面の探し方（`kind_of`） |
| 型の文字 | 英数字・`_`・`.` の並びだけ | ソースに入る文字列なので、UI から来た値でも信用しない |
| 口 | LSP `globe/addPart`（`RPC_METHODS` 28 → 29）、wasm `add_part`、`Backend.addPart` | S250・S261 と同じ形（TextEdit の配列、保存しない） |
| UI（マウス） | 木の行は `draggable`（package・function・record・type は除く）。図の svg が `dragover`・`drop` を受ける | 木と図を別の部品のまま、DataTransfer の `application/x-globe-class` だけでつなぐ |
| UI（キーボード） | 図が開いているとき、木の各行に「図へ」ボタンを出し、図の `extent` の中心に足す | ドラッグできない人のため。既存の「開く」ボタンと同じ並び |

## 3. 図

```text
dragstart(木の行 L.Res) → dragover/drop(図の上)
  → backend.addPart(diagram.class, "L.Res", x, y)   … Rust: 宣言の挿入編集
  → view.dispatch(changes)                          … エディタが変わる（Ctrl+Z で戻る）
  → 図が読み直され、新しい部品が出る
```
