add_part（globe-mode-fmt）

クラスの状態足す場所
public の宣言あり最後の宣言の次の行（protected・equation などの手前）。字下げはその宣言に合わせる
宣言なし最初の節かクラスの annotation（無ければ end）の行の前

宣言は L.Res res annotation(Placement(transformation(origin = {x, y}, extent = {{-10, -10}, {10, 10}})));

名前と種類

名前の付け方と断る型

  • 名前は型の最後の部分の頭を小文字に（resistor、重なれば resistor1）
  • 座標は 2 単位に吸着（移動と同じ格子）
  • package・function・record・type は断る。引けない・読めなければ受ける
UI

ドロップと「図へ」

  • 木の行を draggable にし、図の svg が drop を受ける
  • キーボード用に、図が開いているとき各行に「図へ」ボタン（図の中央へ）
  • 名前の入力は持ち越し。足したあとにリネームで変える
