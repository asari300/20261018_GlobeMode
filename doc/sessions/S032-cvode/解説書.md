## 1. 目的

ロードマップの候補 6（残りの計画のソルバ）の続き。登録表で未実装（`GM-E10005`）だった `cvode` を、SUNDIALS の CVODE を呼んで使えるようにする。設計は [architecture.md](../../architecture.md) のソルバの表と S032 の注、ライセンスは [licenses.md](../../licenses.md) の SUNDIALS の行。

## 2. 決定と理由

| 項目 | 決定 | 理由 |
| --- | --- | --- |
| 何を足すか | `cvode`（`ida` は次） | 部品は常微分方程式の形で導関数を返すので、CVODE がそのまま合う |
| crate | `sundials-sys` 0.6.2（SUNDIALS 7.1.1 を同梱） | BSD-3-Clause。`build_libraries`・`static_libraries` で同梱のソースを cmake でビルドし、静的にリンクする |
| feature | `globe-mode-exec` の `sundials`（sim・CLI が転送）。sundials-sys は `cvode` だけ | 既定・wasm・CI は cmake も C も要らない。`klu`（LGPL）・openmp・pthreads は使わない |
| 方法 | BDF、Newton 法、密な行列と線形ソルバ、ヤコビ行列は CVODE の差分商 | 最小。疎な構造と部品の方向微分は `shortcut:` で後回し |
| 実行系との境 | 1 回の `advance` が CVODE の 1 歩（`CV_ONE_STEP`）。上限は `CVodeSetStopTime`。刻みの間は `CVodeGetDky` | 他の適応ソルバと同じ。事象・リセットの後は `CVodeReInit` |
| 断られた点 | 右辺の関数が正の値（回復できる失敗）を返す | CVODE が刻みを縮めて試し直す |
| unsafe | workspace は `forbid` のまま。`globe-mode-exec` だけ `deny` にして `cvode.rs` で許す | `forbid` は `allow` で外せない。別の crate に分けるより小さい |

## 4. 再現手順

```bash
cargo build -p globe-mode-cli --features sundials   # cmake・C コンパイラ・libclang が要る
target/debug/globe simulate -L src/Modelica/GlobeModeValidation \
  -m GlobeModeValidation.Simulation.DiodeSwitching --solver cvode
cargo test -p globe-mode-exec --features sundials
```
