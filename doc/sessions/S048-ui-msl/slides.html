ui-msl

ブラウザ UI で MSL を読み、ChuaCircuit を検査して実行してプロットする

「MSL を読む」→ ChuaCircuit の 検査 0 error・実行・44 信号
目的

このセッションでやること

  • P4 の完了条件の前半「ChuaCircuit で開く・検査・実行・プロットが通る」をブラウザで通す
  • 既存の Decay の流れは変えない。MSL は起動時に読まず、ボタンで読む
  • CI の ui ジョブにも MSL の試験を載せる
決定と理由

決めたこと

項目決定理由
MSL の渡し方public/msl/MSL.json（15 MiB）を fetchsmoke.mjs の readMo と同じ形。wasm 側は変えない
作る所pack-msl.mjs（prepare-wasm の段）data/msl が無ければ警告だけで飛ばす
読む時機ボタン。起動時は読まないDecay の起動を重くしない
Backendlibrary(name, json) を足すGlobeWorker.library は作り直しでも再生する
グラフライブラリのモデルは未対応と表示S046 の持ち越し（索引に無い）
