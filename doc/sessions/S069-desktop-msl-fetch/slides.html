Desktop が MSL を取得する

配布版を起動した利用者が、環境変数なしで MSL 4.1.0 を使えるようにする

S056 の持ち越し「MSL の置き場（同梱か取得か）」を決めて実装する
目的

このセッションでやること

  • S056 まで、MSL は --library / GLOBE_LIBRARY で渡すだけ。配布版の利用者は MSL を使えない
  • MSL を同梱するか、初回に取得するか、利用者に場所を聞くかを決める（ADR-0030）
  • 取得 → 検証 → 展開 → sidecar の作り直しを実装し、CI の smoke で回す
決定と理由

3 案を比べて、初回に取得

案長所短所
同梱オフラインで動く配布物が 29 MB 以上増える。MSL の版を上げるたびに配り直す
初回に取得（採用）配布物が増えない。msl/<版>/ で版を分けられる初回にネットワークが要る
利用者が指定実装が最小MSL を持たない利用者には何も起きない

--library / GLOBE_LIBRARY は今のまま優先する（MSL 以外のライブラリの道）

決定と理由

取得の手順

  • curl で zip を落とす（HTTP の crate を足さない。.deb は Depends: curl）
  • sha256 を照合してから zip で展開する。.. や絶対パスは拒む
  • 目印は最後に書く。途中で落ちたら目印が無く、次回やり直す
  • xtask の fetch-msl と URL・sha256・目印が同じ。コードは共有せず、定数の一致を CI で確かめる
