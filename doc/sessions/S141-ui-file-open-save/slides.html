ファイルを開く・保存する

S140 の点検の順位 1。自分のモデルを持ち込み、持ち帰る

ブラウザ・Android は input とダウンロード、Desktop は dialog と fs
目的

このセッションでやること

  • UI に「開く」「保存」を足す（Desktop は「名前を付けて保存」も）
  • 口は Backend.openFile() と saveFile(name, text, saveAs?) の 2 つだけ
  • 本文とファイル名は localStorage に自動保存し、起動時に戻す
  • 複数の文書、最近使ったファイル、FMU export は持ち越し
決定と理由

3 列の実装

列開く保存
ブラウザ<input type=file accept=".mo">Blob のダウンロード
Androidブラウザと同じ（sidecar が無く WorkerBackend）ブラウザと同じ
Desktopdialog.open と fs.readTextFiledialog.save と fs.writeTextFile（開いたパスへ上書き）

Desktop の権限は 4 つだけ。fs の許可は dialog で選んだパスに限る。
