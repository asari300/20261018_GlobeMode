サイリスタと時間イベントの上書き

--param は時間イベントだけでなく、同じ名前の修飾で写された値にも届かず、黙って誤っていた。上書きを組み込んでコンパイルし直すようにした（ADR-0022）。ThyristorBehaviourTest は host の限界で、直さずに分類した

SineVoltage に --param V.f=2: V.v(0.05) = 0.309 → 0.588。CauerLowPassSC の V.startTime=0.5 も t = 0.5 で立ち上がる
目的

このセッションでやること

  • S023 の残し: esdirk34 の ThyristorBehaviourTest（消弧の逆回復で射影が発散）
  • S023 の残し: --param で時間イベントの時刻が変わらない件の手元での直し方
  • サブエージェント（Sonnet、high）3 本: サイリスタの計測 / 直し方の見積もり / 実装
原因

実行時の上書きが内側に届かない

形実行時の上書き結果
SineVoltage V(f = 1) の signalSource(final f = f)V.f だけが 2、内側の f は 1 のまま黙って誤る
StepVoltage の startTime時間イベントは既定の時刻のまま黙って誤る
R.R、V.offsetそのまま効く正しい

Rumoca の instantiate が外側の値を内側の束縛に書き込むので、DAE には依存が残らない。警告で見分けることもできない

決定と理由

決めたこと

項目決定理由
--param上書きがあれば pristine を複製して組み込んでからコンパイルソースを書き換えたのと同じ結果。変換済みの session に足すと ED020
型既定の DAE の型で Real・Int・BoolReal を Integer に渡すと落ちる
失敗診断を返す。既定に戻さない戻すと黙って誤る
ThyristorBehaviourTest直さない（候補 19・20）host の失敗の記憶。刻み 0.9 倍で通る崖の調整
