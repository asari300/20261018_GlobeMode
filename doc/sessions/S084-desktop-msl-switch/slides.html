Desktop の MSL の版の切り替えと進捗・取り消し

S069 の持ち越し 2 つ（進捗の割合と取り消し、4.0.0 への切り替えの UI）を閉じた

版は msl/<version>/ に分けて置き、fetch_msl { version } で取得して sidecar を作り直す
目的

このセッションでやること

  • Desktop で MSL 4.1.0 と 4.0.0 を選んで取得・切り替えできる（公開ライブラリの多くは 4.0.0 が前提）
  • 取得中に受信量と割合を出し、もう一度押すと取り消せる
  • 4.0.0 の URL・sha256 は xtask の定数を写し、desktop.yml が 2 版分の一致を確かめる
決定と理由

決めたこと

項目決定理由
置き場msl/<version>/。起動時は 4.1.0 から探す目印が版ごとなので、2 版を並べて置ける
進捗curl を spawn し、zip の大きさを 0.25 秒ごとにイベント msl-progress で出すHTTP クライアントを足さない。全体は HEAD の Content-Length
取り消しcommand cancel_msl が AtomicBool を立て、curl を止めて zip を消す最小の形。展開中は止めない
UIDesktop だけ版の <select>。取得中はボタンが「取り消す」ブラウザ版の MSL.json は 4.1.0 だけ
