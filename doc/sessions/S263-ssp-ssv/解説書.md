## 1. 目的

S253 の SSP 読み取りは `ParameterBindings` を断っていた。S259 で `start`（初期化の前に設定する初期値）ができたので、`Component` の `ParameterBindings` を読んで `start` に写す。

## 2. 決定と理由

詳細は [ADR-0026](../../adr/0026-fmi-import-placement.md) の (t)、仕様の要点は [調査](../../research/ssp-2026-11-15.md) の 5。

| 項目 | 決定 | 理由 |
| --- | --- | --- |
| 読む値 | Real・Float64・Integer・Int32・Boolean。キーは `"<component>.<prefix><name>"` | `start` が f64 で Int32・Boolean も受けられる。`prefix` は仕様どおり名前の前に付ける |
| 優先順位 | 後ろの binding が勝つ | SSP 5.2.3 |
| FMU に無い名前 | 無視する | 仕様の規定（大きな .ssv の一部だけを使える）。綴りの誤りも黙って無視される点は ADR に書いた |
| 断るもの | `ParameterMapping`・System の階層・`sourceBase="component"`・`unit`・配列・ほかの型 | 黙って無視せず明確な誤りにする（S253 と同じ方針） |

## 3. 図

```text
SystemStructure.ssd ── Component a ── ParameterBinding(source=resources/p.ssv | インライン)
                                         │  parse_ssv / parameter_set（globe-mode-fmi）
                                         ▼
                       (名前, f64) ── FMU の変数にある名前だけ ──► CosimSpec.start["a.<prefix><name>"]
```
