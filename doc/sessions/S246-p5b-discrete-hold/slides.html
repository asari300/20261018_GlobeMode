16 本から 18 本
症状

Math.Mean の出力が 0 に落ちる

  • DiodeBridge2Pulse の meanVoltage.y は、globe simulate では 99.03 のまま。FMU では 0.01 s の標本の直後に -5e-16 に落ちた。
  • 定数入力の Mean は通る。整流器の電圧が 0 を横切る時刻が、sample の時刻と重なるときだけ。
原因

同じ時刻の 2 回目の事象で when sample が回り直す

  • 1 回目: 時刻事象。y_last = f*pre(x) を取り、reinit(x, 0)。
  • 2 回目: 同じ時刻の状態事象（ダイオードの切り替え）。行のフィルタが All なので時計の行がもう一度回り、y_last が x = 0 で上書きされた。
  • Rumoca の host と FMI ME は、処理済みの時刻事象と重なる状態事象では時計の行を回さない。

直し

スケジュールが処理済みと言うときだけ

  • ModelInstance::update_discrete_states で scheduled_event_coincidence_at(t) が処理済みなら UnownedOnly。
  • P5b の FMU だけが使う部品の中の 1 か所。Rumoca と exec の host は触らない。
  • 最小のモデル SampleAtZeroCrossing と試験を足した。直す前は yLast = -1e-20、直した後は 0.6355（ME）・0.6366（CS）。
