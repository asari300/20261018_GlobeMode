構文の色付け

S059 の持ち越し。ブラウザのエディタと VS Code で、予約語・型・文字列・数値・コメントに色が付く

明でも暗でも読める色。予約語の一覧は Rust の KEYWORDS と一致
現状

調べたこと

場所色付けの有無
Svelte のエディタ（CodeMirror 6）無し。言語も HighlightStyle も入っておらず、本文は無地
VS Code の拡張無し。contributes.grammars が無く、language-configuration.json だけ
ダークモード（S152）theme.css の変数が明・暗・OS の 3 か所にある。色はここに足す
決定と理由

決めたこと

項目決定理由
CodeMirrorStreamLanguage の小さなトークナイザ新しい文法の依存を足さない。tree-sitter-modelica は AGPL なので使わない
色theme.css の --syn-*、クラス cm-mo-*明暗の切り替えは変数だけで済む。コントラスト 4.5 以上
予約語TS の KEYWORDS を補完と共通にし、一致を試験で確かめるwasm から取る口は無く、足すと起動時の非同期が増える
VS Code自前の TextMate 文法他の文法は写さない（ライセンス）
依存@lezer/highlight（MIT）を直接の依存に既に推移的に入っているが、pnpm では直接 import できない

色を付けるもの

分類Svelte のクラスTextMate のスコープ

組み込みの型cm-mo-typesupport.type

数値cm-mo-numconstant.numeric
コメントcm-mo-cmtcomment.line、comment.block
演算子cm-mo-opkeyword.operator
