6 モデルが 3.0 でも FMPy の validate を通り、2.0 と同じ値
目的

このセッションでやること

  • S095〜S114 の globe-mode-fmu（FMI 2.0 ME）の持ち越し: FMI 3.0 の ME
  • 2.0 と同じ ModelInstance を使い、関数の形だけ変えて呼ぶ
  • write_model_description_3（S124）の EventIndicator の Err を外す
  • CS、Windows・macOS、MSL、Enumeration・String、dependencies は持ち越し
決定と理由

3.0 は 2.0 の関数の包み

3.0中身
fmi3InstantiateModelExchangefmi2Instantiate と共有（resourcePath はそのままのパス）
fmi3EnterInitializationModefmi2SetupExperiment
fmi3GetFloat64・GetInt32fmi2GetReal・GetInteger（nValues = nvr）
fmi3UpdateDiscreteStatesfmi2NewDiscreteStates を bool に移す
残りの 49 関数引数を読まない fmi3Error の stub（マクロ）

Rust は接頭辞の無い名前で出すので FMI3_OVERRIDE_FUNCTION_PREFIX は関係しない

決定と理由

3.0 の modelDescription.xml

  • derivative と ModelStructure は valueReference（2.0 は 1 始まりの索引）
  • EventIndicator は変数を指す: Float64 の _eventIndicator1.. を足した
  • independent の time を足した（validate が「ちょうど 1 つ要る」で落ちた）
  • globe-mode-fmi の ModelStructure に event_indicators。2.0 は変えない
