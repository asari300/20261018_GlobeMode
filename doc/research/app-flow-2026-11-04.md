## 5. 事実の根拠

- ボタンは「検査」「実行」「グラフ」「整形」「止める」「MSL を読む」（Desktop は「MSL を取得する」「更新を確認」と版の選択）だけ（`src/Svelte/src/App.svelte` の `<div class="bar">`、確認日 2026-11-04）。
- 本文の初期値は Decay の固定（`App.svelte` の `EditorState.create`）。
- Desktop の command は `rpc`・`notify`・`cancel_run`・`libraries`・`fetch_msl`・`cancel_msl`・`bench`・`updater_configured`（`src/Rust/apps/desktop/src/main.rs` の `generate_handler!`）。
- `globe lsp` の独自の要求は `globe/check`・`format`・`graph`・`libraryTree`・`librarySource`・`lint`・`simulate`・`simulateColumns`、標準は `textDocument/completion`・`definition`・`didChange`・`didClose`・`didOpen`・`documentSymbol`・`formatting`・`hover`・`references`（`src/Rust/mod/globe-mode-lsp/src/`）。
- 設定ファイルの扱い: `src/Rust/mod/globe-mode-lsp/src/lib.rs` の冒頭（rootUri から上へたどる。`globe/format`・`globe/lint` は params だけで決める）。
- `test_ui.py` の中身: `src/Svelte/tests/test_ui.py` の冒頭の説明（S041・S046・S048・S065・S071・S093・S100・S103・S125・S127・S128・S133）。
