レコードの配列式の方程式を、要素ごとに数える

aw = {R(1, 0), ...} は 6 本（3 要素 × 2 フィールド）のはずが 3 本。v0.10.4 で MSL の Complex だけ直った

record R Real re; Real im; end R;
model A
  R aw[3];
equation
  aw = {R(1, 0), R(2, 0), R(3, 0)};
end A;
// v0.10.2: ED008 unresolved Flat reference `aw`
// v0.10.4: ED001 3 equations, 6 unknowns

// 通る形: for i in 1:3 loop aw[i] = R(i, 0);
//         aw = bw（bw を for 文で決める）

本文: 日本語 · 英語 · 再現 .mo · 一覧 upstream.md

v0.10.4 の結果MSL の Complex、大きさ 3 は直った／普通のレコードと、大きさが size(a, 1) の Complex は再現
Rumoca の誤りの根拠レコードの等式は成分ごと（MLS 10.6.1）、方程式はスカラーに展開して数える（4.8）。omc は 6 と 6 で通す
影響MSL では TransferFunction の形。ただし ShowTransferFunction は別の ED019（配列の成分の切り出し）が先に止める。本数は未計測
GlobeMode 側の回避なし（自前の DAE はフィールドごとに数える。S351）。固定中の Rumoca とは比べられない
提出の判断材料出すなら「普通のレコード」と「size(a, 1) の Complex」に絞る。ED019 は別件
