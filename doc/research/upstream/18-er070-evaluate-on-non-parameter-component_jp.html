parameter でない成分への Evaluate = true を ER070 で断る

仕様は「parameter にだけ効果がある」と言うだけで誤りにしない。v0.10.4 でも同じ

model Rep18
  parameter Boolean with_D = false;
  Modelica.Blocks.Sources.Constant
    Dzero(final k = 0) if not with_D
    annotation (Evaluate = true);
    // ここ → ER070（MLS §18.6）
  Real y(start = 0);
equation
  der(y) = -y + 1;
end Rep18;
// 注釈を外した Rep18Plain は通る

v0.10.4 の結果再現（ER070 Dzero。Rep18Plain は通る）
Rumoca の穴の根拠MLS §18.3 の Evaluate は成分の宣言に書け、parameter でなければ効果が無いだけ。メッセージの §18.6 は Graphical Objects で誤り。omc は通す
影響ライブラリ 258 本（Buildings 173・AixLib 58・IBPSA 27）。LimPID の Dzero
GlobeMode 側の回避なし（ソースを書き換えない）
提出の判断材料MSL が要るが 1 コマンド。関数の局所変数では既に警告 WR006 なので、揃える直しで済む見込み。提出の順は 2 位
