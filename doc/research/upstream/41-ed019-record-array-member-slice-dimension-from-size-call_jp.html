大きさが size(a, 1) だと成分の参照が ED019

Complex aw[size(a, 1)] の aw.re・aw[1].re が ED019 で止まる。リテラルや Integer の大きさなら通る

parameter Real a[:] = {1, 2, 3};
R aw[size(a, 1)];
Real s;
equation
  for i in 1:size(a, 1) loop
    aw[i] = R(a[i], 0);
  end for;
  s = sum(aw.re);   // ED019（Rumoca）
// R aw[3] や n = 3 の R aw[n] は通る
// omc 1.27.2 は 7 と 7 で通す
