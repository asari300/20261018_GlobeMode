使わない別の派生クラスの Medium まで解決して ER002

M は Good しか使わないのに、同じ基底を Bad で継ぐ別のモデルの壊れた関数で落ちる。v0.10.4 でも同じ

partial model PFP
  replaceable package Medium1 = PM;
end PFP;
model Engine
  extends PFP(redeclare package Medium1 = Bad);
end Engine;
model M
  extends PFP(redeclare package Medium1 = Good);
  Real y = Medium1.f(time);
  // ↑ ER002: specificEntropyOfpTX
end M;
// Bad.T_psX の中で未宣言の specificEntropyOfpTX を呼ぶ
// M は Bad・Engine・T_psX を使わない（omc は通す）
