record の parameter の次元を関数の局所変数にすると ED019

v0.10.4 で constant の形は直った。MSL と同じ parameter の形が残る

record Coeff
  parameter Integer nc = 2;
  parameter Real[nc] a = {1, 2};
end Coeff;           // ↑ ここ → ED019
function f
  input Real x;
  output Real y;
protected
  Coeff id;
algorithm
  y := id.a[1] * x;
end f;
// constant の CoeffC は v0.10.4 で通る
