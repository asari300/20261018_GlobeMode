record の eta[size(y, 1)] を関数の呼び出しで束縛すると ET004

大きさが束縛から決まる record を、関数の出力で束縛すると次元を評価できない。v0.10.4 でも同じ

record R
  parameter Real y[:];
  parameter Real eta[size(y, 1)];
end R;
function f
  input Real k;
  output R r(y = {0, 1}, eta = zeros(2));
end f;
model M parameter R p = f(2); end M; // ET004
model M0  // 通る
  parameter R p(y = {0, 1}, eta = {2, 2});
end M0;
