replaceable な record を通して成分を読む束縛が EF024

record の成分・record のクラスのどちらでも、replaceable を通すと束縛が落ちる。v0.10.4 でも同じ

record NV parameter Real m = 1; end NV;
record Stage replaceable parameter NV nomVal; end Stage;
record Coil
  parameter Stage sta;
  parameter Real mSmall = sta.nomVal.m;
  // ↑ 形 1 → EF024: m
end Coil;
// 形 2: replaceable record ST Real a = 2.5; end ST;
//   関数の protected の ST st; Real da = st.a;
//   → EF024: a
// replaceable を外すとどちらも通る

本文: 日本語 · 英語 · 再現 .mo · 一覧 upstream.md

v0.10.4 の結果再現（M・M2・F・F1 が EF024、対照 3 本は通る）
Rumoca の穴の根拠replaceable は後の redeclare を許すだけ（MLS §7.3）。成分の参照は通常の参照（§5.3）、関数の protected は束縛を持てる（§12.4.4）。omc は 7 本とも通す
影響ライブラリ 8 本（Buildings の DX コイル 7、AixLib の R134a 1）
GlobeMode 側の回避なし（Buildings の写しで束縛を定数にすると SpeedSelect は全段を通る）
提出の判断材料提出の順は 11 位（S115 で 14 位から）。29 と原因が同じかは【未確認】
