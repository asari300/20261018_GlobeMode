状態への initial equation を FMU に書き出せない

C profile の初期化は残差の行を「代数の再計算」の上でしか評価しない。fixed の start なら通る。v0.10.4 でも同じ

model E
  parameter Real T_start = 100;
  parameter Real C = 15;
  Real T;
equation
  C * der(T) = -T;
initial equation
  T = T_start; // rows over declaration seeds
end E;

// 対照: Real T(start = T_start, fixed = true);
// なら fmi2 に書き出せる
