継いだ入れ子のクラスを継いだ package の名前で引くと ER002

Q extends P の Q.B が引けない。replaceable な別名なら通る。v0.10.4 でも同じ

package P
  model B  Real x = time;  end B;
end P;
package Q
  extends P;
end Q;
model M
  Q.B b;       // ER002 'Q.B'
end M;
model M2       // 対照: 通る
  replaceable package A = Q;
  A.B b;
end M2;

本文: 日本語 · 英語 · 再現 .mo · 一覧 upstream.md

v0.10.4 の結果再現（M・M1 が ER002。M0・M2 は通る）
Rumoca の穴の根拠クラスの要素には継いだ要素が入る（MLS §7.1）。合成名の残りは Q の要素から探す（§5.3.2）。omc は通す
影響ライブラリの例題では 0 本
