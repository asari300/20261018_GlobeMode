組み込みと同じ名前の redeclare function extends product で ER132

継いだ関数 product を置き換えると、組み込みの product に解決されて落ちる。v0.10.4 でも同じ

package One
  extends Base;  // replaceable partial
                 // function product
  redeclare function extends product
    // ここ → ER132 + ER002 z, x, y
  algorithm
    z := {x[1]*y[1] - x[2]*y[2],
          x[1]*y[2] + x[2]*y[1]};
  end product;
end One;
// 名前を prod にすると通る
