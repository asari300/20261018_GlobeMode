AssertionLevel の parameter が flat から消える

組み込みの列挙 AssertionLevel・StateSelect の parameter は、flat のモデルに変数として残らない。ユーザーの列挙は残る

model A
  parameter AssertionLevel level = AssertionLevel.warning;
  Real x;
equation
  x = time;
end A;
// Rumoca: variables = [x]
// omc:    parameter ... level = AssertionLevel.warning

// 対照 C: 自分で宣言した enumeration は level が残る
