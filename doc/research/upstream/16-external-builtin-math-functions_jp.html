external "builtin" の組み込み関数を実行できない

MSL 4.0.0 の Modelica.Math（sin・exp など 13 個）が実行できない。v0.10.4 でも同じで、コードが EL005 から EL001 に変わった

function mySin
  input Real u;
  output Real y;
  external "builtin" y = sin(u);
end mySin;
der(x) = mySin(time);

// v0.10.4
[EL001] unsupported checked DAE semantics:
  external builtin function `mySin` calls `sin`,
  which the Solve runtime cannot execute

v0.10.4 の結果再現（文面は変わった。パラメータの束縛の形は原因を名指しするようになった）
