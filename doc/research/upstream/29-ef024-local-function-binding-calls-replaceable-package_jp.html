関数の protected の束縛が Medium.f を呼ぶと EF024

モデルの中の関数で、束縛から replaceable な package の関数を呼ぶと落ちる。v0.10.4 でも同じ

model M
  replaceable package Medium = P;
  Real y;
protected
  function g
    input Real u; output Real z;
  protected
    Real w = Medium.f(u);    // ここ → EF024: f
  algorithm
    z := w;     // z := Medium.f(u) なら通る
  end g;
equation
  y = g(time);
end M;

v0.10.4 の結果再現（M・M1 が EF024、M0・M2 は通る）
Rumoca の穴の根拠関数の protected の成分は束縛を持てる（MLS §12.4.4）。Medium.f は囲むモデルから通常の探索で引ける（§5.3）。omc は 4 本とも通す
影響ライブラリ 18 本（IBPSA・Buildings・AixLib の Media.Examples 6 本ずつ）
GlobeMode 側の回避なし（束縛を algorithm に移せば通る。IBPSA の写しで確認）
提出の判断材料再現は 4 行で明快。提出の順は 9 位（S115 で 12 位から）。31 と続けて出してもよい
