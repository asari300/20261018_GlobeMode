outer の参照が inner の修正でなく型の既定を読む

inner System system(energyDynamics = FixedInitial) を無視して Free で評価し、初期方程式が消える

model System
  parameter Dynamics energyDynamics = Free;
end System;
model Volume
  outer System system;
initial equation
  if massDynamics == FixedInitial then
    p = ps_start;    // この方程式が消える
  end if;
end Volume;
inner System system(energyDynamics = FixedInitial);
