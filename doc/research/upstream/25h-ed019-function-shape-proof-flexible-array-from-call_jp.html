Real[:] の局所変数を呼び出しの代入だけで決めると ED019

代入があるのに「代入が大きさを決めない」と言う。v0.10.4 でも同じ

function f
  input Real x;
  output Real y;
protected
  Real[:] X;      // ここ → ED019
algorithm
  X := g(x);      // g の出力は X[2]
  y := X[1];
end f;
// Real[2] X なら通る。束縛 = g(x) も落ちる
