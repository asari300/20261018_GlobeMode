massDynamics を下へ渡すと、if 方程式が違う枝になる

vol(massDynamics = massDynamics) が、囲むモデルの既定 energyDynamics を vol の側で評価する。0 = f のはずが der(m) = f

model Boiler
  extends Decl;   // massDynamics = energyDynamics
  Vol vol(massDynamics = massDynamics);
end Boiler;

model A
  Boiler b(energyDynamics = Dyn.Steady);
end A;
// Rumoca: der(b.vol.m) = b.vol.f
// omc:    0.0 = b.vol.f
