replaceable な package を通した次元が ET004 / EF024

v0.10.4 で素直な形（Real x[P.n]）は直った。replaceable な package を通す 3 形が残る

package P constant Integer n = 2; end P;
model C
  replaceable package Medium = P;
  Real x[Medium.n];          // 次元が package の定数
  ...
end C;
model M3 C c; end M3;        // 既定のまま → ET004
model M4 C c(redeclare package Medium = P); end M4;
// ↑ M4 は通る
// M1: モデルで直接 Medium.n → EF024
// M5: モデルの中の record の x[Medium.n] → EF024

本文: 日本語 · 英語 · 再現 .mo · 一覧 upstream.md

v0.10.4 の結果M・M2 は直った／M1・M3・M5 は再現
Rumoca の穴の根拠package の定数は定数式で次元に使える（MLS §3.8.1・§10.1）。replaceable は redeclare しなければ既定を使う（§7.3）。omc は 7 本とも通す
影響ライブラリ 4 本（v0.10.2）。v0.10.4 で直る見込みは Buildings の Temperature_u 1 本で、残り 3 本【未確認】
GlobeMode 側の回避なし（モデルで redeclare するかモデルの定数を使う）
提出の判断材料出すなら件名を M1・M3・M5 に絞る。提出の順は 12 位（ED019 の群と同じ。S115 で 15 位から）
