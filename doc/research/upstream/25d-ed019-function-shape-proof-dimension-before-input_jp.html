次元を後で宣言する Integer の入力で取ると ED019

input Real x[n] が input Integer n より先だと形の証明に失敗する。v0.10.4 でも同じ

function f
  input Real x[n];   // ここ → ED019
  input Integer n;
  output Real y;
algorithm
  y := sum(x);
end f;
block B
  parameter Real a[:] = {1, 2};
  Real y = f(a, size(a, 1)) * time;
end B;
model M  B b;  end M;
// n を先に、または x[:] なら通る
