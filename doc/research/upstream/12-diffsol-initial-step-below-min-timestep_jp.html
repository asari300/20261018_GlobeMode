最初の刻みの見積もりが min_timestep を下回る

ほぼ 0 の状態で導関数が大きい再開で、最初の step() が一度も試さずに失敗する。diffsol の main にも下限の処理が無い

// TinyStateRestart
Real x(start = 3e-11);
equation
  der(x) = if time < 1 then 0 else 1e5;

// Hairer の見積もりで h ~ 2e-16
// min_timestep (t ~ 1) は 1e-13
// Step size is too small at time = 1.05
