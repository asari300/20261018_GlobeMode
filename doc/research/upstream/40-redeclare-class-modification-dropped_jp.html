redeclare model M = Impl(show = true) の修飾が効かず、show が false のまま。if show の成分が消える

model A
  Holder h(redeclare model M = Impl(show = true));
end A;

// h.m.show = true、h.m.y あり（omc、対照 B・C）

// 対照 C: Impl m(show = true);
