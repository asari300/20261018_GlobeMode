差し替えたクラスの use_in = false が、条件付き成分に届かない

redeclare model Area = AreaFinal で use_in が false になっても、if area.use_in の成分 u が flat に残る

model Holder
  replaceable model Area = PartArea;
  Area area;
  Real u = 1 if area.use_in;
end Holder;

model A
  Holder h(redeclare model Area = AreaFinal);
end A;
// Rumoca: h.area.use_in, h.u
// omc:    h.area.use_in = false（u は無い）
