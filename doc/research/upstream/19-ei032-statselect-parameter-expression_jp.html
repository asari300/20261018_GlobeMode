stateSelect の parameter 式を EI032 で断る

if 式・修正で渡した parameter を、Rumoca はリテラルに畳めないと止まる。v0.10.4 でも同じ

// A: 兄弟の部品の parameter を読む if 式
Rep19Props medium(T(stateSelect =
  if medium.preferredMediumStates
  then StateSelect.prefer
  else StateSelect.default));  // EI032

// B: 修正で渡した parameter
model Rep19Joint
  parameter StateSelect stateSelect;
  Real phi(stateSelect = stateSelect);
end Rep19Joint;
Rep19Joint j(stateSelect = ss); // EI032

v0.10.4 の結果再現（A・B とも EI032。リテラルの A0・B0 は通る）
Rumoca の穴の根拠stateSelect は parameter の属性（MLS §4.8.1）。parameter 式を取れる（§3.8.3）。omc は通す
影響ライブラリ 235 本（A 228・B 7）。IBPSA の ConservationEquation、DeltaRobot
GlobeMode 側の回避なし（S3 の GM-E3001）
提出の判断材料自己完結・4 コマンド。提出の順は 3 位
