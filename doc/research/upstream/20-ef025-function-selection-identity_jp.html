2 つの Medium の別名で関数の選択が EF025

前半の loadResource（136 本）は v0.10.4 で直った。後半の 2 つの Medium の形（20b）だけが残る

partial package PM
  replaceable function f ... end f;
  model BaseProperties
    Real y = f(x);  // 修飾なしの呼び出し
  end BaseProperties;
end PM;
package A extends PM(k = 2); end A;
package B extends PM(k = 3); end B;
model M
  replaceable package M1 = A;
  replaceable package M2 = B;
  M1.BaseProperties b1;  // EF025
  M2.BaseProperties b2;
end M;
