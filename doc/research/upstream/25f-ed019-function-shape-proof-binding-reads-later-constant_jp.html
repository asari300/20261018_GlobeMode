b[:] の束縛が後で宣言する定数を読むと ED019

宣言の順に依って形の証明が失敗する。v0.10.4 でも同じ

function f
  input Real x;
  output Real y;
protected
  constant Real b[:] = {c, 2}; // ED019
  constant Real c = 3;
algorithm
  y := b[1] + b[2] * x;
end f;
// c を先に、またはリテラルなら通る
