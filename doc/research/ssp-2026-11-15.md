## 2. アーカイブ（3 章）

- 拡張子は `.ssp`。有効な ZIP（圧縮方法 0 か 8。暗号化と分割は不可）。
- ルートに `SystemStructure.ssd` が**必須**。`resources/` の下に `.ssv`・`.ssm`・`.ssb` や FMU を置いてよい。ほかに `extra/`・`documentation/`。

## 3. SSD（5 章）

| 要素 | 事実 | 節 |
| --- | --- | --- |
| ルート | `SystemStructureDescription`。`version`（`1.0` か `2.0`）と `name` が必須。子は `System`（必須）、`Enumerations`・`Units`・`DefaultExperiment`（任意） | 5.1 |
| 名前空間 | `ssd` = `http://ssp-standard.org/SSP1/SystemStructureDescription`、`ssc` = `http://ssp-standard.org/SSP1/SystemStructureCommon`（SSV は 6 章） | 3 章の表 |
| `DefaultExperiment` | ルートの子。`startTime`・`stopTime`（どちらも任意）。**刻みは無い**（ソルバ・マスターに依る）。情報目的 | 5.1.1 |
| `System` | 子は `Elements`・`Connections`・`SignalDictionaries`・`SystemGeometry`・`GraphicalElements`（いずれも任意）。`Elements` の中は `Component`・`SignalDictionaryReference`・**入れ子の `System`** | 5.3、5.3.1 |
| `Component` | `type`（既定 `application/x-fmu-sharedlibrary`。ほかに `application/x-ssp-definition`・`application/x-ssp-package`・`text/x-modelica`）、`source`（SSD を基準にした相対 URI。SSP の中のものは**必須**で、例は `resources/MyDemoFMU.fmu`。2.0 から任意になり、無ければ実装なしの設計）、`implementation`（`any`・`CoSimulation`・`ModelExchange`・`ScheduledExecution`） | 5.4 |
| `Connectors` | 要素（`TElement`）の子。`Connector` は `name`・`kind`（`input`・`output`・`parameter` ほか）と型の子（`Real`・`Float64`・`Integer`・`Boolean`・`String`・`Enumeration`・`Binary`・`Clock` など）。FMU のときは名前が変数名に一致する。**接続で使うものは必須、それ以外は無くてよい** | 5.2.1 |
| `Real` の `unit` | `Units` の `Unit` 項目の**名前**。無ければ FMU の変数の単位 | 4.5.1.1 |
| `Connection` | `startElement`・`startConnector`・`endElement`・`endConnector`（`startElement` / `endElement` を省くとシステム自身のコネクタ）、`startIndices`・`endIndices`、`suppressUnitConversion`、子に `LinearTransformation`・`ConnectionGeometry`。**start / end はデータの向きではない**（向きはコネクタの `kind` で決まる） | 5.3.2 |
| `ParameterBindings` | 要素の子。値はインラインか `.ssv` の参照 | 5.2.3、6 章 |

## 4. 最小版が読む範囲と断るもの

| 読む | 断る（明確な誤り） |
| --- | --- |
| 1 つの `System` の `Component`（FMU）、`Connection`、`DefaultExperiment` の `startTime`・`stopTime` | 入れ子の `System`、`ParameterBindings`（S263 の 5 で `Component` の直下だけ読むようになった）、`SignalDictionaries`・`SignalDictionaryReference`、`LinearTransformation`、FMU でない `Component`、`source` の無い `Component`、システム自身のコネクタへの接続、Real・Float64 でない宣言のコネクタ、接続の両端で `unit` の名前が違うもの（`suppressUnitConversion="true"` を除く） |

## 5. ParameterBindings と SSV（S263）

- 確認日: 2026-11-15。出典は同じ仕様書 <https://ssp-standard.org/docs/2.0.1/> の 5.2.3（ParameterBindings）、6 章（SSV）、7 章（SSM）。

| 項目 | 事実 | 節 |
| --- | --- | --- |
| 置き場 | `ParameterBindings` は `Component`・`System` の子。中に `ParameterBinding` を複数置ける | 5.2.3 |
| `ParameterBinding` の属性 | `type`（既定 `application/x-ssp-parameter-set`）、`source`（URI。省略ならインライン）、`sourceBase`（省略か `SSD` は SSD の URI を基準、`component` はコンポーネントの source を基準）、`prefix`（省略か空なら無し。あれば**ソースの全ての名前の前に付けてから**名前の解決・マッピングをする） | 5.2.3 |
| `ParameterBinding` の子 | `ParameterValues`（インライン。`source` が空のときだけ。中身は `ssv:ParameterSet`）、`ParameterMapping`（任意。`source` で .ssm を参照するか `ssm:ParameterMapping` をインライン） | 5.2.3、5.2.3.1、5.2.3.2 |
| 適用の規則 | マッピングが無ければ、ソースの値を元の名前で適用し、合う名前が無ければ**無視**。FMU には modelDescription の変数名で適用（コネクタに出ていなくてよい）。複数の binding は**後ろが勝つ**。階層が違えば上位（System）が勝つ。対象は `causality="input"`・`variability != "constant"` かつ `initial` が `exact` か `approx` の変数（2.0 / 3.0）。適用は FMI 2.0 / 3.0 では初期化モードに入る前 | 5.2.3 |
| SSV ファイル | 整形式の XML 1.0、UTF-8、推奨拡張子 `.ssv`、名前空間 `http://ssp-standard.org/SSP1/SystemStructureParameterValues`（`ssv`）、ルートは `ParameterSet`（`version` と `name` が必須） | 6 章 |
| `ParameterSet` の子 | `Parameters`（必須）、`Enumerations`・`Units`（任意） | 6.1 |
| `Parameter` | 属性 `name`（セット内で一意）。子に型の要素が**ちょうど 1 つ**（`Real`・`Float64`・`Float32`・`Integer`・`Int8`〜`UInt64`・`Boolean`・`String`・`Enumeration`・`Binary`）と、任意の `Dimension`（配列） | 6.2 |
| 型の要素 | `value` 属性（必須。配列は空白区切りの行優先）。`Real`・`Float64`・`Float32` は任意の `unit`（`Units` の項目の名前） | 6.2.1〜6.2.13 |
| SSM | ルート `ssm:ParameterMapping`（名前空間 `http://ssp-standard.org/SSP1/SystemStructureParameterMapping`）、子は `MappingEntry` | 7 章 |

- 最小版が読む範囲は [ADR-0026](../adr/0026-fmi-import-placement.md) の (t)。Real・Float64・Integer・Int32・Boolean の `Parameter`、`.ssv`（`source`、SSP の中の相対パス）とインライン、`prefix`、後ろが勝つ、FMU に無い名前は無視。断るのは `ParameterMapping`・System の階層・`sourceBase="component"`・`unit`・`Dimension`・ほかの型。
- 【未確認】仕様書の本文には `.ssv` の完全な XML の例が無かった。型の要素の名前空間（`ssv:` か `ssc:` か）は XSD で確かめていないので、名前空間を見ずに局所名だけで読む（SSD の読み方と同じ）。Boolean の値の字句（`true`・`false`・`1`・`0`）は XML Schema の `xs:boolean` に倣った【未確認】。

## 6. 未確認・持ち越し

- XSD での検証はしない（要素の名前だけを見る。名前空間は見ない）。
- `source` の URI のパーセント符号化・`file:` などのスキーム・`#` の断片は扱わない（SSP の中の相対パスだけ）。
- `Units` の中身（換算の係数）は読まない。単位は名前の一致だけを見る。
- OMSimulator など他の実装との突き合わせはしていない【未確認】。
